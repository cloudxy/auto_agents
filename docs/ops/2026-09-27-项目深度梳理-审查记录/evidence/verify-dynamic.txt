### R4 QA-6 更正：上面同一进程内两次构造 Dynaconf 的探针被污染（第一次 load_dotenv 已把 PROBE=file 写进 os.environ），结论无效。

$ AUTO_AGENTS_PROBE=env uv run python -c "Dynaconf(..., dotenv_override=True).PROBE"   -> file   （.env 覆盖真实环境变量）
$ AUTO_AGENTS_PROBE=env uv run python -c "Dynaconf(..., dotenv_override=False).PROBE"  -> env    （环境变量优先）
