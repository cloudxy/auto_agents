## 3. 开通 / 激活

### 第一次成功（gate）— 空租户经办贴网址出数

本轮 **判定北极星** 仍是这一条：一家任务数为 0、不在内部测试名单的企业里，经办当天能交差。**不要先去结账，不要先订能力，不要先开通中转。** 步骤给人看，不是密钥注入。

1. **进空企业。** 未登录从官网读到采集第一句后点免费注册。主按钮是「创建企业」。企业名为空会提示「请填写企业名」；只填 1 个字会提示「企业名至少 2 个字符」——这两种都不会进后台。成功后进入 **该企业** 后台，不是个人空间。
2. **看数据中心是不是真 0。** 打开「数据中心」：接口成功、还没有结果时，只见「还没有结果，去提交采集」。空白、或把加载失败画成 0 条，都不是空企业。点 CTA 去采集任务。
3. **打开采集任务就能提交。** 任务数为 0 时，提交入口看得见。页上 **没有**「请先开通专业档」「请先订阅能力」。只读同事提交会被拒；经办可以提交。
4. **贴网址，立刻看句，不要盯着转圈。** 新增任务：选示例爬虫，地址贴示例链接。点提交后 **3 秒内** 必须变成「已入队」，或下面拦住句之一。不得停在「正在采集」。
5. **入队成功才算等待。** 最多等 120 秒。回到数据中心，本企业出现条数。别的企业打开同一批，看起来像「页面不存在」（0 行、没有对方字段）。这就是 **第一次成功（gate）**。
6. **规划未开放不是坏了。** 若同事先点了「AI 采集规划」：打开和提交都只见「智能规划未开放」，主操作 **去采集任务**。不会出方案、不会因此创建采集任务。不要答「还没有规划」，也不要让对方在规划页等出数。规划已开放且提交成功时，向导会进入「方案与试采」并在列表出现该行——**那一页不用「已入队」**，也不是本轮交差的必要条件。
7. **拦住也算诚实，不算「没货」。**  
   - 「采集未运行，不会出数」→ **查看节点**。租户 **没有**「启动工人」；工人是平台进程。客服不指导重启，升级 **平台管理员**。  
   - 存储满：「已达配额上限」→ **去结果库**。  
   - 用量/并发满：「已达配额上限」→ 买方 **申请提升** 进同一结账；经办/只读只到「请联系本企业管理员开通」。  
   工人句与配额句 **不得混用**。将满只警告「接近上限。超额操作会被拒绝。」，**不是**已达上限，页上无满额「申请提升」。

ToB：邀请 / SSO 说明文案本波 N/A（证书怎么配是 sre，本文不写）。  
ToC：未登录的第一次成功 = 读懂首页采集句并创建企业。**付费不是北极星，也不是经办的第一次成功。**

预发夹具出数 **不得**对外说成：非测试企业北极星已经在生产出现。客服仍按上面教；教完不等于成绩已达成。

### 买方：一条结账（提交开通，不是去支付）

买方从定价点「去结账」，或从用量点「去结账 / 申请提升」，或从「我的渠道组」点「去升级」。应进入同一结账页。打开结账 **不等于** 已买。本波对外主路径 **不是**弹出收银台。

| 看见什么 | 含义 | 下一步 |
|---|---|---|
| 商品（专业档 / 企业档 / 中转之一）+ **提交开通** | 还没有单据，通道配没配都这样 | 点「提交开通」。打开结账时空态 **不是**整页「收款通道未开通」。 |
| 「待支付」+「收款通道未开通，提交后等待平台确认开通」 | 提交成功。通道未配时 **仍会建单** | **等待平台管理员确认收款**。可去用量页「订单」tab 看同一张单。不要改走免费注册，不要再点一次想「再下一单」。 |
| 「已有待支付」 | 同一商品已经有一张待支付 | 落回那张单。**不**建第二笔。不要说「已有未完成的支付」。 |
| 「已开通」；Toast「已开通专业档 / 企业档 / 中转」 | 平台管理员已对该笔确认收款 | 专业/企业 → 去用量看上限；中转 → 去我的渠道组。租户订单 **不得**写「已确认」。 |
| 「请联系本企业管理员开通」 | 当前账号不是买方 | 关掉模态，留在来源页。不建单。 |
| 「没有这个商品。」 | 地址上的商品不对 | **返回定价**。 |

**客服与对外说明禁止接着说：** 现在就能买、已经能买、支付已通、四柱可卖。通道未配不是账号坏了。打开结账 ≠ 已买。本波 **没有**取消入口；单据保持待支付，不会变成「未完成」。专业档开通 **不会**把「我的渠道组」改成已开通中转。

用量页 **没有**可提交的套餐订购表（线下 / 支付宝 / 微信下单都已拆掉）。只读能看用量数字，不能创建待支付。

**预发 / 生产接通收款通道之前：** 买方按上表提交后就是待支付，等平台管理员在运营台确认。客服 **不得**口播生产已经能付完，也不得把内部测试单据或确认收款说成收款通道已接通。收银台「去支付」不是本波放行路径，不要当主教法。

金额：专业档展示与定价页同一数字（¥299）。企业档、中转展示结账页该商品数字，**不得**用专业档价格冒充。

### 租户管理员：出站一把名，中转两句分家

第一次成功 = 本人能走完本企业五条，且不再把登录者当成平台管理员。

| 想做的事 | 实际看到 |
|---|---|
| 给外部系统拉本企业结果 | 数据工厂 → **出站拉数钥匙**。零把时：「还没有出站拉数钥匙。签发后才能从外部系统拉本企业结果。」有权者 **签发出站拉数钥匙**。明文只这一次。渠道组令牌 **不能**拿来拉数（会被拒、0 行）。 |
| 找「API 钥匙」第二叶 | 导航没有。直打旧地址 → 「页面不存在或已被移除」，**不会**跳到出站页。 |
| 打开我的渠道组（还没买中转，含只开通了专业档） | 只「未开通中转」。无令牌、无「已开通 / 使用中」。买方 **去升级**。 **禁止**答「还没有令牌」。 |
| 打开我的渠道组（企业档或中转已开通，还没签发） | 只「还没有令牌」。买方 **签发令牌**。 **禁止**答「未开通中转」，也 **禁止**答「还没有渠道组。创建后才能签发令牌。」若签发过程需要先建组，只发生在签发弹窗里。 |
| 成员 | 能看见自己；有「添加成员」。不能把任何人设成平台超管。只读写控件是隐藏的。 |
| 用量 | 看见并发 / 存储 / tokens 三个 0 与上限，不是加载失败。升级仍是「去结账」。 |
| 我的安装 | 开关开、一行都没有：「还没有安装」，次链去能力市场。 **禁止**写成「能力市场未开放」。 |
| 能力市场 | 总开关关：「能力市场未开放」。开关开但没货：「暂无已上架能力」。两句不得对调。本页无上架、无总开关。 |
| 值班 / 运营台 / 用户 / 系统设置 | 导航没有。直打 → 「页面不存在或已被移除」+「返回工作台」。没有「抱歉您没有权限」，没有「当前账号不能改系统设置」。这 **不是**故障。 |

签发渠道组令牌成功：页上只给用法（地址 + 步骤）。**不得**说「网关已对租户开通」。签发成功 ≠ 已对租户开放对话。

权限还在加载：「权限加载中」。写入口看得到，但提交不会成功。整站不空白，也不露出平台写面。会话失效：「登录已过期。重新登录后回到刚才的页面。」

### 平台管理员：一扇值班门，运营台确认收款

**值班（中转站管控，唯一入口）：**

1. 系统管理 → **中转站管控**。导航里值班类叶子只有这一项。钥匙签发若需要，只在页内「钥匙」tab，不另开菜单。
2. 网关能连上、还没登记任何平台模型：「还没有平台模型，去网关登记」+ **刷新**。不要答「暂无渠道」。
3. 已登记且探针为活：该行「活」。能看总览 / 探针 / 事件。页上只给用法，**不**宣称网关已对租户开通，**不**陈述可买。「活」不是租户已买中转。
4. 租户打开这个地址：应是「页面不存在或已被移除」。这次尝试 **不算**值班打开成功。

**运营台确认收款（买方待支付之后）：**

1. 运营管理 → 平台运营台。零张待确认：「暂无待确认收款」。不是服务器错误。
2. 有待支付时：看见企业名 + 结账页该商品金额（专业档须与定价页 ¥299 一致；企业档 / 中转 **不得**写成专业档价）+ **确认收款**。确认前旁注「确认后不可撤销」。
3. 确认成功：超管 Toast「已确认收款」（这是超管动作名）。租户订单变成「已开通」，**不得**让租户看见「已确认」。
4. 金额不符或点错别人的单：拒绝，单据仍待支付，配额 / 中转不变。再确认已开通的单：保持已开通，配额不叠。
5. 租户直打运营台：404 同形，确认不了任何企业。

**用户 / 设置：** 按登录名停用后对方用原密码登不进去；已停用可筛出并恢复。种子平台账号不可删。保存设置不得说「官网已同步」。对外联系配空了，访客页就不要出现「联系我们」或占位邮箱；配了只标明这是联系方式，**不**声称已接通电话值班。

**能力市场（超管壳）：** 上架 / 下架一行。租户与访客 **没有**投稿入口。总开关关时公开面只「能力市场未开放」。下架不拆掉已经订过的安装行。

## 4. 客服 / CS 话术

客服先对锁句，再决定升不升级。三问不够就停，不要发明第四套出口。升级对象是 **平台管理员**（人），**不要**说「找开发」。经办要开通套餐时，先让对方找 **本企业管理员** 走结账；已经提交、停在待支付，再升平台管理员确认收款。

| 用户会问 | 标准答 | 升级给谁 |
|---|---|---|
| 「新公司后台是空的 / 智能规划一直转，第一次怎么交差？要不要先付费？」 | **不用先付费、不用先订阅。** 打开数据中心应看到「还没有结果，去提交采集」。到采集任务贴示例网址，3 秒内应出现「已入队」，随后在本企业数据中心看到条数。规划页若写「智能规划未开放」，这是正常关闭，点「去采集任务」即可，不要等规划出方案，也不要说「还没有规划」。卡住时只会出现「采集未运行，不会出数」或「已达配额上限」，两句不能混。空白当 0 条、或一直「正在采集」，才算异常。 | 句对但一直无条数、或工人句已出现 → **平台管理员**（先看采集是否在跑）。客服不指导启动工人。不要把拦住解释成「没人要采集」，也不要让对方去结账才能交差。 |
| 「怎么开通套餐？是不是已经能买？我点了提交一直待支付。」 | **不陈述可买。** 本企业管理员从定价或用量点「去结账」，主按钮是「提交开通」（不是用量页再填一张订购表）。通道还没配时，提交仍会出一张「待支付」，并写「收款通道未开通，提交后等待平台确认开通」——这是预期，不是账号坏了。同一商品再提交只会看到「已有待支付」，不会出第二张。开通完成前档位不变；开通后订单只写「已开通」，不写「已确认」。专业档开通不会附赠中转。经办/只读点「去结账」只会看到「请联系本企业管理员开通」。官网第一句仍是采集。生产能不能自动收完款，以通道是否已接通为准，客服不得口播「已经能付完」。 | 已经提交、停在待支付 → **平台管理员**（运营台确认收款；金额须与结账页该商品一致）。把空态/待支付当成事故、或要求改口成能买 → 仍由平台管理员会同产品运营守这道护栏，客服不改口、不找开发。 |
| 「出站钥匙在哪？渠道组到底是没开通还是没令牌？我打开值班/设置怎么是页面不存在？」 | **三件不是同一把钥匙，值班也不是你们企业的菜单。** 拉数只用「出站拉数钥匙」这一页签发；渠道组令牌不能拿来拉数。打开「我的渠道组」：还没买中转（含只开通了专业档）写「未开通中转」，买方去升级；已经开通中转但还没签发写「还没有令牌」，买方签发令牌。两句说反了就会把人带错路。公司管理员打开值班、运营台、用户管理、系统设置，本来就应看到「页面不存在或已被移除」，主按钮「返回工作台」，没有「抱歉您没有权限」。这不是故障，也不要答应给租户开第二扇值班门。 | 把 404 当故障、或钥匙/中转两句对不上、或签发后对话仍失败 → **平台管理员**（先核对：出站还是渠道组、中转开没开、值班是不是租户误打）。不要把租户带到开发、也不要让租户去登记平台模型。 |

补充（同一套锁句，不另开功能）：

- 「同事把结果链接发给我，打开是不存在」→ 跨企业本来就像「页面不存在」。不要答「你没有权限」。
- 「能力市场是空的 / 订不了」→ 「能力市场未开放」= 总开关关着；「暂无已上架能力」= 开关开了但没货；「还没有安装」= 本企业安装叶为 0。三句不得对调。
- 「结账打不开 / 没网」→ 「结账打开失败，请稍后重试。」或「网络不可用。连接恢复后再打开结账。」离线 **不是**「收款通道未开通」（后者只出现在提交成功后的待支付说明）。
- 「签发后看不见全文 / 对话失败」→ 明文只显示这一次。关闭后再看只有掩码。签发成功只给用法，不表示网关已对租户开通。经办不能签发渠道组令牌。
- 「导出 101 条 / 只要表格」→ 「单次最多导出 100 条」，不会产生文件；请缩小范围。成功导出是 CSV 或 JSON，不是表格软件专用格式。
- 页上若出现内部英文码或裸数字状态：按「加载失败，请稍后重试。」记下页上的错误编号，升级平台管理员。客服不读堆栈。

## 5. 对外说明

用户语言，无内部代号。本轮 **有条件放行**四条可走完的人话路径——**不是**整站四柱已完成，也不是收款已经对所有人接通。

**新企业可以当天交差。** 创建企业并登录后，若还没有结果，页面会请你去提交采集。贴一条示例链接，成功时会提示已入队，随后在「数据中心」看到本企业的条数。别人的企业看不到你的条。不必先开通套餐，也不必先订能力。智能规划如果写着未开放，去采集任务即可，不必在规划页等待。卡住会立刻说明：采集没有运行时写「采集未运行，不会出数」；用量或存储到顶时写「已达配额上限」。

**官网第一句仍是采集**（粘贴链接即可出数）。不是订阅成功，不是支付成功，也不是中转推销。有人提交开通或确认收款，都不替代交差。

**开通套餐或中转由本企业管理员在结账完成。** 定价付费档按钮是「去结账」。结账主按钮是「提交开通」。通道还没配时，提交后会看到待支付，并说明收款通道未开通、提交后等待平台确认开通——这是说明，不是你的账号坏了。请不要把「去结账」理解成已经付完，也不要把可见面理解成已经陈述可买。专业档开通不会附赠中转；中转要从「我的渠道组」的「去升级」走。订单只会出现「待支付」或「已开通」。

**出站拉数钥匙和渠道组令牌不是同一把。** 要从外部系统拉本企业结果，只签发「出站拉数钥匙」。渠道组是中转开通之后的用法；没开通时页面写「未开通中转」，开通了还没签发时写「还没有令牌」。

**公司管理员不是平台管理员。** 值班、运营台、用户、系统设置不属于本企业菜单。误打这些地址会看到「页面不存在或已被移除」。能力市场对租户是逛货架、订一行；开不开放由平台决定。

已知限制（诚实，避免客服被追问同一句）：示例站点等待上限 120 秒；单次结果最多导出 100 条；将满不会拦住提交；租户不能启动采集节点；钥匙明文只出现一次；租户不能改官网第一句、不能打开平台专属页。值班一行「活」不表示已买中转。本波不对外报值班时效，也不把预发夹具出数说成生产北极星已出现，更不把确认收款说成支付已通。

## 6. 这不是产品需求时

若分诊是「已有能力，用户不知道」：本文即主交付，不新开产品需求。理由：

- 空企业能提交、规划未开放有关闭句、结账只「提交开通」、未配通道可待支付、出站单一产品名、未开通中转与还没有令牌分家、值班单一入口、租户 404 同形——均已在合同与 `edge-states.md` 里。客服不会答、经办先去规划空转、买方把待支付当事故、管理员把 404 当故障，是 **教 / 开 / 告** 缺口，不是新功能。
- 「用户想听到能买」在收款通道指纹出现前是 **预期禁句**，不是漏做的定价文案。付钱教法只教「提交开通 → 待支付 → 平台确认 → 已开通」，不宣布生产收银台已接通。
- 「值班显示活但中转仍未开通」是两套页面，不是漏做的购买成功页。
- 「签发了令牌但对话失败」在真网关轮记下之前，只给用法、不宣称已对租户开通——这是预期诚实，不是漏做的开通成功页。
