## 1. 文案护栏（全访客 / 全租户可见面）

出现任一句 = 本设计合同失败：

| 禁止 | 用什么 |
|---|---|
| **「当前可买」**（四字及变体） | 付费出口只「去结账」；SKU 可结账 ≠ 可印四字 |
| 「支付已通」「网关已对租户开通」 | 签发成功只给用法 |
| 「已有未完成的支付」 | **「已有待支付」** |
| 「已确认」（租户订单） | **「已开通」** |
| 「开通处理中」「未完成」「支付未完成，套餐未开通」 | W2 不构造、不渲染 |
| 用量页「套餐与订购」可提交表（BillingPanel：线下/支付宝/微信下单） | 拆除；只留「去结账」 |
| 「还没有采集结果。完成一次采集后会显示在这里。」 | 「还没有结果，去提交采集」 |
| 规划未开放时「还没有规划」 | 「智能规划未开放」 |
| 规划成功「已入队」「规划已受理」 | 向导进入「方案与试采」且列表出现该行 |
| 未开通中转时「还没有令牌」 | 「未开通中转」 |
| 已开通零令牌时「未开通中转」 | 「还没有令牌」 |
| 已开通零令牌「还没有渠道组。创建后才能签发令牌。」 | **删除**。打开页 Then 只「还没有令牌」+ 买方签发；建组若需要只在签发流程内 |
| 市场关旗「暂无已上架能力」 | 「能力市场未开放」 |
| 开关开、可见行=0「能力市场未开放」 | 「暂无已上架能力」 |
| 安装 0 行写成「能力市场未开放」 | 「还没有安装」 |
| 值班「暂无渠道」/ GWT-61.2 合成句 | 「还没有平台模型，去网关登记」或挂了句 |
| 租户设置写面「当前账号不能改系统设置」 | **404 同形** |
| 「抱歉您没有权限」当平台页 Then | 后台 404 同形 |
| `QUOTA_EXCEEDED` / 裸 `429` / `FORBIDDEN` / `PAYMENT_NOT_CONFIGURED` / `QUOTA_PLAN_LOCKED` | 工人句或配额句或规划未开放句 |
| 失败装 0 / 失败装没货 / 0 画成加载失败 | 错误态 +「重试」 |
| 请先开通专业档 / 请先订阅能力（采集提交前置） | 无此前置；空企业可提交 |

## 通用规则

### Toast vs 内联 vs 全屏

| 严重度 | 用什么 |
|---|---|
| 成功 | Toast 3s，动词与按钮同名（「已入队」「已签发」「已开通专业档」） |
| 可恢复操作失败 | 内联，不关弹窗、不清表单 |
| 页级加载失败 | 内容区替换 + **重试** |
| 会话失效 | 跳登录，保留 `from` |
| 部分（将满、待支付等确认、导出上限） | 警告色 Alert，不是错误红、不是成功绿「已买」 |

不只靠颜色：错误 ✕、警告 ⚠、成功 ✓、将满 ⚠、「活」● 文字、「预告」文字角标。

### 加载节奏

首次：骨架（形状跟真内容）。刷新：旧内容 opacity 0.6 + 顶细进度，不整页骨架。&lt;200ms 不闪。&gt;10s：「加载较慢」+ 仍可重试。

### 未知错误兜底

「加载失败，请稍后重试。」小字「错误编号 {trace_id}」（无堆栈、无 code）。主按钮「重试」。

### 离线默认句（错误态的网络分支）

标题「网络不可用」。说明「已打开的内容仍可阅读；提交、签发、刷新列表会失败。」主按钮「重试」。**禁止**离线渲染成空列表或金标空态。

### 404 同形

与未登录打不存在页同一模板：标题「页面不存在或已被移除」；主按钮「返回工作台」。无渠道列表、无密钥、无源列表、无上架控件、无设置表单、无「抱歉您没有权限」、无「当前账号不能改系统设置」。

租户（含公司管理员）直打闭集 → 屏 20：

| 地址 | 超管 | 租户 |
|---|---|---|
| `/newapi`、`/newapi/*`（含钥匙 tab） | 屏 16 | 屏 20 |
| `/platform-ops` | 屏 17 | 屏 20 |
| `/users` | 屏 18 | 屏 20 |
| `/settings`（写面） | 屏 19 | 屏 20 |
| `/rbac`、`/enterprise`、`/payment-credentials` | 既有 | 屏 20 |
| `/api-keys`、`/api_keys` 及历史第二套钥匙 | — | 屏 20（**不**重定向出站） |
| 上架治理写面子路由 | 屏 22 | 屏 20 |
| 他企结果/单/成员/安装/钥匙深链 | — | 屏 20（0 行、无对方字段） |

**不是 404：** 租户打开 `/capabilities`（货架）、`/relay`（渠道组产品面）、`/usage`、`/outbound-keys`、`/ai`、`/data`。市场关旗也不是 404（关闭句）。

### 隐藏 vs 禁用

| 能力 | 无权限时 | 理由 |
|---|---|---|
| 平台专属叶（值班/运营台/用户/设置写/上架治理写） | **隐藏**；直打 404 | 不该知道有平台写面 |
| 发现性：提交采集、签发、订阅 | **禁用 + 旁注**找管理员句 | 应该知道有这功能 |
| 定价「去结账」、用量「去结账」、渠道组「去升级」 | 非买方 **可点进屏 7**（按钮字不改） | When 是点按钮；灰掉会找不到下一步 |
| 预告行订阅 | **隐藏按钮** | 预告不可订，不是权限不够 |
| SKU≠active 时「签发令牌」 | **隐藏**（不是禁用） | 避免像已买但不能签 |
| 只读成员写控件 | **隐藏**（FR-89） | 点了再失败不算藏 |
| `permissionsReady=false` 的写入口 | **不隐藏**；不可提交成功；旁注「权限加载中」 | GWT-M30.5；未知 ≠ 无权限滤光 |

### 交互四态（写控件）

| 态 | 表现 |
|---|---|
| hover | 主色加深；指针变化 |
| focus | **可见焦点环**（不能只有 hover） |
| active | 按下加深 |

## 屏 23：注册 `/register`

### 加载

主按钮「创建中…」。

### 空

➖ 空表单是初始，不是空态。主按钮锁字 **「创建企业」**。

### 错误（含离线）

| 条件 | 文案 |
|---|---|
| 企业名为空（GWT-M51.2） | 「请填写企业名」；不创建；不进后台 |
| 企业名恰好 1 字（GWT-M51.4） | 「企业名至少 2 个字符」；不创建 |
| 其它校验 | 「注册未完成：{原因}。改正后再次创建企业。」 |
| 离线 | 「创建企业失败：网络不可用。检查连接后重试。」 |

### 禁止

已登录租户寻找「开通个人空间 / 去掉企业只用个人账号」：无该入口。成功后不是 C 端个人空间首页。

### 成功（GWT-M51.1）

创建一家企业并进入 **该企业** 后台。Toast「企业已创建」。主按钮若需登录链：落地该企业后台，不是个人仪表盘。

### 部分

名 ≥2 且其余必填未填：只提示缺项，不创建。页上无「当前可买」。`DUTY_CONTACT` 空则本页无联系 CTA。

**交互：** 焦点序：企业名 → 邮箱 → 密码 → 创建企业。
