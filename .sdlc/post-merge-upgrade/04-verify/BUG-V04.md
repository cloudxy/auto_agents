# BUG-V04 · 买方提交取消：只有「无入口」，没有直打 API

| 项 | 内容 |
|---|---|
| 严重度 | major |
| 违反的 GWT | GWT-M11.13 |
| 发现于 | 覆盖矩阵：`Checkout.test.tsx:194` 覆盖 GWT-M11.10 无取消钮；`test_fr_m*` 无 cancel POST |
| 指派 | `/backend` |
| 状态 | open |

## 2. 复现步骤

```
1. 企业 A 买方创建一张 checkout_pending
2. 在 test_fr_m11_*.py 搜索 cancel / 取消 → 无
3. UI 断言无取消钮 ≠ 后端拒绝提交取消
```

## 3. 期望 vs 实际

| | 内容 |
|---|---|
| **期望** | 提交取消 → 拒绝；单据保持待支付；配额不变；不产生「未完成」 |
| **实际** | 未对 cancel/unpaid 写路径做 HTTP 断言 |

## 5. 影响范围

| 项 | 内容 |
|---|---|
| 受影响的用户 | 会抓包的买方 |
| 有 workaround 吗 | UI 无入口 |
| 安全影响 | 若旧 `/orders/{id}` 取消仍通，可能把 W2 单打成 unpaid（spec 禁止租户见「未完成」） |
