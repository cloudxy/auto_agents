## US-M1-01 规划未开放不假装出方案

### Card

作为采集经办，我想在智能规划未开放时立刻看到「智能规划未开放」，以便改走采集任务贴地址——而不是对着「正在规划」空转。

### Context

| 项 | 内容 |
|---|---|
| 什么时候用 | 打开 AI 采集规划；平台智能规划默认关 |
| 多频繁 | 空租户第一次特别疼 |
| 这之前 | 已登录，准备贴 URL |
| 这之后 | 改走采集任务（US-M1-03）或等规划开放 |
| 现在怎么做 | LLM 默认关；规划/试采走业务异常或装成空 |
| 不做会怎样 | 经办以为系统在出方案，北极星永远 0 |

### Confirmation

FR-M01。打开或提交规划未开放时，句只「智能规划未开放」。规划已开放且 GWT-70.1 前置满足且成功：只「可见方案」= 向导进入「方案与试采」步且方案列表出现该行（GWT-M01.4）。未登记只 GWT-70.2「还没有平台模型」。网关不可达且无本企业激活供应商只 GWT-74.1「平台 LLM 网关不可达」。有本企业激活供应商且网关停只 GWT-73.6。不用「已入队」、不用「规划已受理」、不另写「规划失败」。
