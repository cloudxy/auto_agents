## 1. 背景与问题定义

**谁**：要把网页变成本企业表格的 **采集经办**；要开通/付钱的 **买方（公司管理员 / 开通负责人）**；要管成员/用量/钥匙/渠道组/安装的 **租户公司管理员**；要值班与治理的 **平台超管**。不是「用户」。

**现在什么情况**：菜单和官网看起来齐。经办第一次出数仍脆（工人 / 配额 / 智能规划默认关；C4 未跑）。买方同时能点官网「去结账」和用量页「套餐与订购」，状态词两套；0 笔生产支付。出站查找用户会撞上不止一把「能拉数」的凭证名。值班操作者面与网关钥匙面不是同一入口。市场旗默认关。词表仍写「令牌不发给租户」「无支付网关」。无租户访谈、0 工单、Reach **未量化**。

**期望什么结果**：经办在空的非夹具企业贴地址，能交差或立刻看见卡住原因；规划未开放时不假装出方案；数据中心能看见本企业条。买方只走一条结账，能下单、能看见待支付/已开通，能被开通——不要求本波弹出真收银台。公司管理员能走完成员、用量、出站钥匙、渠道组、安装各一条。超管只有一个值班入口，运营台/用户/设置各能走完；对外联系空则不展示。市场旗开能订一行，关时写「未开放」。

**凭什么说改善了**：判定窗内出现至少一家 **非夹具租户** 采集完成且条数>0（北极星）。买方只看见一条结账故事且能走到待支付或已开通（驱动）。不把 live 沙箱当北极星。未量化不得标市场通过。不得标四柱 GA。

### W2 — 买方一条结账故事（必须功能不含 live 沙箱）

对照仍验收（live **另波**，本波不把通道收银台当放行）：FR-U30 通道仅支付宝/微信；FR-U31 商户凭据仅超管；FR-U33/U38 **仅约束通道路径**（未验真的通道通知不得开通）；FR-U35 付费档主钮到结账不到注册；FR-U36 非买方不能下单。超管确认收款 **不走** FR-U38。

W2 放行：FR-M10 + GWT-M11.1…M11.6 + GWT-M11.8 + GWT-M11.12 + GWT-M11.14…M11.17 + FR-M12（含 GWT-M12.6 / M12.8 执法）+ FR-M13 + FR-M14 + FR-M15。GWT-M11.7 不是本波放行条件。租户可见状态闭集本波仅「待支付」「已开通」。同一商品再提交租户句只「已有待支付」。

#### FR-M10 租户可见面只保留一条结账故事

用量页不得再出现可提交的「套餐与订购」表单（含线下 / 支付宝 / 微信可提交选择）。升级/满额入口只有「去结账」，进入与定价页专业档主钮 **同一** 结账故事。W2 租户状态词闭集（§0.4.1）：**待支付** / **已开通**。不得给租户看「已确认」「支付未完成，套餐未开通」「开通处理中」「未完成」。

#### FR-M11 买方能下单、看见状态、被开通

必须功能：**能下单**（产生待支付）、**能看见状态**（我的订单或结账页）、**能被开通**（超管确认收款 → 已开通，不可逆，**不走 FR-U38**）。商品闭集 `plan_pro` / `plan_enterprise` / `relay` 各有一条提交→待支付→确认收款边。**不要求** 本波出现支付宝/微信收银台。两通道均未配置时：结账页仍可提交开通，产生待支付，文案「收款通道未开通，提交后等待平台确认开通」。同一企业同一商品同时只能有一笔待支付（含并发，GWT-M11.12）。再提交只见「已有待支付」，禁止「已有未完成的支付」。**[SEC-3]** 确认收款只能作用在本笔待支付，金额必须与结账页该商品展示金额一致（专业档=定价页 ¥299；企业档=结账页企业档展示且不得用 ¥299；`relay`=结账页该 SKU 展示且不得用 ¥299）。

#### FR-M12 专业档 ¥299；开通后三数字与定价页同一套；中转不是专业赠品

### 文案闸与注册（随波验收）

#### FR-M50 禁「当前可买」直到 live 支付通道指纹

Q-AGPL 已答：SKU 可施工可结账。**所有访客可见面与所有租户可见面** 在 live 支付通道指纹之前不得出现「当前可买」四字。禁区包括首页、功能介绍、定价、后台导航、用量、结账、渠道组、能力市场、任务/结果、站内通知。仅超管配置页也不得用这四字冒充已通。超管确认收款 ≠ 指纹。HMAC 夹具 ≠ 指纹。

| GWT | 类型 | 内容 |
|---|---|---|
| GWT-M50.1 | 正常 | **Given** live 支付通道指纹未发生 **When** 访客打开任一未登录可达页 **Then** 全文不出现「当前可买」 |
| GWT-M50.2 | 边界 | **Given** 已有一张非夹具租户待支付或超管已确认开通、指纹仍未发生 **When** 访客打开定价 **Then** 全文仍不出现「当前可买」 |
| GWT-M50.3 | 越权 | **Given** 租户公司管理员已登录 **When** 寻找编辑定价文案 **Then** 没有该入口 |
| GWT-M50.4 | 边界 | **Given** 指纹未发生、经办或公司管理员已登录 **When** 打开任一租户可见页 **Then** 全文不出现「当前可买」 |

#### FR-M51 注册=创建企业；无个人空间

注册主按钮「创建企业」；企业名必填且至少 2 个字符。成功后进入 **该企业** 后台，不是 C 端个人空间。已登录租户不能开通个人空间。

| GWT-M51.2 | 空态 | **Given** 企业名为空 **When** 点「创建企业」 **Then** 提示「请填写企业名」；不创建企业；不进入后台 |

## 3.1 状态流转

### 采集任务

沿用 upgrade §3.1。本特征追加：智能规划未开放 → 提交规划 **不入队、不产生方案**（FR-M01）。第一次采集 **不** 以付费/订阅/中转为前置（FR-M03）。

**非法：** 无工人却超过 3 秒仍「正在采集」；规划未开放却产生可入队方案；结果写入其它企业；候选当合格出数。

### 结账单据（租户可见）

W2 可构造（闭集仅两态，§0.4.1）：

```
（无单）──买方在结账页提交开通──> 待支付
待支付 ──超管确认收款且金额=结账页该商品展示──> 已开通
```

终态（W2）：已开通。待支付不是终态（可被确认）。

Live 波才构造、**本波不验收产生**（不进 W2 闭集、不进 FR-M14）：

```
待支付 ──FR-U38 验真通过且开通完成──> 已开通
待支付 ──验真通过但开通未完成──> 支付已到账，开通处理中 ──开通完成──> 已开通
待支付 ──通道失败 / 超时──> 未完成
```

| 流转 | 触发 | 谁 | 副作用 | 波 |
|---|---|---|---|---|
| 无单 → 待支付 | 买方在结账页提交开通 | 买方 | 租户可见待支付；用量页不产生第二套单 | W2 |
| 待支付 → 已开通 | 超管确认本笔且金额与结账页该商品展示一致 **[SEC-3]** | 超管 | `plan_pro`：配额专业档执法（GWT-M12.6/M12.8），中转仍未开通。`plan_enterprise` / `relay`：中转已开通能力具备（GWT-M11.15/M11.17）。**不走 FR-U38** | W2 |
| 待支付 → 已开通 | FR-U38 验真且开通完成 | 系统 | 同商品履约；未验真不得走此边 | live |
| 待支付 → 支付已到账，开通处理中 | 验真通过、开通未完成 | 系统 | 档位仍为开通前 | live |
| 待支付 → 未完成 | 通道失败/超时 | 系统 | 档位不变 | live |

**非法流转：**

| 非法 | 期望（状态 / 记录 / 副作用） |
|---|---|
| 只读/经办 → 待支付 | 不创建；联系管理员 |
| 用量页旧订购入口 → 第二套单 | 不产生；原单不变 |
| 两名买方同时提交同一商品 → 2 笔待支付 | 只 1 笔待支付；另一人「已有待支付」；配额不变 |
| 租户自标已开通 | 保持待支付；配额不变 |
| 已开通 → 再确认再叠配额 | 保持已开通；配额不叠 |
| 买方取消 → 未完成 | 无取消入口；保持待支付（GWT-M11.10） |
| 未验真通道通知 → 已开通 | 保持待支付；无 `payment_succeeded`（FR-U38 **仅通道**） |
| 确认收款但金额≠结账页该商品展示（含企业档写成 ¥299） → 已开通 | 保持待支付；配额/中转不变 **[SEC-3]** |
| 租户再提交同一商品待支付 | 只 1 笔；句为「已有待支付」；禁止「已有未完成的支付」 |
| 已开通 + 迟到通道成功通知 → 再叠配额 | 保持已开通；记迟到回调。专业档中转仍未开通（GWT-M11.11）；企业档/`relay` 中转保持已开通、不重签令牌（GWT-M11.18） |
| 商品=`plan_pro` 已开通 → 中转已开通 | 中转保持未开通；令牌数 0 |
| HMAC 夹具 → live 指纹 | 指纹不算发生；禁四字仍生效 |

### 出站拉数钥匙

```
（无钥匙）──有权者签发──> 已签发（明文仅当次）
已签发 ──吊销──> 已吊销
```

**非法：** 只读签发；渠道组令牌列入出站；未在出站入口签发的凭证拉到行；跨企业拉到行。

### 市场总开关 / 安装行

沿用 FR-U11：关闭时不得新产生安装行。FR-M40：点货架 ≠ 进治理七叶。下架不级联删安装。

### 值班入口

合法：超管打开唯一入口。非法：租户打开见到渠道列表或密钥或「抱歉您没有权限」；导航出现第二套网关钥匙叶。
