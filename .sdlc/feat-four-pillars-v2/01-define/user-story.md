## US-W0-01 访客不被骗

### Card

作为第一次打开官网的访客，我想看到的「现在就能用」都是我能走完的，以便决定要不要注册——而不是对着示意大数、Excel 和空头套餐做决定。

### Context

| 项 | 内容 |
|---|---|
| 什么时候用 | 第一次打开首页 / 功能介绍 / 定价 |
| 多频繁 | 每名新访客一次；定价可能反复比 |
| 这之前 | 搜索或被内部分享 |
| 这之后 | 注册，或离开 |
| 现在怎么做 | 读 Slogan「智能数据采集」；Hero `128,000+`；Features 卖 Excel；定价三档都进注册；技能精选失败变空白 |
| 不做会怎样 | 继续履约裂缝；WACT 观察钟也无法诚实启动 |

### Confirmation

指向 FR-01、FR-02、FR-03、FR-05、FR-15。Q-VOICE 未关：不验收「我们是××平台」那一句。卖点闭集见 FR-01 A1–A5 / B1–B6。五档 `cta` 各一格（GWT-15.6 / 15.15–15.18）。「体验 AI 采集流程」另报不进 F1（GWT-15.19）。先逛再注册必须带同一匿名身份（GWT-15.5）；无浏览会话注册只计数、不进 F1（GWT-15.14）。
