## 1. 一句话结论

现界面仍是 **采集控制台 + P6 四类目录雏形 + SaaS 骨架 + 中转值班页**，不是四柱产品，更不是五类平级的能力市场。目标 IA 要的是：官网单一「能力市场」、五类可搜可订、预告可见不可订、unlist 不杀已订、治理台 7 叶、租户订的是**这一张卡**。现 UI 连四类展览都做不全（能力广场卡不可点、无搜索、失败装空），与目标差的不是换标签，是 **一整组尚未存在的 flow**。Q-VOICE 未关前禁止新写并列四柱 Hero；诚实面与权限壳可以先走。

## 2. 诊断口径

### 2.1 界面要认得的角色（Power Market 已切三件事，不得合成一种「用户」）

| 角色 | 心智任务 | 现界面 |
|---|---|---|
| 匿名访客 | 判断现在能做什么、逛已上架能力、比价、注册 | 首页只讲爬虫；市场是两个广场；定价卖未履约项；无登录 |
| 租户 owner / 经办 | 注册后登录、邀成员、订一张卡到某个宿主、看配额 | 注册有、成功页无登录；订阅无屏；官网无会话 |
| 租户只读 | 看本企业任务/用量/已订，不能订不能卸（除产品另定） | 按钮常直接隐藏，无「请联系管理员」 |
| 平台超管 | 源同步、五类 listing、许可 override、渠道窗口、平台 LLM | 菜单有，词是工程师的（资产目录/扫描/专家）；守卫把租户 `admin` 当平台超管 |

策略不变：后台 antd 基座，契约质量 > 花样；官网是品牌前线，必须两遍法。混合熟练度 → 空态邀请；破坏性确认永不跳过。

### 2.2 用户完成什么才算「市场成立」（相对现网）

| 用户完成 | 设计权威 | 现网 |
|---|---|---|
| 导航只有「能力市场」；`/skills` 到达带 `type=skill` 的市场 | D19 | ❌ 双叶并存 |
| 五类筛选 + 搜短名命中；卡片主标题是展示名/短名 | D22 / D3 | ❌ 四 Tab；命令不存在；能力广场卡不可点 |
| 预告可见不可订；已上架可订这一行 | D17 / D10 / D24 | ❌ 无预告、无订阅 |
| unlist 后商店消失；已订行仍可卸、不可再订 | D23 | ❌ 无安装表、无此态 |
| 出处链仅当父插件 listed；否则纯文本署名 | 审查「官网出处不泄漏」 | ❌ 无详情 |
| 失败 ≠ 空；筛选空 ≠ 目录空 | P-DES-01 / P-DES-04 | ❌ 三处 catch→`setItems([])` 再渲染「暂无已发布」 |
| 访客读到的「现在就能用」都能走完；无虚构规模 | 四柱诚实面 | ❌ Hero `128,000+` / `3.2 亿条`；Features 卖 Excel |

| 租户 admin 做不了平台写 | D14 | ❌ `ProtectedRoute.requireAdmin` 认租户 `admin`；插件验证无 `usePermission` |

## 3. 信息架构裂缝

### 3.1 用户第一个词 vs 现在放哪

| 用户第一个词 | 现在 | 目标 | 碰撞 |
|---|---|---|---|
| 「装一个技能 / 命令 / 智能体」 | 官网「技能广场」**和**「能力广场」；后台「能力资产 → 资产目录」；词表四类 +「专家」 | 单一「能力市场」；五类平级；智能体 ≠ 专家 | **三名一物，且少一类。** `ASSET_TYPE_LABELS` 仍是 `expert` / `expert_team` |
| 「订这个插件会不会把技能也装上」 | 无订阅，故无文案 | **不会。** 订/卸只作用于这一行（D24） | 新方案若沿用「安装插件」口语会把礼包语义做回来 |
| 「我已经订过、商店里怎么没了」 | 无屏 | 「我的安装」仍在；商店 404 同形不解释 unlist | 旧稿偏「下架后安装」；v2 必须把 **unlist ≠ blacklist** 画成两种残留 |
| 「我的采集 / 结果」 | 数据工厂 → 采集任务（页内再套文件/定时/告警/模板）；结果在任务抽屉 + 数据中心 | 采集仍在后台；导出诚实 | 「采集方案」三义；Excel 只在官网 |
| 「额度」 | 用量看板（`tenantOnly`）；定价 | 有档名、有下一步、无内部码 | Alert 写 `429 QUOTA_EXCEEDED` |
| 「渠道假不假」 | 系统管理 → 中转站管控 | 平台超管值班页；租户导航隐藏、直打同 404（Q-RELAY 前不画租户渠道组） | 产品柱埋进设置；`requireAdmin` 让公司管理员能进 |
| 「我的同事」 | 成员管理 vs 用户管理 | 菜单层按角色消失 | 进页后 Alert 教走另一套 IA |

### 3.4 IA 碰撞按严重度

**P0 — 与已过审 D 决策或诚实面直接冲突（新方案必须改）**

1. **商店双入口**（D19）— `NAV_LINKS` 技能广场 + 能力广场；首页 `SkillsSection` 链 `/skills`。
2. **四类 ≠ 五类**（D22）— 官网/后台/`ASSET_TYPE_LABELS` 都没有 `command`；对外仍 `expert`。少一类等于商店对象错了。
3. **产品仍叫「专家」**（D22）— 后台 Tab、扫描按钮、空态路径、组建团表单「团长专家」。CONTEXT 已改，UI 未跟。
4. **官网价值主张只卖采集，定价卖四柱** — `SITE_SLOGAN`；Features 写「CSV / Excel」；定价突然出现工单、BYOK、渠道组、私有技能库。
5. **虚构规模仍渲染** — `HERO_STATS`；角标「示意数据」不能赎。
6. **注册成功无登录出口** — 主按钮「再注册一家」。
7. **租户 admin = 平台写面** — `ProtectedRoute` 无 `is_platform_admin`（登录快照甚至没有该字段）；中转/LLM/平台运营走 `requireAdmin`。
8. **失败装空**（P-DES-01）— 首页精选、技能广场、能力广场同一陷阱。

**P1 — 任务归属 / 深度 / 词**

9. 后台叶名「资产目录」不是市场；组名「能力资产」是系统模块名。
10. 技能内 3 层（目录→技能→候选）。治理任务可 3 层；**逛五类必须顶栏 1 层**，不得把命令塞进插件 JSON 展览。
11. 人帐双页：Members Alert 教走用户管理 — 应在菜单层按角色消失。
12. 「采集方案」三义；本波至少改可见标签。
13. 能力广场卡无 `role`/链接 — 详情必须是真 URL，不能再做死展览。

**P2**

14. 幽灵 `/enterprise` `/rbac`。
15. `tenantOnly` 对超管隐藏用量/成员，Header 无「你在平台视角」。
16. 官网「管理后台」直链 `REACT_APP_ADMIN_URL`（默认 localhost:9112）。
17. 登录页紫渐变与品牌蓝青脱节。

## 4. 必须进全新方案的 flow

图例：✅ 可走完　⚠️ 能进但断或词错　❌ 无屏。每条 flow 都是 `/pm` 的 FR 覆盖候选；砍掉等于商店或诚实面不成立。

### F1 · 诚实首页（Q-VOICE 前只删空头，不写新定位句）

```
访客打开 / 
  → Hero 不得出现绝对规模数字（删 HERO_STATS 整区，不是加角标）
  → Features 不得承诺未实现的 Excel / 多通道工单
  → 技能精选：有真卡则链到市场（不是 /skills 独立广场）；失败走 F10，禁止空白当没货
  → 主 CTA：注册或登录后台（Q-MARKET-USER 未关前不把「逛市场」做成唯一主承诺）
```

现网：❌ 假统计、Excel、精选 catch 变空、CTA「体验 AI 采集流程」只滚到示意锚点。

### F2 · 注册 → 登录开工

```
/register 提交成功
  → 成功屏主按钮「登录管理后台」→ 后台 /login?from=/dashboard
  → 次按钮才是「再注册一家」
  → Toast 与按钮同名：承诺能登录，屏上就要能登录
登录页：页脚「没有账号？企业注册」→ 官网 /register
```

现网：❌ 主按钮再注册；登录页无回链。

### F3 · 定价 CTA 分档

```
免费档 CTA → /register
专业/企业 CTA → 不得再进 /register
  Q-PRICE/Q-BILL 未关：标「预告不可购买」或「企业需求请联系」（mailto/说明页）
  禁止按钮写「联系升级」实际去免费注册（P-DES-03）
```

现网：❌ 三档同一出口。

### F4 · 平台壳 vs 租户壳（权限是界面，不是只藏按钮）

```
租户公司管理员
  → 导航无中转站管控 / 平台 LLM 写 / 用户管理 / 平台运营台 / 市场源与 listing 写
  → 直打这些 URL：与「页面不存在」同形（旧 spec 对中转的默认；新方案需 /pm 冻结）
  → 不是 /unauthorized「抱歉」
平台超管
  → 进得去上述页；无租户时用量/成员不出现或权限态「用量属于企业空间」
插件「验证」、源「同步」、listing 开关
  → 无权限：禁用 + 旁注，不要只靠菜单隐藏（发现性）
  → 平台专属危险操作（许可 override、源登记）：隐藏
```

现网：⚠️ 中转降级 Alert 是全库最好的错误态样本，但进页守卫过宽；插件验证无 `usePermission`。

### F5 · 商店列表 D1（五类货架）

```
屏：/capabilities?type=&q=&host=&category=
进入：导航「能力市场」；首页精选；/skills → ?type=skill
关键元素：类型（全部+五类中文标签）· 搜索短名 · 宿主 · 分类 · 卡片
主操作：搜 origin_local_name / title 打开详情（真链接）
卡片标题：展示名或短名；禁止 mattpocock-skills__code-review 当 H
预告：角标「预告」，无订阅按钮，旁注「尚未上架」
已上架：登录「订阅」；未登录 → 登录回跳（不 403）
unlisted / 黑名单：不出现
离开：详情；筛选保留在 URL
返回：保留 q/type/滚动
```

现网：❌ 四 Tab 死卡；无命令；无预告。

### F6 · 商店详情 D2

```
屏：/capabilities/:type/:slug   type 为新枚举
读：说明 / 许可 / 来源 / 宿主 / 合集「包含」（只列 listed/coming_soon 子卡）
出处：父插件 listed → 可点链接；否则纯文本署名（审查冻结，防 L1 把 unlist 插件带出来）
订阅：listed 可订这一行；coming_soon 大标「预告」+ 按钮禁用「尚未上架」

### 9.2 计划四要素（修订稿，未实现；Q-VOICE 前不把市场做成 Hero 主视觉）

**色彩（命名）**  
`ink` = 统一 `deepSpace`，删 `#0b1830` 分叉；`signal` = 主操作蓝；`telemetry` 青 **只用于一处**（数据在流动 **或** 预告，二选一）；`paper` 内容底；`alert` 熔断/配额。

**字体**  
系统/antd 无衬线。不上衬线（会滑向簇 1）。用字重与行长 <80 字做层级。

**布局概念**  
Q-VOICE 前：**一条采集管线**，不要四柱平均用力。假统计删除。功能五卡收成管线节点或删。市场货架等商店波，且必须是真数据。

```

[ CTA 登录开工 ]
商店波在四步与定价之间插入：市场货架 6 张真卡（五类可混，预告角标是信息装置）

对齐：货架与定价左对齐；Hero 可居中（唯一居中）。

**原则**

1. 大胆只花在 Hero 一句（不要光晕+芯片+渐变字+三列统计叠在一起）。
2. 货架用「预告/已上架/已下架」装置承载信息，不用装饰 eyebrow。
3. 后台保持 antd；同一套 semantic 让「预告/正品/配额/已下架」跨应用可认。

### 9.3 第二遍自问

「给另一个爬虫 SaaS 会不会画出同样的深空 Hero + 五卡 + ALL-CAPS 眉标？」——会。故：砍眉标或改成中文短标签且仅用于真分类；砍每卡 hover 抬起；统计三列删除。
