## 1. 判定纪律

| 项 | 规则 |
|---|---|
| 判定周期 | 相关波次对用户可用之后 **4 个上海自然周**；中途不下成败 |
| 基线 | 无。第一轮目标就是建立基线 |
| 时区 | **Asia/Shanghai 业务日**；指标用 **事件发生时间** |
| 分流 | 无 A/B。市场总开关是发布控制。若将来做实验，分流单位 = **企业** |
| 排除 | 市场入站候选不得计入采集北极星。内部测试企业四周复盘用 **手工名单**，不得假装已有内部账号过滤器 |
| 验收 | 以事件可查为准；任务表仅核对。不得用 `/admin/stats` 或通知表 `task_completed` 冒充 WACT |
| 禁止当 OEC | Hero 静态数字、全历史成功率、单任务质量分、扫描成功次数、技能平均分、渠道 24h 事件数、LLM 调用成功次数、listed 资产数 |
| Q-VOICE | 未关前不得假设观察窗内核心动作会改成订阅。改核心动作走变更流程，**禁止双北极星** |

Hero `128,000+` / `12 节点` / `3.2 亿条` **禁止当基线、禁止当四周数字**。

## 2. 北极星（唯一）

| 字段 | 内容 |
|---|---|
| 名称 | 周活跃完成租户数（WACT） |
| 口径 | 一个上海自然周内，至少发生 1 次 **核心动作** 的企业去重数 |
| 核心动作（默认） | 采集任务进入 completed **且** result_count>0。排除 `is_marketplace_candidate=true` |
| 核心动作（待 Q-VOICE） | 若对外第一句改为能力市场优先：用变更流程把核心动作改为「订阅成功」。**禁止同时两个北极星**。**禁止**「任务∨订阅∨LLM」 |
| 来源 | 事件 `task_completed`（FR-15：`tenant_id`、`result_count`、`spider`、`source`、布尔 `is_marketplace_candidate`） |
| 时间窗 | 上海周一 00:00 至周日 24:00，事件发生时间 |
| 目标值 | 建立基线。四周结束必须能报「这四周每周 WACT=？」；报不出 = 埋点 FR 失败 |

选「企业完成一次能交差的采集」，因为这是今天离用户价值最近、且 Wave 0 已把最小出数环纳入冻结集的动作。市场订阅是驱动，避免「订了很多从未出数」算成功——除非操作者用 Q-VOICE 改主叙事。

混淆：WACT=0 可能是没人来 / 没登录 / **工人未运行**（FR-18）。驱动指标拆开看，不得把工人空洞解释成「获客失败」。

## 3. 驱动指标（4 个）

### D1 注册成功数

| 字段 | 内容 |
|---|---|
| 口径 | 一周内 `tenant_signup_succeeded` 次数（按次，不去重个人邮箱） |
| 来源 | FR-15 |
| 时间窗 | 上海自然周，事件时间 |
| 目标 | 建基线 |
| 诊断 | WACT=0 且注册=0 → 获客句；注册>0 → 断在登录或出数 |

### D2 注册后 168h 首次登录率

| 字段 | 内容 |
|---|---|
| 口径 | 分子：该周注册企业中，注册时刻起 168h 内至少一次 `login_succeeded` 的去重企业。分母：该周注册成功企业 |
| 来源 | FR-15；登录必须能关联企业 |
| 时间窗 | 每企从注册起滚动 168h |
| 目标 | 建基线。修好成功页后此率应从「几乎无法发生」变为可观测——不设百分比 |
| 诊断 | 分母有、分子无 = 仍停在 FR-04 |

### D3 TTFV（注册 → 首次出数）

| 字段 | 内容 |
|---|---|
| 口径 | 对已发生首次 **`is_marketplace_candidate=false` 且 `result_count>0`** 的 `task_completed` 的企业：该次 − 注册成功的 **中位数**。候选不构成首次出数 |
| 来源 | FR-15 |
| 时间窗 | 四周窗内完成首次出数者；未出数 **不进中位数分母**（另报「四周仍未出数的注册企业数」） |
| 目标 | 建基线 |
| 诊断 | 登录率高但未出数人数高 = 工人/配额/向导前置（**FR-18/19/12**，不是后波 stub） |

**相对 grok-files 度量稿：不回退。** 不得把 TTFV 定义成「首次任意 `task_completed`」。

### D4 周订阅成功租户数

| 字段 | 内容 |
|---|---|
| 口径 | 自然周内至少一次 `market_subscribe_succeeded` 的企业去重 |
| 来源 | FR-43 |
| 时间窗 | 上海自然周 |
| 目标 | Wave 1 对用户可用后建基线 |
| 诊断 | 列表浏览高、订阅 0 = 预告太多、许可闸、或登录回跳失败 |

## 4. 护栏指标

| 指标 | 口径 | 红线 | 来源 | 超线 |
|---|---|---|---|---|
| 跨租户可见事故 | 经复现确认：企业 A 读到 B 的任务/结果/安装/成员；含出站钥匙混拉两家企业行（GWT-13.3） | **0** | 越权审计 + 手工复现 | 停发布，先修隔离 |
| 公开泄漏未上架/黑名单/未放行许可 | 抽检公开列表/详情出现上述资产 | **0** | 对账 + FR-33 | 关公开市场或回滚上架 |
| 同窗口任务失败率 | 失败 /（完成+失败）；窗口与「近 7 日结果」相同；排除候选 | 相对基线 **上升 10 个百分点**。第一轮无基线：只记录同窗口周失败率，**不停在空算的 +10** | 任务状态（须与 FR-16 同一窗口） | 有基线后超线则停止市场大推与采集对外承诺 |
| 非超管改渠道或平台 LLM 成功 | 成功写次数 | **0** | 审计 | 视为 Wave 0 未完成 |
| Wave L 完成后平台路径仍依赖 new-api 运行时 | 平台路径规划/评分仍打到 new-api 进程 | **0**（Wave L 完成后） | FR-72 | 视为 Wave L 未完成 |

| 公开页失败装空 | 首页精选或市场列表把加载失败渲染成「暂无/还没有」 | 抽检 **0 次** | FR-01.4、FR-31.4 | 阻止发布 |

## 5. 埋点契约（事件名冻结）

字段最低集：`occurred_at`、`anonymous_id` **或** 已登录的 `tenant_id`/`user_id`、`role`（若已登录）。

存储：可按 `event_name` + 发生时间查询的产品事实。失败不挡主路径。v1 **至少一次**（不要求精确一次键）。保留 ≥90 天。不混审计日志、不混站内通知、不上外部分析 SDK、不进数仓（本程序 N/A）。

切日：存 UTC、报表日 Asia/Shanghai。

| 事件 | 何时 | 关键字段 | 对应 FR | 查询面 GWT |
|---|---|---|---|---|
| `official_page_viewed` | 打开首页/定价/市场/注册 | `page` | FR-15 | GWT-15.9 |
| `official_cta_clicked` | 点主按钮 | `cta`：`register_free` / `pricing_pro` / `pricing_enterprise` / `login` / `browse_market` **分档不得合并**，五档各一格。首页「体验 AI 采集流程」「进入管理后台」**不在**这五档内，另报，不得塞进 F1 分母 | FR-15 | GWT-15.6 / 15.15 / 15.16 / 15.17 / 15.18；旁路 GWT-15.7 / 15.19 |
| `tenant_signup_succeeded` | 企业开通成功 | `tenant_id`；先逛再注册 **必须**带与浏览事件相同的匿名身份（无「若有」）。无浏览会话的注册只计数、不进 F1 分母 | FR-15 | GWT-15.5 / GWT-15.14 |

## 7. 漏斗

### F1 激活（官网 → 第一次出数）

- 不允许把「直接打开后台登录」算进官网漏斗分母（另报）。
- 不允许把「体验 AI 采集流程」算进 F1 分母（另报）。
- 不允许把无浏览会话的注册算进 F1 分母（只计数，进 D1）。
- 回退再前进：按企业取 **首次** 到达该步的时间。
- 步间时间窗：168h。

步骤：曝光 → CTA → 注册成功 → 首次登录 → 首次提交任务 → 首次 `is_marketplace_candidate=false` 且 `result_count>0` 的 `task_completed`。

今日除注册行与任务行外全是洞。Wave 0 后应可数——**前提是** 先逛再注册的 signup 带与浏览事件相同的匿名身份，且 FR-18 使出数可能发生。

### F3 市场（浏览 → 订阅）

步骤：list_viewed → search（可选）→ detail_viewed → subscribe_succeeded。预告项上提交订阅被拒进 `rejected`，原因字面量 `coming_soon`。Wave 1 前不可测。预告分母必须切开，不得把预告浏览当「可订曝光」。
