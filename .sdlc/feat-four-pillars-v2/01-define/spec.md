## 1. 背景与问题定义

四套 Working Backwards。③ 是用户能 **做** 的事。

### 1.1 柱 A · 智能采集

**谁**：租户里要把指定网页变成表格的采集经办（operator），不是「会写爬虫的人」。

**现在什么情况**：官网说「粘贴链接交给 AI」；后台有任务、向导、结果与 CSV。注册成功没有登录出口。调度/模板/AI 试采入队不带企业；结果回流常变成无主行（真库拒写或租户看不见）。根编排没有采集工人时任务一直等待，屏上不拦。零条目任务不会收尾。官网卖 Excel，实现拒 xlsx。市场候选与租户成果同表，配额把候选算进去。无生产工单（ops：0 张）。

**期望什么结果**：「我注册完能进后台，贴一个地址，最后在本企业结果里看到条数并能导出我打得开的文件。如果现在跑不起来，页面要告诉我卡在工人还是配额，而不是假装在爬。」

**凭什么说改善了**：注册后能登录；一次合格出数（完成且条数>0，且不是市场候选）可被事件计数。WACT / TTFV 能报出数字。本轮先建立基线。

### 1.2 柱 B · SaaS

**谁**：开通企业空间的负责人（owner），以及被邀请的成员。

**现在什么情况**：免费注册、成员、用量条、手改配额都在。定价印着 ¥299、工单支持、渠道组、私有技能库；升级按钮去再注册。月度 token 数字不挡真正打模型的动作。用量页泄漏内部错误码。到期状态写了但登录不执法。公司管理员与平台超管在写面上被当成同一类。

**期望什么结果**：「我知道自己是哪一档、用了多少、满了点哪里。公司管理员管不了全站渠道和平台模型。到期之后进不来。」

**凭什么说改善了**：配额拒绝可计数且带维度；注册→登录不再断链；非超管改渠道/平台模型成功次数 = 0。

### 1.3 柱 C · 中转站

**谁**：平台值班（平台超管）；以及走平台路径规划/评分的采集经办。

**现在什么情况**：值班页有总览/探针/窗口。官网零入口。企业档却写「渠道组」。租户公司管理员能进写面。规划走本企业或平台供应商，与值班页不是同一条运行时。是否把中转当 **租户可买 SKU** **操作者未决**（Q-RELAY）。操作者已决：平台 LLM 数据面改走 LiteLLM Proxy，new-api 退出运行时。

**期望什么结果**：「我做规划/评分走平台路径时，请求进平台 LLM 网关；我自己配的供应商仍直连。值班打开页能看出网关侧模型，分得清『还没配』和『网关挂了』。new-api 不再作为运行时。公司管理员改不了窗口。没拍板之前，定价不能假装已经卖渠道组。」

**凭什么说改善了**：非超管渠道写成功 = 0；租户直打渠道页与「页面不存在」同形；平台路径规划不再经过 new-api 进程；网关挂的文案不是套餐超限句。

### 1.4 柱 D · 能力市场

**谁**：三件不同的事，不得合成一种「用户」——① 匿名访客逛已上架能力；② 已登录租户把 **某一行** 订到某个宿主；③ 平台超管管源、上架、许可。宿主里的 Agent 使用者通过说明自己启用；平台不代改本机配置（D21）。

**现在什么情况**：P6 目录能扫能验；技能广场能搜能打开正文；能力广场四 Tab、卡不可点、仍叫「专家」、没有命令。无上架态、无订阅、无「我的安装」。CONTEXT 已五类平级；页面未迁。无用户原声「我想安装」——本柱进冻结集是因为 D10 已决一期必须，且现商店面零动作则市场不成立。

**期望什么结果**：「我搜短名能找到。预告只能看不能订。已上架且过许可的，登录后能把这一行订到 Grok / ZCode / Kimi / Claude 之一或多个（每宿主一行）。订插件不会把里面的技能一并订上。商店里没了的，我已经订过的还能在『我的安装』里卸掉。」

**凭什么说改善了**：周去重订阅成功企业可计数；公开列表不出现未上架/黑名单/未放行许可（护栏事故 = 0）。

#### FR-07 租户壳：平台专属页隐藏，直打与「页面不存在」同形

#### FR-12 套餐数字是真闸；拒绝可理解

### Wave L — LLM 数据面切换（冻结）

插在 Wave 0 之后。**不晚于** Wave 1 市场评分开始依赖稳定的平台路径规划/评分。**禁止**写成 Wave 3 / FR-60 stub。**禁止**长期双通道当产品卖点（切换窗允许短双跑作回滚件；切完 new-api 进程停止）。

### Wave 1 — 能力市场（冻结）

会话落点（已冻结，可被变更流程推翻）：**逛市场在官网（可无登录）；订阅与「我的安装」在后台（已有登录）。** 未登录点订阅 → 去登录再回来，回来时尚未订（GWT-32.6 / GWT-32.7）。不要为了「按钮在官网」再造一套官网登录。

**商店不存在句（QA-01 GET 详情 oracle；QA-21 收窄）：** 只约束 **打开公开详情**（GWT-32.3 / 33.3 / 36.3）。未上架或黑名单的公开详情，对外与 **同站真 404** 字节级同形。官网真 404 文案为「页面不存在，可能已被移除或地址有误」。**禁止**出现「已下架」「或已下架」。预告不是本句：预告可见、无订阅按钮（QA-02 / D17）。

#### FR-35 「我的安装」：展示 ≠ 停用

## 3.1 状态流转

### 上架

```
unlisted ──超管上架──> listed ──超管下架──> unlisted
   └──超管标预告──> coming_soon ──上架──> listed
listed ──标预告──> coming_soon
coming_soon ──超管撤回预告──> unlisted

终态：无。黑名单在治理状态，不是上架列。
```

| 流转 | 谁 | 合法？ | 副作用 |
|---|---|---|---|
| → listed（第三方） | 超管 + 二次确认 | 合法 | 商店可见可新订；记下最近一次上架时刻；**下架后该时刻不清空**（GWT-37.6） |
| → coming_soon | 超管 | 合法 | 商店可见不可订 |
| listed → unlisted | 超管 | 合法 | 商店消失、不可新订；已订行保留 |
| coming_soon → unlisted | 超管 | **合法**（预告撤回到未上架） | 商店消失、不可新订；已订行若有则保留 |
| 同步 | 系统 | — | **不得**把第三方标 listed；denylist 插件行保持 unlisted，不连坐子卡 |

**非法（每条一个 Then）：**

| 非法流转 | 期望（状态 / 记录 / 副作用） |
|---|---|
| 租户改上架 | 拒存；上架态不变；无商店变化 |
| 同步自动 listed | 第三方新行保持未上架 |
| **已上架同时黑名单** | **拒存**；上架态与黑名单都保持动作前；**不**在保存时改写成未上架 |
| 已黑名单再标 listed | **拒存**；上架态不变；黑名单仍在 |
| 无 MCP 却因「未验证」禁止 listed | 不允许该拒绝；无 MCP 可 listed（FR-40） |

### 安装行

```
无行 ──订阅成功──> 已订（经办可改启用/信任）
已订 ──卸载──> 无行（可再订，若仍 listed）
已订 + 能力 unlist ──仍已订（标已下架，经办可卸不可再订）
已订 + 黑名单/软删 ──安装行只读（经办可卸、不可改启用/信任）
```

同一能力第二宿主 = **新行**。订/卸不沿合集边走。

**非法：** 只读**角色**订阅或改启用/信任/卸载（任何行，含黑名单行）；预告新订（拒绝；可见故不是商店不存在句）；unlisted/黑名单新订（与订阅从不存在短名相同；无新安装行；无「已下架」；不套商店不存在句）；跨企业改安装行。

### 企业状态

```
active ──到期巡检/运营停用──> expired 或 disabled
expired/disabled ──不得登录、不得用已有会话写
```

**非法：** 到期后继续入队或打模型。

### 任务（出数相关）

合法：pending → running → completed 或 failed。零条目必须离开 running。无工人时不得长时间停在 pending 还显示「正在采集」。

**非法：** 无主入队；结果无主当成功。

此表须与日后 `/dba` 的 db-spec 2.1 一致。不一致以本文为准，但要显式同步。
