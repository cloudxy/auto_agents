# ADR-0016：产品事实落 OLTP 追加表，不建仓

> 状态：**accepted**
> 日期：2026-09-08｜决策者：/architect｜相关：FR-15 / FR-43；metrics-blueprint v1.4

## 背景

仓库无 `metrics.yaml`、无产品事件 SDK、ops 0 工单。WACT 无法报出数字。spec 把数仓分层标为实现面 N/A。architect 只负责事件能否落查询面，不改口径与事件名。

**触发这个决策的约束**：

| 约束 | 来源 |
|---|---|
| 能按 `event_name` + 发生时间查询 | 蓝图 §5 |
| 失败不挡主路径；v1 至少一次 | 蓝图；GWT-15.2 |
| 查询面仅平台超管；租户直打同 404 | QA-09；GWT-15.3 / 43.3 |
| 不混审计日志、不上外部 SDK、不进数仓 | 蓝图；spec §5 |
| 切日：存 UTC、报表日 Asia/Shanghai | FR-16 |

## 决策

新建 **主库追加表**承载产品事实（实体名交 `/dba`）。一行 = 一次事件。字段最低集：`occurred_at`（UTC）、`event_name`、匿名 `anonymous_id` **或** 已登录 `tenant_id`/`user_id`、`role`（若已登录）、蓝图该事件的关键字段。保留 ≥90 天。投递：**至少一次**；v1 **不**要求精确一次键。上报失败吞掉，主路径成功。

查询 API 仅 `require_platform_admin`。租户导航无入口；直打与后台「页面不存在或已被移除」同形。通知类型字符串 `task_completed` **禁止**当本事件。

事件名与 `cta` 五档字面量 **原样**采用蓝图，本 ADR 不改名。先逛再注册：signup **必须**带与浏览相同的 `anonymous_id`（cookie/local 匿名身份，服务端原样写入）。

## 备选与否决理由

### 备选 A：本程序建 ODS/DWD 或 `metrics.yaml`

**否决理由**：warehouse 诊断源未建；禁止第二套口径。蓝图目标是「能判定」，不是提升 x%。

### 备选 B：写 `operation_logs` / 站内通知冒充漏斗

**否决理由**：无匿名访客、无事件名契约、通知 `task_completed` 会污染 WACT。

### 备选 C：上外部分析 SDK

**否决理由**：密钥与出境面；查询面无法保证仅超管；与「至少一次、失败不挡」的本地闸不一致。

### 备选 D：v1 就做精确一次（唯一键 + 幂等表）

**否决理由**：蓝图显式不要求。先让查询面存在。重复计入可在四周复盘手工说明。

## 证据

```
事件名 grep 生产代码 0 命中（定义帽缺口盘点）
operation_logs 无 event_name / anonymous_id
spec §5 数仓 N/A
```

## 代价与风险

| 代价 | 缓解 |
|---|---|
| 至少一次可能重复 | 四周复盘不把重复当增长；下轮再加幂等键 |
| OLTP 表变宽 | 保留 90 天 + 按时间查询；不在本程序做热列宽表分析 |

## 影响范围

| 谁 | 需要做什么 |
|---|---|
| `/dba` | 追加表访问模式：按时间、按企业、按 event_name |
| `/backend` `/frontend` | 蓝图字段即验收；失败不挡 |
| `/qa` | 每个事件一条查询面 GWT（含五档 cta、signup 身份） |
| `/analyst` | 不改口径 |

## 后续复审条件

事件量使主库备份/锁成为问题，或操作者要求精确一次——另开特征，仍不必因此建仓。
