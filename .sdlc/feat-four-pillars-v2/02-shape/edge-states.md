## 通用规则

### Toast vs 内联 vs 全屏

| 严重度 | 用什么 |
|---|---|
| 成功 | Toast 3s，动词与按钮同名 |
| 可恢复操作失败 | 内联，不关弹窗 |
| 页级加载失败 | 内容区替换 +「重试」 |
| 会话失效 | 跳登录，保留 `from`：「登录已过期。重新登录后回到刚才的页面。」 |
| 部分成功 | 警告色 + 数字，不是错误色 |

### 不只靠颜色

错误 ✕、警告 ⚠、成功 ✓、预告「预告」文字角标、正品/伪装/不可用文字+图标。

### 离线（全屏默认句，各屏可收窄）

标题「网络不可用」。说明「现在连不上服务器。已打开的内容仍可阅读；提交、订阅、测试连接、刷新列表会失败。」主按钮「重试」。**禁止**把离线渲染成空列表。

### 未知错误兜底

「加载失败，请稍后重试。」小字「错误编号 {trace_id}」（面向用户，无堆栈）。主按钮「重试」。

### 加载节奏

首次：骨架（形状跟真内容）。刷新：旧内容 opacity 0.6 + 顶细进度，不整页骨架。&lt;200ms 不闪。&gt;10s：「加载较慢」+ 仍可取消/重试。

## 官网首页 `/`

### 加载

静态区立即可画。精选：6 张卡片骨架，不对整页居中 Spin。

### 空

精选 200 且 0 卡：「还没有上架的能力。开通后可在能力市场浏览。」次链「去能力市场」。**禁止**「还没有技能 / 暂无已发布」。无真实聚合则**不渲染**统计区（FR-02）。

### 错误（GWT-01.4）

精选依赖的公开列表不可用：该区块「暂时无法加载能力」+「重试」。其余 Hero/四步/定价入口继续。禁止空白当没货。

### 权限

匿名可看。租户公司管理员寻找「编辑官网卖点」：无入口（GWT-01.5）。已登录看可买集合与匿名相同。

### 边界

无假统计数字。功能介绍导出「单次最多 100 条」。无准确率/认证/正品保证句。无「直连平台网关」「我的中转令牌」。行长 &lt;80 字。精选最多 6 卡。

### 离线

精选走错误句（同上），不得变空。静态区可离线阅读。主 CTA 点击失败：「网络不可用。连接恢复后再注册。」

**测试连接失败（73.4）：** 「连接失败：连的是本企业供应商「{name}」，不是平台网关。{原因或「该行地址无响应」}。检查该行地址与密钥后，再点测试连接。」禁止 71.2 / 74.1 / 套餐句。  
保存失败：弹窗不关 + 内联原因。

### 权限

| 角色 | 表现 |
|---|---|
| 经办 | **能进页**；本企业行「测试连接」「保存」可点 |
| 只读 | 能进；写/测试**不渲染**；「当前账号不能管理供应商。需要经办或企业负责人权限。」 |
| 租户 admin | 同经办（本企业） |
| 非超管 + 平台行 | 无写/无测试连接；激活拒绝「不能改平台级供应商」；行不变 |
| 未登录 | 登录 |

不得 `ProtectedRoute requireAdmin` 把经办挡在门外。不得只靠 HTTP 200 勾 73.4。

### 边界

测试中仅该行 spinner「测试连接中…」。名称超长截断。密钥输入仅掩码回显。网关进程停：保存/测试仍可用。

### 离线

列表错误句。点测试连接：「连接失败：网络不可用，没有测到该行地址。恢复后对「{name}」再点测试连接。」仍是本行语境，不是网关空态。

### 空

### 边界

七叶都在。无「上架全部子资产」。listed_at unlist 不清。无 MCP=未知可上架。第三方上架二次确认。引用列表忽略子行上架、跳过黑名单。

### 离线

同步：「同步没有开始：网络不可用。」列表走加载失败句，不得变「还没有目录项」。
