## 屏 1：LLM 配置 `/llm`

| 项 | 内容 |
|---|---|
| **路由** | `/llm` |
| **进入方式** | 系统管理 → LLM 配置；仪表盘零任务第一步；直打（经办 **不得**被 requireAdmin 挡到 403/登录循环） |
| **主操作** | 管理本企业供应商；对该行做「测试连接」 |

### 关键元素

| 元素 | 说明 |
|---|---|
| 页 h1 | 「LLM 配置」 |
| 本企业行表 | 名称、协议、模型、激活开关、操作 |
| 行操作 | 「测试连接」「编辑」「管理模型」「删除」 |
| 新建 | 「添加供应商」 |
| 平台级行 | 标记「平台」；租户/经办 **不出现** 测试连接/保存/激活 |
| 激活提示 | 有激活行：「当前激活：{name}」；无：「还没有激活的本企业供应商。添加并激活后，规划将直连该行；否则走平台路径。」 |

现网按钮「测试」**必须改名**「测试连接」，与 GWT-73.4 When、成功/失败句同一动词。

现网 Alert「仅管理员可管理供应商」对经办 **作废**。只读才显示「当前账号不能管理供应商。需要经办或企业负责人权限。」

### 交互描述

**进入（73.4 前置，缺一不可）：**

1. 侧栏在经办权限已加载时渲染「LLM 配置」（`menu:llm`）。
2. 路由守卫允许 `operator`（以及租户 admin / 超管）；**不是** `requireAdmin`。
3. 页内 `canOperate` 对经办为真（本企业行）。
4. 该行「测试连接」可见且可点（非 hidden）。

缺第 4 步 = 73.4 未完成（即使 API 测试连接 HTTP 200）。

**「测试连接」按钮：**

| 条件 | 状态 | 文案 | 说明 |
|---|---|---|---|
| 经办/负责人 + 本企业行 + 未在测 | enabled | 「测试连接」 | 点击 = 测该行 `base_url`/密钥，**不**打平台网关 |
| 该行测试中 | disabled + 内部 spinner | 「测试连接中…」 | 仅该行；其它行可点 |
| 只读 | **不渲染**按钮 | — | 旁注见上 |
| 平台级行 + 非超管 | **不渲染**按钮 | — | 73.3 |
| 无本企业行 | — | — | 空态邀请添加；不出现网关空态句 |

**点击后：**

- 成功：Toast「连接成功」；行内 Tag ✓「{latency}ms · {model}」（颜色+图标）。
- 失败：不 Toast 含糊「操作失败」。行内 Tag ✕ + tooltip/内联（与 `edge-states.md` `/llm` 错误态同文，全特征只这一句）：
  - 「连接失败：连的是本企业供应商「{name}」，不是平台网关。{原因或「该行地址无响应」}。检查该行地址与密钥后，再点测试连接。」
- **禁止**失败时出现：「还没有平台模型，去网关登记」「暂无渠道」「平台 LLM 网关不可达」「已达配额上限」。

**保存本企业行（73.1）：** 网关停仍成功。Toast「已保存「{name}」」。

**激活平台级行（73.3）：** 开关不出现或点了内联「不能改平台级供应商」；平台行不变。

**删除：** Popconfirm「确认删除供应商「{name}」？」ok「删除」。

### 交互态（四态）

| 元素 | hover | focus | active | disabled |
|---|---|---|---|---|
| 测试连接 | 链接色加深 | 2px focusRing（键盘可及，73.4 的「点」含键盘激活） | 按下反馈 | 测试中；tooltip「正在测该行地址」 |
| 激活 Switch | — | focusRing | — | 平台行对租户不渲染 |
| 添加供应商 | primaryHover | focusRing | 下沉 | 只读：不渲染 |
| 行 | surfaceRaised | 行外框 | — | — |

### Tab 焦点（页）

```
1. 添加供应商（若有）
2. 筛选控件
3. 表：逐行 激活 → 测试连接 → 编辑 → …
关闭弹窗后焦点回到触发按钮（测试连接或添加）
```

### 离开 / 返回

从编辑弹窗取消：列表筛选与滚动保留。测试结果 Tag 保留到下次测试或刷新。
