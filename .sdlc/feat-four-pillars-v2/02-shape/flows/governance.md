## 各叶要点

**源：** 登记 / 同步 / last_sync / 错误 / jobs。部分失败：12/14 用警告色「同步完成：12 个包成功，2 个失败」；失败在行内；商店不整页骨架。第三方新行不是已上架。`url` 类源提交失败：「此类源尚未支持，没有开始同步。」D16：总开关关或源列表 0 → 行为与今日本机扫描一致，不空成功「已切换到源注册表」。

**目录：** 五类筛选 + listing 三态（未上架/已上架/预告）+ alias + 许可 override。列「出处插件」只读。alias 冲突：「短名「{alias}」已被占用。两边都没有改。」unlist 后 `listed_at` 仍显示。

**插件：** 合集 Drawer：每行「在目录中打开」「单独上架」。无「上架全部子资产」。`dev-team` 行上架失败句「已合并，不可上架」；子行不继承。无 MCP：验证态「未知」，**可以上架**。声明 MCP 但探测失败：「不可用」。验证通过不是法律担保。

**技能 / 命令 / 智能体 / 专家团：** 命令空态「还没有命令。同步源或在目录登记后会出现在这里。」禁止 git 路径。智能体 uses_skill 只读。专家团成员为智能体名；空态「还没有专家团。」主按钮「组建专家团」。

**引用列表（FR-36）：** 超管在智能体/团详情只读「引用」；未上架子技能仍列出；黑名单跳过并可见审计提示。不是租户执行面。

第三方上架：二次确认「将把第三方「{name}」标为已上架，商店会对访客可见。确认上架？」
