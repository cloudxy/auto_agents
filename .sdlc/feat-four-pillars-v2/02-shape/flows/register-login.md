# Flow · 注册成功 → 登录

> 泳道：L4
> FR 锚点：FR-04、FR-08｜作者：/designer｜日期：2026-09-08
> 下游：`/frontend` official Register + admin Login · T-03
> 六态见 `edge-states.md`。

## 屏序列总览

```
/register 填写 ──提交──> 成功屏 ──主按钮「登录管理后台」──> {ADMIN}/login?from=/dashboard
              └──失败──> 留在表单 + 内联错误（无成功屏）
成功屏 ──次按钮「再注册一家」──> /register（清空）
登录页 ──「没有账号？企业注册」──> 官网 /register
到期企业登录 ──> 失败句「企业已到期或停用，请联系平台」（≠ 密码错误）
```

## 屏 1：企业注册 `/register`

| 项 | 内容 |
|---|---|
| **路由** | `/register` |
| **进入方式** | 定价免费档；首页主 CTA；登录页回链 |
| **主操作** | 开通一家企业 |

### 关键元素

| 元素 | 说明 |
|---|---|
| 企业名 / 负责人用户名 / 密码等 | 沿用现字段，不删 |
| 提交 | 「创建企业」；请求中 disabled +「创建中…」 |
| 成功屏 | 替换本页内容，不是新路由 |

### 交互描述

**提交成功：** 进入成功屏。文案含**企业名**与**负责人用户名**（不是空书名号）。Toast「企业已创建」与按钮动词连贯。

**提交失败：** 不出现成功屏；不创建可登录企业。内联「注册未完成：{发生了什么}。改正后再次创建企业。」

**已有企业的只读成员提交：** 失败；**不**暗示其它企业是否存在（通用「注册未完成，请检查填写内容」）。

### Tab 焦点

```
1. 企业名
2. 负责人用户名
3. 密码
4. （其余字段按视觉序）
5. 创建企业
→ 失败后焦点落到第一个错误字段
```

### 交互态

| 元素 | hover | focus | active | disabled |
|---|---|---|---|---|
| 创建企业 | primaryHover | focusRing | 下沉 | 提交中；空必填时旁注「请填写企业名」 |

## 屏 2：注册成功（同路由）

| 项 | 内容 |
|---|---|
| **形态** | 成功结果，非表单 |
| **主操作** | 去登录 |

| 元素 | 说明 |
|---|---|
| 主按钮 | 「登录管理后台」→ `{ADMIN_URL}/login?from=/dashboard` |
| 次按钮 | 「再注册一家」→ `/register` |
| 正文 | 「企业「{name}」已开通，负责人 {username}。登录后开始采集。」 |

禁止主按钮再指向 `/register`。禁止 Toast 写「即可登录」而屏上不能登录。

### Tab 焦点

```
1. 登录管理后台
2. 再注册一家
```

## 屏 3：后台登录 `/login`

| 项 | 内容 |
|---|---|
| **路由** | `{ADMIN}/login?from=` |
| **进入方式** | 成功屏主按钮；官网次 CTA；会话过期拦截 |
| **主操作** | 登录进入 `from` 或 `/dashboard` |

### 关键元素

| 元素 | 说明 |
|---|---|
| 用户名 / 密码 | |
| 主按钮 | 「登录」；成功后去 `from`（须站内相对 path，防开放重定向） |
| 页脚 | 「没有账号？企业注册」→ 官网 `/register` |
| 视觉 | 不用紫渐变；`surface` + `primary` |

### 错误分流（禁止同一句）

| 原因 | 文案 | 下一步 |
|---|---|---|
| 凭证错误 | 「用户名或密码不正确。核对后再登录。」 | 留在表单 |
| 企业到期/停用 | 「企业已到期或停用，请联系平台。」 | 无「再注册」冒充解锁 |
| 网络 | 「登录请求失败，检查网络后重试。」 | 「重试」 |

会话过期拦截：保留 `from`，文案「登录已过期。重新登录后回到刚才的页面。」

### Tab 焦点

```
1. 用户名  2. 密码  3. 登录  4. 企业注册链接
```
