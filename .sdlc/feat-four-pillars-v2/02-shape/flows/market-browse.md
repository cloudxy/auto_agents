## 屏序列总览

```
导航「能力市场」 /capabilities?type=&q=&host=&category=&page=
  /skills → 同页且 type=skill
  非法 type=bogus → 筛选失败「没有这种类型」，不得出技能列表
  卡（真链接）──> /capabilities/:type/:slug
       ├─ 已上架：说明/许可/来源/宿主/包含；登录「订阅」
       ├─ 预告：大标「预告」；**无订阅按钮**
       └─ 未上架/黑名单：官网 404 同形（无「已下架」）
未登录点订阅 → {ADMIN}/login?from=… 回详情后仍未订
```

## 屏 1：列表 `/capabilities`

| 项 | 内容 |
|---|---|
| **进入** | 导航唯一能力入口「能力市场」；首页精选；`/skills` |
| **主操作** | 按五类/短名找到卡并打开详情 |

### 关键元素

| 元素 | 说明 |
|---|---|
| 类型 | 全部 + 技能 / 插件 / 命令 / 智能体 / 专家团。无「专家」 |
| 搜索 | 展示名或 origin 短名；筛进 URL |
| 宿主 / 分类 | 可选；进 URL |
| 卡片标题 | 展示名或短名；**禁止** `mattpocock-skills__code-review` 当 H |
| 预告卡 | 角标「预告」；**无订阅按钮**（禁止 disabled「尚未上架」冒充预告） |
| 分页 | 默认 20，最大 50；`total` = 仅可见行；无「还有下一页」当第 2 页空 |

### 交互描述

筛选变化 → 重拉 + URL 同步 + 回到第 1 页。返回详情后恢复 q/type/page/滚动。

非法类型：校验失败文案「没有这种类型。请选择技能、插件、命令、智能体或专家团。」**不得**展示技能列表当作成功。

### 交互态

| 元素 | hover | focus | active | disabled |
|---|---|---|---|---|
| 卡片 | 边框 `borderStrong`，不抬起 | 可见环 | — | — |
| 类型 chip | surfaceRaised | focusRing | — | 非法值不作为可选项 |
| 清除筛选 | primaryHover | focusRing | 下沉 | 无筛选时不出现 |

空/错见 edge-states（目录空 ≠ 筛选空 ≠ 失败）。

## 屏 2：详情 `/capabilities/:type/:slug`

| 项 | 内容 |
|---|---|
| **进入** | 卡片真链接；alias 与目录短名同一行 |
| **主操作** | 读说明；已上架则去订阅 |

### 关键元素

| 元素 | 说明 |
|---|---|
| 标题 | 展示名 |
| 预告大标 | 预告项必须有；**无订阅按钮** |
| 订阅 | 仅已上架。未登录：按钮「登录后订阅」。已登录经办：「订阅」 |
| 正文 | `<pre>` 纯文本；脚本当文本；无 script 节点 |
| 包含 | 仅 FR-33 可见子卡；黑名单/软删永不出现 |
| 出处 | 父插件已上架 → 链接；否则纯文本署名 |
| 折叠 | 「订阅不等于已在宿主运行」+ 说明片段；**无**「启用到宿主」 |
| 禁止句 | 「安装此插件将获得全部技能」「已在你的宿主里运行」 |

### 未登录订阅

点「登录后订阅」→ 后台登录带 `from`（详情 path 或 installs）。回官网详情后安装行仍 0，须再点「订阅」。

### Tab 焦点（详情）

```
1. 返回市场  2. 出处链接（若有）  3. 包含子卡链接  4. 订阅或登录后订阅
正文 pre 可 Tab 进入以便复制，不执行 HTML。
```

### 交互态

| 元素 | hover | focus | active | disabled |
|---|---|---|---|---|
| 订阅 | primaryHover | focusRing | 下沉 | 只读：旁注见 subscribe flow |
| 预告（无按钮） | — | — | — | 不渲染订阅控件 |
| 子卡链接 | 下划线 | focusRing | — | 未上架子卡不出现 |
