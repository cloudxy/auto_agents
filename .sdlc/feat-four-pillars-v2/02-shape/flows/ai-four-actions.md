## 失败句矩阵（产品可见；code 判断禁止用 message 分支）

同一用户动作只有一句 Then。套餐闸在成功路径前。

| Given（摘要） | 规划 / 试采 / 评分 看见 |
|---|---|
| 无本企业激活行 + 网关有模型 + token 未尽 | 成功结果（outbound 网关；UI 不写「已进入 LiteLLM」） |
| 无本企业行 + 网关可达 + **0 模型** | **「还没有平台模型」** +「去 LLM 配置添加本企业供应商，或等平台登记模型后重试。」不是假装成功，不是套餐句 |
| 无本企业行 + **网关不可达** + token 未尽 | **「平台 LLM 网关不可达」** +「稍后重试，或添加并激活本企业供应商后直连。」无 `QUOTA_EXCEEDED` |
| 有本企业激活行（网关在或停） | 走该行；失败 = **该行自己的失败句**：「本企业供应商「{name}」调用失败。{原因}。去 LLM 配置检查该行或点测试连接。」**不是** 74.1，**不是** 71.2，**不是**套餐句 |
| token 已满（无论网关） | **「已达配额上限」** +「申请提升配额」 |
| 套餐未尽但成本熔断 | **不是**套餐那句。用「平台模型成本保护已触发。稍后重试或联系平台。」 |

禁止：空模型句与网关不可达句互勾；BYOK 失败勾 74.1；HTTP 200 空 clusters 当成功。
