## 屏序列总览

```
访客打开 /
  ├─ Hero（无假统计）──主CTA──> /register
  │                    └──次CTA──> {ADMIN}/login
  ├─ 四步序列（真序列）
  ├─ 能力精选 ──真卡──> /capabilities/:type/:slug
  │              └──失败──> 区块失败态（其余静态仍在）
  └─ 定价 /pricing
           ├─ 免费主按钮 ──> /register     cta=register_free
           ├─ 专业主按钮 ──> 页内「预告不可购买」  cta=pricing_pro
           └─ 企业主按钮 ──> 页内「预告不可购买」  cta=pricing_enterprise
```

禁止：三档都进 `/register`；「联系升级」实际去免费注册；Hero `128,000+` / `12 节点` / `3.2 亿条`；Excel 写成当前可买；「直连平台网关」「我的中转令牌」「我的渠道组」当前可买。

## 屏 1：首页 `/`

| 项 | 内容 |
|---|---|
| **路由** | `/` |
| **进入方式** | 导航「首页」；深链 |
| **主操作** | 判断现在能完成的采集控制面，决定注册或登录 |

### 关键元素

| 元素 | 说明 |
|---|---|
| Hero 一句 | 当前能演示的采集控制面（粘贴链接 / 任务 / 结果）。**不**选定对外第一句品牌口号的替换文案；只删空头 |
| 主 CTA | 「免费注册」→ `/register` |
| 次 CTA | 「登录管理后台」→ `{ADMIN_URL}/login`（`cta=login`） |
| 旁路锚点 | 「体验 AI 采集流程」只滚到四步；**另报、不进 F1**；不得记为五档 cta |
| 四步 01–04 | 真序列，允许编号；入场动效只播一次；`prefers-reduced-motion` 则静止 |
| 能力精选 | 最多 6 张真卡；标题=展示名或短名；预告角标；真链接；失败见 edge-states |
| 功能介绍 | 导出只写 CSV 或 JSON +「单次最多 100 条」；成员/用量若出现则后台能做完 |

### 交互描述

**主 CTA「免费注册」**：始终 enabled。按下 = 去注册。

**次 CTA「登录管理后台」**：始终 enabled。按下 = 去后台登录。不是唯一主承诺（Q-MARKET-USER 未关）。

**能力精选卡**：

| 条件 | 行为 |
|---|---|
| 已上架 | 真链接进详情；无「订阅」按钮在首页卡上（避免未登录误订） |
| 预告 | 角标「预告」；可进详情；无订阅按钮 |
| 列表 5xx / 离线 / catch | **禁止**空白当没货。标题仍在。文案「暂时无法加载能力」+ 主按钮「重试」 |

**禁止句（GWT-01.6）：** 抽取准确率、AI 评分已校准、插件官方认证、渠道正品保证。

**禁止句（GWT-70.4 本票）：** 「直连平台网关」「我的中转令牌」。

### 交互态（四态）

| 元素 | hover | focus | active | disabled |
|---|---|---|---|---|
| 主 CTA | `primaryHover` | 2px `focusRing` | 轻微下沉 | — |
| 次 CTA | 边框 `borderStrong` | 同 focusRing | — | — |
| 精选卡 | 边框变 `borderStrong`，**不**整卡抬起 | 可见环 | — | — |
| 重试 | 同主按钮 | 同 | 同 | 请求中：内部 spinner「重试中…」 |

### 离开 / 返回

离开注册或详情后返回：滚动位置尽量保留；精选按 URL 无状态则重新拉。失败态在重试成功前保持失败，不偷偷变空。

## 屏 2：定价 `/pricing`

| 项 | 内容 |
|---|---|
| **路由** | `/pricing` |
| **进入方式** | 导航「定价」 |
| **主操作** | 看清免费档能走完；付费档知道现在买不到 |

### 关键元素

| 元素 | 说明 |
|---|---|
| 免费档数字 | 并发 5 / 存储 10,000 条 / 月度 20 万 tokens，与用量页三数一致，不以预告出现 |
| 免费主按钮 | 「免费注册」→ `/register` |
| 专业 / 企业主按钮 | 「预告不可购买」；**href 不是** `/register` |
| 闭集 B | 工单支持 / 中转站渠道组分配 / 私有技能库 / 专属客户成功：删除或标「预告」；所在档主按钮仍不得是免费注册 |
| ¥299 / 定制 | 不得写成「现在就能买到并开通」 |
| 页内说明 | 点付费主按钮后展开：标题「预告不可购买」；说明「该档尚未开通购买。」；次操作 mailto「联系平台」（不到注册） |

已登录租户看定价：「当前可买」集合与匿名相同。专业档仍不到「再开一家免费企业」。

### Tab 焦点（付费说明展开后）

```
1. 关闭
2. mailto「联系平台」
3. 知道了（关闭）
→ Esc 关闭 → 焦点回到刚点的档位主按钮
```

### 交互态

| 元素 | hover | focus | active | disabled |
|---|---|---|---|---|
| 免费注册 | primaryHover | focusRing | 下沉 | — |
| 预告不可购买 | surfaceRaised | focusRing | — | —（这是主按钮，不是 disabled 假装预告） |

预告卖点用角标，**不要**用禁用主按钮冒充预告。
