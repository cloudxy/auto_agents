## 屏序列总览

```
经办 /spiders/tasks ──提交──> 有工人：等待终态 ≤120s → 完成且条数>0 → 结果抽屉导出 CSV/JSON
                      └──无工人：拦住或立即「采集未运行，不会出数」
0 条收尾：离开运行中，说明「完成，0 条」
数据中心：只本企业非候选；「还没有采集结果」≠ 列出候选
用量：上海月；≥90% 警告；满「已达配额上限」+ 申请提升（不到注册）
```

## 屏 1：采集任务 `/spiders/tasks`

| 项 | 内容 |
|---|---|
| **进入** | 数据工厂 → 采集任务 |
| **主操作** | 提交并看到出数或被拦住 |

### 提交

| 条件 | 行为 |
|---|---|
| 经办 + 企业有效 + 有在线工人 | 入队；任务出现在本企业列表 |
| 无在线工人 | **阻止提交**或提交后立即可见：「采集未运行，不会出数。查看节点或联系值班。」主按钮「查看节点」→ `/spiders/nodes`。不得长时间「正在采集」 |
| 只读 | 提交禁用 +「当前账号不能提交采集」 |
| 超管无企业 | 拒绝入队：「需要企业空间才能提交采集」 |
| 无企业身份 | 不入队，说明原因 |

新建任务弹窗 Tab：关闭 → 类型 → 爬虫 → 参数 → 取消 → 提交。Esc。关闭后焦点回「新增任务」。返回保留筛选/页码/滚动。

运行中禁删：disabled + tooltip「运行中的任务不能删除」。

### 空态两种

| 类型 | 文案 | 操作 |
|---|---|---|
| 无筛选且 0 任务 | 「还没有采集任务。新增任务或去采集向导创建一个。」 | 「新增任务」 |
| 有筛选且 0 | 「没有符合条件的任务」列出筛选 | 「清除筛选」 |

禁止默认空表无文案。禁止筛选空 = 真没有 同一句。

## 屏 2：结果抽屉 / 数据中心导出

| 项 | 内容 |
|---|---|
| **路由** | 任务抽屉；`/data` |
| **主操作** | 导出打得开的文件 |

### 导出

| 条件 | 行为 |
|---|---|
| 30 条非候选 | 格式仅列出 CSV 和/或已有 JSON；得到 30 行 |
| 0 条 | 「没有可导出的结果」；**不**下载空文件；按钮 disabled + 该旁注 |
| 120 条 | 最多 100 条；按钮旁**始终可见**「单次最多 100 条」 |
| 跨企业猜 ID | 与「没有这个任务」同形 |

数据中心：只有候选、没有自己的条 → 「还没有采集结果。完成一次采集后会显示在这里。」主按钮「去采集」。**不**列出候选。

## 屏 3：节点 `/spiders/nodes`

工人掉线且任务无终态满 120 秒：任务/节点上可见「采集工人不在线」，不是无限「运行中」无解释。

空：说明心跳含义 +「没有在线节点时不能出数」。

## 屏 4：用量 `/usage`

| 项 | 内容 |
|---|---|
| **进入** | 概览 → 用量看板（tenantOnly） |
| **主操作** | 看三档进度与满额下一步 |

| 条件 | 文案 |
|---|---|
| 从未用过 | 「还没有用量。完成第一次采集后这里会显示配额进度。」「去采集」 |
| 70–89% | 「已用 {p}%」+ 维度名 |
| ≥90% 未满 | 「接近上限。超额操作会被拒绝。」无内部码 |
| token 满 | 「已达配额上限」+ 主按钮「申请提升配额」→ 联系说明，**不到** `/register` |
| 存储满 | 「已达配额上限」+「去结果库」→ `/data`，不到注册 |
| 只读 | 可见进度；无改套餐 |
| 超管无企业 | 「用量属于企业空间」，**不是**「暂无用量数据」 |
| 本月 | 按 Asia/Shanghai 日历月 |

页上禁止渲染 `QUOTA_EXCEEDED` / 裸 `429`。

打模型被套餐闸拒（规划页）：同一套餐句，见 `ai-four-actions.md`。成本熔断 ≠ 套餐句。

### Tab 焦点（申请提升说明）

```
关闭 → mailto/说明链接 → 知道了
Esc → 焦点回「申请提升配额」
```
