> 泳道：L4
> FR 锚点：FR-06、FR-07、FR-17、FR-11.3、FR-15.3｜作者：/designer｜日期：2026-09-08
> 下游：admin 菜单 / ProtectedRoute / 404 · T-05 · ADR-0017
> **不**重排五组；**不**修 `/enterprise` `/rbac`。

## 屏序列总览

```
登录成功
  → 权限未知：顶栏/侧栏「权限加载中」或上次读叶；禁止平台写叶、禁止整站空白
  → 权限已加载：
        租户经办/公司管理员
          导航无：中转站管控、平台运营台、用户管理、源与上架写
          有：仪表盘、数据工厂、用量、成员、我的安装、LLM 配置
          直打 /newapi /platform-ops /users / 源上架写地址
            → 后台 404 同形（无渠道列表、无密钥、无「抱歉您没有权限」）
        平台超管
          上述平台叶可见；值班打得开
仪表盘零任务引导 ──第一步──> /llm 或采集向导（禁止 /newapi）
```

## 屏 1：应用壳（所有后台页）

| 项 | 内容 |
|---|---|
| **路由** | 布局 `/` |
| **进入方式** | 登录后 |
| **主操作** | 按任务找叶，不被教「进页再换 IA」 |

### 关键元素

| 元素 | 说明 |
|---|---|
| 五组 Sider | 组名/顺序冻结 |
| 叶过滤 | `is_platform_admin`；`tenantOnly` 滤到**叶子** |
| 权限加载中 | 侧栏骨架或文案「权限加载中」；读叶可保留 |

### 隐藏 vs 禁用（平台专属）

| 场景 | 隐藏还是禁用 | 理由 |
|---|---|---|
| 中转站管控 / 平台运营 / 用户管理 / 源登记 / 上架开关 | **隐藏**导航 | 租户不该发现平台值班面；直打 404 防存在性泄漏 |
| `/llm` 对经办 | **显示** | BYOK 是租户能力 |
| `/llm` 平台级行的写控件 | **隐藏**该行写/激活；只读可见「平台」标记 | GWT-06.6 / 73.3 |
| 只读看「订阅」 | **禁用 + 旁注**「当前账号不能订阅，请联系企业管理员」 | 应知道有这功能 |
| 插件验证（租户） | **禁用 +「需要平台管理员」** 或无入口 | 发现性 vs 平台危险操作：验证偏发现性可禁用；源登记/许可放行 **隐藏** |

### 直打

租户公司管理员打开 `/newapi`：

- 渲染后台 `NotFound`：**「页面不存在或已被移除」** + 「返回工作台」
- 网络响应不得带渠道列表或完整 Key
- 不得进 `Unauthorized`「抱歉」

超管打开同一地址：值班页（flow `duty-page.md`）。

### 交互态

| 元素 | hover | focus | active | disabled |
|---|---|---|---|---|
| 菜单叶 | surfaceRaised | 可见环 | — | 权限未知时不可点平台写叶（它们根本不渲染） |
| 返回工作台 | primaryHover | focusRing | 下沉 | — |

## 屏 2：仪表盘零任务引导

| 项 | 内容 |
|---|---|
| **路由** | `/dashboard` |
| **主操作** | 新租户走完第一步 |

步骤顺序（现网可保留三步结构，改目标）：

1. 「配置本企业模型」→ `/llm`（不是中转站）
2. 「创建采集任务」→ `/spiders/tasks` 或向导
3. 「AI 采集规划」→ `/ai`

禁止第一步进 `/newapi`。
