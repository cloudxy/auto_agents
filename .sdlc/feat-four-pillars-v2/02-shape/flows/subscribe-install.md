## 屏序列总览

```
已登录经办在详情点「订阅」──弹窗选宿主──确认「订阅到 {host}」
  ├─ 成功 Toast「已订阅到 {host}」；我的安装 +1 行
  ├─ 已订同一宿主：提示已订阅，行数不变
  ├─ 再订另一宿主：两行都在
  └─ 失败：不关窗
我的安装：启用 / 信任开须确认 / 卸载须确认
  unlist → 行留、标「已下架」、可卸、再订禁用「已下架，不能新订」
  黑名单/软删 → 行留、只读启用/信任、经办仍可卸；不教「还能跑」
  卸插件 → 只掉插件行
```

## 屏 1：订阅弹窗

| 项 | 内容 |
|---|---|
| **形态** | 弹窗（详情页触发；会话在后台时也可从登录回跳后再打开详情） |
| **主操作** | 把**这一行**订到一个宿主 |

### 宿主两态（禁止都叫「空」）

| 名单 | UI |
|---|---|
| **未声明 / 未给出** | 四宿主都可订：Grok / ZCode / Kimi / Claude |
| **已声明且零项** | 四宿主都禁用 + 旁注「该能力未声明支持任何宿主」 |
| **已声明仅含 Kimi** | Kimi enabled；Grok 禁用 +「该能力未声明支持 Grok」 |

不兼容宿主：**提交前**禁用+旁注，不要等 422。

### 进不了 / 拒绝

| 谁 | 文案 | 行 |
|---|---|---|
| 预告 | 详情无按钮；若提交 → 拒绝，无新行 | 0 |
| 只读 | 「当前账号不能订阅，请联系企业管理员」 | 0 |
| 超管无企业 | 「需要企业空间才能订阅」 | 0 |
| 未上架/黑名单/从不存在短名 | 与从不存在相同；无「已下架」 | 0 |
| 三类配额已满 | **仍允许订阅**；用量三数不增加 | +1 |

订插件：只 + 插件一行，不多子技能/命令/智能体。禁止礼包句。

成功说明可折叠「订阅不等于已在宿主运行」+ 片段。无 enable-host。不写「已写入 ~/.zcode」。

失败不关窗、保留宿主选择。确认按钮：点击后 disabled +「订阅中…」。

### Tab 焦点

```
1. 关闭
2. 宿主列表（方向键；Space 选）
3. 取消
4. 「订阅到 {host}」
→ 锁焦 → Esc=取消 → 焦点回详情「订阅」
```

### 交互态

| 元素 | hover | focus | active | disabled |
|---|---|---|---|---|
| 宿主选项 | surfaceRaised | 外环 | — | 不兼容：旁注始终可见 |
| 订阅到 {host} | primaryHover | focusRing | 下沉 | 未选宿主 / 全禁用 / 提交中 |

## 屏 2：我的安装 `/capabilities/installs`

| 项 | 内容 |
|---|---|
| **进入** | 能力资产 → 我的安装（tenantOnly） |
| **主操作** | 看已订行；卸一行 |

按五类分组。列：名称、宿主、上架残留标记、启用、信任、卸载。

| 行态 | 启用/信任 | 卸载 | 再订 |
|---|---|---|---|
| 正常 listed | 可改；信任=开须确认 | 须确认 | 详情可再订其它宿主 |
| unlist「已下架」 | 可改启用/信任 | 经办可卸 | **禁用** +「已下架，不能新订」 |
| 黑名单/软删 | **不可改** | 经办**可以**卸 | 不可再订；不说「还能跑」 |
| 只读角色任何行 | 不可改 | **拒绝**；行不变 | — |

空：「还没有订阅的能力。去能力市场看看已上架的能力。」主按钮「去能力市场」（官网 `/capabilities`）。

卸插件确认：「卸载插件「{name}」在 {host} 的安装？其中的技能不会一并卸载。」

信任=开确认：「打开信任后，按该能力的说明在宿主里使用。平台不会改你的本机配置。」

返回：保留分组折叠与滚动。

无「启用到宿主」按钮。

### Tab 焦点（卸载确认）

```
关闭 → 取消 → 卸载（危险）
Esc=取消 → 焦点回该行「卸载」
```

### 交互态

| 元素 | hover | focus | active | disabled |
|---|---|---|---|---|
| 卸载 | dangerHover | focusRing | 下沉 | 只读角色：tooltip「当前账号不能卸载」 |
| 再订（已下架） | — | 仍可 focus | — | 旁注「已下架，不能新订」 |
| 启用 Switch | — | focusRing | — | 黑名单行 |
