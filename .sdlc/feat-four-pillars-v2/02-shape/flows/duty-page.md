## 屏 1：值班 `/newapi`

| 项 | 内容 |
|---|---|
| **路由** | `/newapi` |
| **进入方式** | 仅超管菜单；直打（租户 → 404 同形，进不了本屏） |
| **主操作** | 看清网关模型，分清没配过 vs 挂了 |

### 关键元素

| 元素 | 说明 |
|---|---|
| 顶栏 Tab | 总览 / 探针 / 事件 |
| 刷新 | 「刷新」 |
| 模型/部署表 | 来自 LiteLLM 侧；列用「模型/部署」不是「渠道」方言当空态主语 |
| 密钥字段 | **仅掩码**或无该列（FR-75.2） |
| 探针 verdict | 文字 **正品 / 伪装 / 不可用** + 图标；禁止「original 正品」中英叠词 |
| 窗口写 | 仅超管；经办 API 拒且列表不变（70.3） |

### 三态（不得互勾）

**A. 正常（71.1）** 管理面可达且已登记模型/部署：

- 表有行；总览数字来自网关；无完整 Key。

**B. 空态（71.2）** 管理面可达、`available=true`、模型 0 行：

- **不是**加载失败，不用错误色整页替换。
- 内容区空态标题：**「还没有平台模型，去网关登记」**
- 说明：「平台 LLM 网关已连通，但还没有登记任何模型。登记后再刷新本页。」
- 主按钮：**「刷新」**（本轮不外链 LiteLLM Admin UI）
- 本地事件/探针区可同时存在。
- locale/emptyText **禁止**「暂无渠道」及 new-api 配置句。

**C. 降级（71.3）** 管理面不可达（HTTP 200 + `available=false`，产品不 500）：

- 页顶 Alert（警告色，非空态插图）：
  - 标题：**「LLM 网关管理面不可达，仅本地事件/探针」**
  - 说明：「现在读不到网关侧模型/部署。下方仍显示本库已有事件与探针。恢复后点刷新。」
- 模型表：**不要**用空态 71.2。表区说明「网关列表暂不可用」，**禁止**「暂无渠道」。
- **本地事件表、探针批次仍渲染**（有数据就列出；本地也空则用「还没有本地探针记录」邀请等下次批次，仍禁止「暂无渠道」）。
- 主按钮「刷新」。

**加载失败（本应用 API 5xx，不是网关管理面）：** 走 edge-states 错误态「值班页加载失败」+ 重试。不得装成 71.2。

### 交互描述

**刷新：** 顶细进度；已有本地数据 opacity 0.6，不变整页骨架。

**改窗口/登记平台上游：** 超管可。经办进不了页；若打 API，产品无成功 Toast。

**伪装：** Tag「伪装」+ 图标；不出现「已自动关闭」。

### 交互态

| 元素 | hover | focus | active | disabled |
|---|---|---|---|---|
| 刷新 | primaryHover | focusRing | 下沉 | 加载中「刷新中…」 |
| Tab | — | 可见环 | — | — |
| 窗口保存 | primaryHover | focusRing | 下沉 | 校验失败旁注 |

### Tab 焦点

```
1. 刷新  2. 总览/探针/事件 Tab  3. 表/Alert 内按钮
七叶不在本页。窄屏 Tab 滚动。
```

### 离开 / 返回

从其它页返回：停在上次 Tab；降级 Alert 在数据刷新前保持。
