**本票做什么**：中转站管控、平台运营台、平台用户管理、市场的源登记与上架开关：租户导航不出现。直打这些地址的结果与「页面不存在」相同（无渠道数据、无密钥、不是道歉式「您没有权限」）。`/llm` **不得**整页当成不存在。空缓存不得全开写面也不得整站空白。登录投影 `is_platform_admin`。

**本票不做什么**：不改值班列表来源/空态句（T-18 / FR-71）；不把 `/llm` 本企业写与 test 改成 `require_operator`（T-17 / SH-09）；不去掉 `ProtectedRoute requireAdmin` 作为经办「点」完成态（T-17 / SH-11）；不改 `channel_id` 类型。

## expand-contract

直打 404 同形是前端路由 + 后端守卫一起：先让租户直打返回与未登录打不存在页相同的壳（无渠道列表、无密钥），再藏导航。禁止先藏菜单而 API 仍 200 带密钥。

## GWT / Then（不得改写成短句）

- GWT-07.1：平台超管打开中转站管控看得到值班页。远端不可达时是降级说明，**禁止**渲染成「暂无渠道」装成没配过。Wave L 后具体降级/空态句见 GWT-71.2 / GWT-71.3（同一动作不得出现第二套相反 Then）。本票只要求超管打得开、不可达时不装成没配过。
- GWT-07.2：租户经办看导航无「中转站管控 / 平台运营台 / 源与上架写」。
- GWT-07.3：租户公司管理员直打中转站地址，所见与未登录打一个不存在页相同：无渠道列表、无密钥、无「抱歉您没有权限」。**渠道 404 无密钥（勿用掩码当 Then）。**
- GWT-07.4：租户公司管理员提交改渠道额度 → 拒绝且额度不变。
- GWT-07.5：新租户仪表盘零任务引导点第一步不到中转站；可到本企业模型页或采集向导。
- GWT-07.6：**行为保持**：探针将某渠道判为伪装，该渠道保持可用、不自动关闭；窗口与额度不变。T-19 换网关调用后本条仍真。
- GWT-17.1：经办权限已加载，导航至少有仪表盘、数据工厂；不得出现中转写 / 平台运营 / 源与上架写。本条不是导航闭集（Wave 1 允许「我的安装」）。
- GWT-17.2：登录后权限缓存尚未就绪，可见「权限加载中」或保留读叶；**不得**整站空白，**不得**露出中转/平台 LLM 写/用户管理/平台运营。
- GWT-17.3：确认无平台写权限时平台写入口不出现。
- **禁止**把 operator 403 写成 `/llm` 写面完成态（经办写与 test 的 `require_operator` 在 T-17）。本票 `/llm` 只保证：租户可进本企业供应商页（不整页 404）；平台行写控件不出现；GWT-06.5 只验企业负责人保存本企业行。
