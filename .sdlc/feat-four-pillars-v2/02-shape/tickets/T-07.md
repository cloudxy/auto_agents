# T-07 · 全部产任务路径带企业；回流归属=入队企业

## FR 锚

| FR | GWT | 覆盖 |

**本票做什么**：定时、模板、向导试采、手工提交：任务必须属于一个企业。没有企业身份则不入队。结果落成「我的结果」时归属等于入队企业。无主结果不得出现在任何租户的结果里。入队显式传 `tenant_id`（017 NOT NULL；禁止候选 NULL）。

**本票不做什么**：不改 Scrapy 管道协议；工人仍看不见企业；不把候选迁表。

## expand-contract

## GWT / Then（不得改写成短句）

- GWT-09.1：经办已登录且企业有效，提交采集 → 任务出现在本企业任务列表。
- GWT-09.2：本企业一条定时规则到期触发，系统入队 → 新任务仍属于该企业。
- GWT-09.3：企业 A 经办用企业 B 的模板触发 → 拒绝；B 不出现新任务。
- GWT-09.4：平台超管无企业空间走租户任务提交 → 拒绝入队，不产生无主任务。
- GWT-10.1：企业 A 的任务跑完且有条数，A 的经办打开结果看得到这些条；企业 B 看不到。
- GWT-10.2：向导试采由企业 A 触发，试采出条在 A，不在别人。
- GWT-10.3：企业 B 按任务编号猜 A 的结果，与「没有这个任务」相同。
- GWT-10.4：回流时找不到入队企业，条到达 → 不写入「我的结果」；任务侧可查失败/死信，不得静默丢给别的企业。
