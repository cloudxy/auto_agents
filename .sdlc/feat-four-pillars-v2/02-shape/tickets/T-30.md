## 边界

**本票做什么**：命令作为五类之一的独立可订卡片；市场筛「命令」出现已上架命令卡并可进详情；无已上架命令时走筛选空态句，**不是**把插件 JSON 当命令货架；未上架命令搜 slash 名不出现。

**本票不做什么**：

- 不把命令做成插件抽屉里的 JSON 列表货架
- 订命令不级联插件/技能（沿用 T-25 一行语义）
- 不砍治理台命令叶（T-28 已锁七叶）
- 不实现 slash 执行引擎
