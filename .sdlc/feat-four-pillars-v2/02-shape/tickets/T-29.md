## Then（合同 v1.6 原文，禁止缩短；**锁 ADR-0012**）

Then（ADR-0012）：bundled slug=`{plugin}__{origin_local_name}`；**不改** `uq_asset_type_name_alive`；两源撞插件名 → 后一次失败、已有行 name 不变；新平台表与 `TENANT_EXEMPT_TABLES` + 夹具同 PR；迁移里禁止 attach 源；纠正对第三方不可用；夹具 `example-pdf-extractor`。

ADR-0012 验收 Then **必须**含（缺一不可）：

1. Catalog `name` **仍**类型内全局唯一。**不改** `uq_asset_type_name_alive`（不加 source、不改列序、不拆键）。
2. **Bundled** 技能 / 命令 / 智能体 slug = `{plugin}__{origin_local_name}`。卡片主标题用展示名或 origin 短名，**禁止**把长前缀当主标题。
3. 两个源产生同一插件目录名：后一次 **失败**（解析失败可见），已有行的 `name` **不变**。禁止静默加源前缀改名。
4. 第一方夹具 `example-pdf-extractor`：无父插件、无第三方源名，商店闸打开后按该短名可搜。源同步挂上源名后按第三方，保持 unlisted 直到超管点头。

插件内字节相同的嵌套副本按 content_hash 折叠为一条。本程序不给 `skills.name` 补 `alive_flag`。

D16：市场总开关关闭或源列表为零项时，扫描行为与 **今日本机插件目录扫描** 一致；不出现「已切换到源注册表」的空成功；不新增冒充已切源的源名。

D5：第三方行（非第一方夹具 `example-pdf-extractor`）上，「纠正」不可用或明确只能写库内；源树文件不变。
