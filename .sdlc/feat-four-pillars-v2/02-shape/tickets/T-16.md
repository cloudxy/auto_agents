## GWT / Then（contract v1.6 §7.2 全文锁；不得回退短句）

### 解析（SH-01 / SH-16 / SH-18）

`LLM.DATA_PLANE=litellm` 时（T-20 完成后默认；本票实现该解析）：

1. `check_llm_tokens_month`（上海月）→ 满则停（FR-12 / GWT-12.3），不得改口成网关故障（GWT-74.2）。
2. 若本企业有激活供应商 → 直连该行（FR-73；本票只保证无自有行不走该支；有自有行四动作在 T-17）。
3. 否则 → **只** LiteLLM `/v1/chat/completions`（FR-70）。
4. **禁止**：平台公共 `llm_providers` 直连、yml/env 直连、手填 new-api URL。
5. 测试观察点 = 捕获 outbound URL + 侧用量，禁止「进入 LiteLLM」空心句。
6. **SH-01**：同 PR 改写 `backend/tests/test_saas_byok.py::test_no_own_key_falls_back_to_platform`：无自有行 → outbound 为网关 URL，**不是** `https://pub`。禁止整文件 `test_saas_byok.py` 当绿闸成员。
7. **SH-16**：`DATA_PLANE=litellm` 时 `_resolve_llm_runtime_config` 的 except **禁止** `resolve_config_from_settings()`（应失败成 74.1 句，或仍解析到网关 URL）。禁止落到 yml/env / `https://pub`。
8. **SH-18**：同 PR 测试必须 **正断言**：resolve 抛错后 outbound **是**网关 URL，**或**该次结果 **只**「平台 LLM 网关不可达」。禁止只做「不是 pub / 不是 yml」。不要把「或」写成 `in{74.1句, 网关URL}` 去勾 70.1 与 74.1 两格。该「或」是 except 路径两个允许实现结果：一张夹具只钉其中一个（outbound=网关 URL 可勾 70.1、不可勾 74.1；该次结果只「平台 LLM 网关不可达」可勾 74.1、不可勾 70.1）。负向「不是 pub / 不是 yml」可作辅证，不得单独过闸。SH-18 正断言仍须同 PR 落地，不得靠整文件 `test_saas_byok.py` 绿闸。

### 失败格（SH-13 保持；SH-15 按 GWT 拆开，禁止无绑定的「或」）

When = 该动作自己的 HTTP；Then = **等到该次结果上出现**与**该格** GWT 同一句。与 §7.2 括号、第四 When 同一写法。**不得互勾。**

- **70.2 / 70.8 / 70.9 Then 只「还没有平台模型」**（空模型；`LLM_GATEWAY_NO_MODEL`）：规划/试采（70.2/70.8）计划 `status=failed` 且 `error_message` **只**该句；评分（70.9）job/响应 **只**该句（`SkillJob status=failed` 的 `detail.reason` 或 `consume_once` 返回的 `error`）。禁止用「平台 LLM 网关不可达」勾这些格。不是假装成功；不是套餐超限句。
- **74.1 / 74.4 / 74.5 Then 只「平台 LLM 网关不可达」**（网关不可达；`LLM_GATEWAY_UNREACHABLE`）：规划/试采（74.1/74.4）计划 `status=failed` 且 `error_message` **只**该句；评分（74.5）job/响应 **只**该句。不是套餐超限那句；无 `QUOTA_EXCEEDED`。不得与 GWT-70.2「还没有平台模型」、GWT-73.6 本企业行失败句、GWT-12.5 熔断句互相勾选。禁止用「还没有平台模型」勾这些格。
