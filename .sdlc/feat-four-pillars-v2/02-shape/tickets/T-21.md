## 边界

**本票做什么**：官网只留一个「能力市场」入口；公开类型五类平级（技能 / 插件 / 命令 / 智能体 / 专家团）；`/skills` 到达已筛技能的市场；非法 `asset_type`（含 `bogus`）筛选失败，不兜成技能；新建 `backend/services/power_market/` 目录包（单体内域，不拆微服务）。

**本票不做什么**：

- 不实现列表分页闸 / 商店不存在句 / 「包含」（T-23）
- 不实现订阅、安装表（T-25）
- 不实现源同步、bundled slug 撞名（T-29）
- 不实现 alias（T-33）
- **不新开评分链**；市场评分只许走 T-16 已钉的 `llm_chat` HTTP
- 不另起市场微服务；不把 LiteLLM 并进根 compose
- 不写安装表 / 源表 / alias 表结构（等 `/dba`；本票只登记本票引入的平台目录表豁免）
- 不代选六问；不新建聊天 UI
