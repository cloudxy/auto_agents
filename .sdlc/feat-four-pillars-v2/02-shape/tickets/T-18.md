## expand-contract（SH-06）

HTTP 与 Redis **用 string `gateway_ref`**（expand：`newapi:channel:cfg:{id}` 双读 → `relay:channel:cfg:{ref}`）。表列 `gateway_ref` **等 `/dba`**，本票禁止改 `channel_id` 类型。配置 **只允许** `NEWAPI.*` 读 + `RELAY.*` 写，禁止第三前缀。禁止一票改类型。

## GWT / Then（不得改写成短句）

- GWT-71.1：平台超管已登录、网关已登记模型/部署，打开值班页 → 看得到来自平台 LLM 网关的模型/部署列表与总览/探针/事件；页上无完整上游 Key（仅掩码或无该字段）。

- GWT-71.3：网关管理面不可达，超管打开值班页 → 降级说明「LLM 网关管理面不可达，仅本地事件/探针」；本地已有事件/探针仍可见；**禁止**「暂无渠道」。HTTP **200** + `available=false`，不 500。
- GWT-71.4：租户公司管理员打开值班页地址 → 走 GWT-07.3（与「页面不存在」同形，无渠道列表、无密钥）。
