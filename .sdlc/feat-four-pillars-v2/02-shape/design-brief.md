## 1. 用户

| 项 | 内容 |
|---|---|
| 主要角色 | ① 匿名访客（判断现在能做什么、逛已上架能力、比价、注册）② 租户经办/负责人（登录、采集出数、本企业模型、订/卸一行）③ 平台超管（七叶治理、值班、产品事实） |
| 熟练度 | 混合：访客/新注册负责人偏新手；经办每天多次采集偏熟练；超管值班熟练 |
| 次要角色 | 租户只读（看任务/用量/已订，不能订不能卸不能提交）；租户公司管理员（管成员与本企业模型，**不是**平台超管） |

**熟练度决定设计策略**：官网空态邀请、注册成功带路；后台高频操作记住筛选/滚动、破坏性确认永不跳过。

## 2. 使用场景

| 项 | 内容 |
|---|---|
| 触发时机 | 访客第一次打开官网；注册当天登录；经办贴链接出数 / 点本企业行「测试连接」；超管打开值班看网关模型 |
| 使用频率 | 官网：每名新访客一次，定价可反复。采集 / `/llm`：每天多次。市场订阅：每周。值班：每日 |
| 设备与环境 | 桌面为主。官网 CTA ≥44px；治理七叶窄屏滚动不删叶。后台表 `size=small` 可保留密度，图标按钮仍给 aria-label |
| 这之前用户在做什么 | 搜索或内部分享；或已在采集任务里失败想换模型 |
| 这之后用户要做什么 | 登录开工 / 导出 CSV·JSON / 订到某个宿主 / 值班登记模型 |

**频率决定点击预算**：测试连接、提交采集、导出 = 一屏内完成；订阅允许弹窗选宿主；治理七叶 1 层顶栏。

## 8. 视觉方向（官网两遍法）

### 8.1 第一遍计划（实现前）

**色彩（命名 hex）**

| 名 | hex | 角色 |
|---|---|---|
| `ink` | `#001529` | 深空底、页脚、Sider；删 `#0b1830` 分叉 |
| `signal` | `#0958d9` | 主操作（semantic primary；AA 白字） |
| `brandBlue` | `#1677ff` | primitive 保留；禁止当小字/按钮字色 |
| `telemetry` | `#006d75` | **只一处**：采集管线节点描边/序号，表示「数据在流动」 |
| `paper` | `#ffffff` | 内容底 |
| `alert` | `#cf1322` | 熔断/错误（白字 AA） |

预告角标走 `primarySubtle` + `onPrimarySubtle`，**不**用 `#13c2c2` 当文字（2.21:1 不合格）。青 `#13c2c2` 仅允许叠在 `ink` 上的非文字装饰，且本轮默认不用（避免簇 2）。

**字体**

系统 / antd 无衬线栈。不上衬线（会滑向簇 1）。层级靠字重与行长 <80 字，不成套 ALL-CAPS 眉标。

**布局概念**

Q-VOICE 前：**一条采集管线**，不要四柱平均用力。

```
[ Hero：一句当前能完成的事 | 主CTA「免费注册」 | 次CTA「登录管理后台」 ]
[ 四步序列 01–04（真序列，入场只播一次） ]
[ 能力市场货架：最多 6 张真卡，预告角标是信息装置；失败=失败态 ]
[ 定价：免费可点注册；专业/企业「预告不可购买」 ]
[ 页脚 CTA 登录开工 ]
```

对齐：货架与定价**左对齐**；Hero **唯一允许居中**。

**原则（三句）**

1. 大胆只花在 Hero 一句，不叠光晕 + 芯片 + 渐变字 + 三列统计。
2. 「预告 / 已上架 / 已下架 / 正品 / 伪装」是信息装置，不是装饰 eyebrow。
3. 后台保持 antd；同一套 semantic 让这些状态跨应用可认。

### 8.2 第二遍对照五个 AI 默认簇

| 簇 | 现网是否命中 | 本轮改什么 |
|---|---|---|
| 1 暖奶油+衬线+赤陶 | 未命中 | 继续不上衬线、不用赤陶 |
| 2 近黑+荧光强调 | 亲戚：Hero `#0b1830` + 青 + infinite glow | 统一 `ink`；关掉 `.hero-glow` infinite（`prefers-reduced-motion` 也停）；青不当事文字 |
| 3 报纸风 | 未命中 | 保持卡片间距，不改细线零圆角 |
| 4 SaaS 卡片套件 | 五张同半径 20、同阴影、hover 统一抬起 | 功能区收成管线节点或删到 ≤3 块；**禁止**整卡抬起；hover 只加深边框 |
| 5 万物皆模板 chrome | ALL-CAPS 眉标、`查看全部 →` | 眉标改中文短标签且仅用于真分类（五类）；链接不加 `→` 后缀 |

自问：「给另一个爬虫 SaaS 会不会画出同样的深空 Hero + 五卡 + ALL-CAPS？」——会。故以上修订是**选择**，不是默认。

后台登录页现网紫渐变（`#667eea–#764ba2`）像另一产品 → 改走 semantic `primary` / `surface`，与官网 ink/signal 同一家族。
