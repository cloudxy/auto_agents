## 2. 关键流程（含焦点顺序）

### 2.1 浏览 → 详情 → 订阅（FR-03/04/05/06）

```
屏 1 货架
├─ 进入：治理壳「货架预览」（超管）/ official（闸开后租户，本轮不动）
├─ 关键元素：分类 tab（全部+五类）· 右上排序组（综合/最热/最新）· 筛选条 · 卡片网格 · 分页
├─ 主操作：点卡片 → 屏 2 抽屉（1 次点击，无页面跳转，URL 不变）
├─ 交互：
│   tab 点击 → 仅改 type 参数，page 重置，已加载卡片保留（半透明 0.6 + 顶部细进度条），不变骨架
│   排序组点击 → 改 sort 参数，行为同上；「最热」无全库计数时服务端回 sort_applied=smart，
│               UI 静默接受（选中态保持「最热」，不显示任何计数数字，不弹提示——GWT-04.4）
│   卡片 hover → 边框 token 主色 + shadow-card 升一档；focus-visible → 2px 主色外环（键盘可达）
│   卡片为 <button role/article> 语义，aria-label「查看 {展示名} 详情」
├─ 离开：抽屉打开 / 跳转治理目录（空态引导）
└─ 返回行为：抽屉关闭后回到原滚动位置与筛选/tab/sort 状态（查询参数驱动，天然恢复）

屏 2 抽屉（右侧，宽 520px；<768px 全宽）
├─ 进入：卡片/治理行单击；焦点移入抽屉（见下）
├─ 主操作：读 md 正文；（闸开且可订阅时）订阅
├─ 交互：
│   CTA 闸关（gate_open=false，含管理员预览态）→ 禁用 + 文案「市场暂未开放，开放后可订阅」，点击无动作
│   示例条目 [复制] → navigator.clipboard + toast「已复制到剪贴板」
│   大文档渲染期 → 正文区 Skeleton（NFR-02，<3s）
│   md 渲染抛错 → 该区降级纯文本，其余区块不受影响（K2）
├─ 离开：× / Esc / 遮罩点击 → 关闭
└─ 返回行为：焦点回到触发的卡片/行；货架状态不变

屏 2 焦点顺序（Tab）：
1. 关闭按钮 ×（aria-label「关闭详情」）
2. 示例区 [复制] 按钮（如有，自上而下）
3. 订阅 CTA（禁用时仍可聚焦——禁用原因由文案本身说明）
→ 焦点锁在抽屉内；Esc 关闭；关闭后焦点回触发元素
```

### 2.2 目录导入三步（FR-07，NFR-U2 ≤3 步）

```
步骤 1 选择来源
├─ 主按钮「选择目录」（webkitdirectory）· 次按钮「选择文件」· 折叠「高级：服务器路径」
├─ 三者互斥（沿用 IMPORT_EXCLUSIVE「文件与目录只能二选一」语义）
├─ 选择目录后本地回显：「已选择：{目录名} · {n} 个文件」+ [重新选择]
│   前端预检 n > 500 → 立即 Alert 拒绝（钉句见 §10），不上传
├─ 浏览器不支持 webkitdirectory → 目录按钮不渲染，服务器路径项直接展开（NFR-08，能力不缺失）
步骤 2 导入预览（上传+解析后）
├─ 类型分组清单：每行 = 类型 Tag + 名称 + [新建|更新] 标注；plugin 行下缩进子行列 bundled
├─ 跳过清单：「已跳过 {n} 个文件」+ 逐条原因（非白名单扩展名/超过大小限制）
├─ [确认导入 {N} 项]（主）/ [取消]（= 不发 confirm，零写入，GWT-07.2）/ [重新选择]
步骤 3 导入结果
├─ 汇总「导入完成：新建 {a} · 更新 {u} · 失败 {f}」；失败逐条中文原因（警告色，非错误色）
└─ [完成]（关闭 + 刷新目录） / [重新选择]
焦点顺序（Modal 内，antd 焦点锁默认）：× → 来源按钮组 → （已选回显的）[重新选择] → 取消 → 开始/确认导入；Esc 关闭（任何步骤关闭都零写入——两段式无状态保证）。
```

### 2.3 同步 .agents（FR-01 治理面入口，T-02）

```
PluginTab「同步 .agents」按钮 → loading（按钮 spinner + 文案「同步中…」，列表不变灰）
├─ 成功 → toast「同步完成：新增 {a} · 更新 {u} · 无变化 {c}」+ 列表刷新
└─ 失败 → toast「同步失败：{原因}。已有数据未受影响。」（后一句是信任修复点：非破坏语义的用户可见承诺）
```

## 4. 屏 1：市场货架

布局（参考图一，ASCII）：

```
┌ Tabs：全部|技能|插件|命令|智能体|专家团 ────────── [综合|最热|最新] ┐
│ [搜索：展示名或短名……] [宿主 ▾] [分类……]                            │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐                               │
│ │ ▓banner▓ │ │          │ │          │  卡片四要素（NFR-U1）：      │
│ │ ⬤icon    │ │          │ │          │  ① icon 头像（真图/占位）     │
│ │ 主标题    │ │          │ │          │  ② 主标题 + 副标题           │
│ │ 副标题    │ │          │ │          │  ③ ≤2 行描述                 │
│ │ 描述 ≤2行 │ │          │ │          │  ④ 底部标签 ≤3               │
│ │ [标签…]   │ │          │ │          │  整卡可点 → 屏 2 抽屉          │
│ └──────────┘ └──────────┘ └──────────┘                               │
└──────────────── 共 {N} 件 · 上一页 / 下一页 ──────────────────────────┘
```

网格 `repeat(auto-fill, minmax(280px, 1fr))`、gap 16px（现状 260px 提升，容纳 banner+四要素；宽内容区自然呈现三列，不硬钉）。排序组放 Tabs 右侧扩展槽（antd `tabBarExtraContent.right`），对齐参考图一「tab 左、排序右」。

### 4.1 加载态

| 场景 | 表现 |
|---|---|
| 首次加载（无缓存数据） | MarketSkeleton 骨架 6 张（现状保留），骨架形状升级为与新卡一致：banner 条 + 头像圆 + 两行标题 + 两行描述 + 标签条 |
| 切 tab / 换排序 / 翻页（有旧数据） | **保留旧卡片**（透明度 0.6 + `aria-busy`）+ 顶部 2px 不定式进度条；**不变骨架**——刷新时内容消失像崩溃（实现提示：React Query `placeholderData: keepPreviousData`） |
| < 200ms | 不显示加载态（防闪烁） |
| 同名查询后台刷新 | 静默，无 UI |

### 4.2 空态（三重，判据与行动不同）

| 类型 | 判据 | 文案 | 行动 |
|---|---|---|---|
| **某类型 tab 空**（GWT-03.3） | `type ≠ all` 且该类可见集 = 0 | 标题「暂无该类资产」（钉句）<br>说明「同步 .agents 后，{类型中文} 会出现在这里。」 | [立即同步]（主，调 syncAgentsHub；仅超管预览态显示）+ [去治理目录]（次） |
| **筛选后空**（现状保留） | 有 q/host/category 且结果 0 | 标题「没有符合条件的能力」+ 筛选回显清单（现状 FilterEcho） | [清除筛选]（主） |
| **整架空**（现状保留扩展） | 无筛选且全库可见集 = 0 | 标题「暂无已上架能力」（现状钉句）<br>说明「上架后能力会出现在这里。当前有 {live_total} 个资产未上架。」（预览态给治理线索） | [去治理目录]（主） |

租户侧（闸开、official）空态沿用现状句不加治理行动——本轮 official 不动，此处只约束 admin 预览态。

### 4.3 错误态

| 场景 | 表现 | 下一步 |
|---|---|---|
| 列表请求失败（网络/5xx/兜底） | 内容区替换：`role=alert` +「市场列表加载失败」（现状钉句）+「检查网络后重试」+ trace 小字（如有） | [重试]（主，loading 期间防重复点击） |
| 非法 type 参数 | 「没有这种类型」（现状钉句） | [查看全部]（重定向 type=all） |
| 局部失败 | 排序/筛选属同一查询，无局部区——不适用 | — |

### 4.4 权限态

| 场景 | 隐藏还是禁用 | 理由/表现 |
|---|---|---|
| 租户闸关（market_closed payload） | 状态页 | 现状钉句「能力市场未开放」+「开放后，已上架的能力会出现在这里。」（GWT-03.4 oracle 不动） |
| 超管预览态（preview=true） | 显示 + badge | 页顶 Alert info：「预览模式 · 市场未对租户开放，你看到的是上架后的展示效果」；gate_open=true 时不显示 badge（所见即真实货架） |
| 治理动作（同步入口） | **仅预览态显示** | 空态的 [立即同步] 只对超管渲染；货架其余元素不含治理动作（治理动作在治理面，越权 404 由后端门面兜底，前端不做 403 态） |

### 4.5 边界态

| 边界 | 表现 |
|---|---|
| 主标题超长 | 单行截断 + `…` + `title` 属性全文（不换行撑高卡片） |
| 描述超长 | 2 行 clamp（Paragraph ellipsis rows=2，现状） |
| 描述缺失 | 灰字「暂无描述」（占位而非空白） |
| 副标题缺失（无 origin_plugin_name） | 用类型中文（技能/插件/命令/智能体/专家团）兜底，不用空串 |
| 底部标签 > 3 | 优先级 精选 > 预告 > 类型 > 其他；超出收进 `+N` Tag，hover 列出 |
| 卡片极多 | 分页现状保留（「共 {N} 件」+ 上一页/下一页）；本页 ≤ 12 卡 |
| 「最热」无计数（GWT-04.4） | 选中态保持「最热」，顺序=综合序，**页面上不出现任何计数数字**，无降级 banner（测试断言走 `sort_applied`） |
| 图损坏/404 | `onError` 回落占位（§8），不报错不 toast（GWT-06.3） |

排序组与 tab 的交互态四件套：hover = 浅灰底；focus-visible = 2px 主色外环；active = 深一档底色；disabled = 不适用（三档恒可选，降级不禁用）。

## 5. 屏 2：详情抽屉

```
┌──────────────────────────────┐
│ ×关闭                          │
│ ▓▓▓▓▓ 背景横幅（高 120px）▓▓▓▓▓ │
│ ┌────┐ 主标题（≤2 行截断+title） │
│ │icon│ 副标题 · 已订阅 N 次* · 更新于 YYYY-MM-DD │
│ └────┘ [技能] [精选] [预告]      │
│ ── 帮你做的事 ──（有维护时才渲染）│
│ ▸ 示例条目 ……       [复制]     │
│ ──（md 正文，GFM 渲染）──       │
│ ████ 正文 ████ ████            │
├──────────────────────────────┤
│ [ 订阅 ]（sticky footer CTA）   │
└──────────────────────────────┘
*「已订阅 N 次」仅 N ≥ 1 时显示（真实 capability_installs 计数，无数据不显示假数字——附加 a）
```

### 5.1 加载态

| 场景 | 表现 |
|---|---|
| 打开抽屉（详情请求中） | 抽屉框立即出现（固定宽 520px，防布局跳动）+ 内容 Skeleton：横幅条 + 头像圆 + 标题两行 + 标签行 + 正文 3 行 |
| 大文档渲染期（≤5000 行，NFR-02） | 仅正文区 Skeleton + `aria-live=polite`「正在渲染正文…」，头部区块先呈现（先给身份，再给正文） |
| 渲染 > 3s | Skeleton 保持，无白屏（NFR-02 预算即验收线） |

### 5.2 空态

| 区块 | 判据 | 表现 |
|---|---|---|
| md 正文空（GWT-05.3，plugin 型预期） | detail 正文为空串 | 正文区「暂无正文」（钉句）+ 小字「该资产没有可展示的 Markdown 正文」；其余区块正常（GWT-05.3 oracle） |
| 示例区未维护（附加 d） | examples 为空数组/NULL | **区块整体隐藏**（不渲染标题与空框，GWT-05.3） |
| 示例有维护 | 1–20 条 | 标题「帮你做的事」+ 逐条引用样式块 + [复制] |
| 元信息无订阅数 | N=0 | 「已订阅 N 次」整条不显示（不是显示 0——回避计数噪音） |

### 5.3 错误态

| 场景 | 表现 | 下一步 |
|---|---|---|
| md 渲染异常（K2/NFR-04） | 仅正文区降级 `<pre>` 纯文本；头部/标签/示例/CTA 不受影响 | 无需用户动作 |
| 详情请求失败（网络级） | **关闭抽屉 + toast「详情加载失败，请重试」**（contract §6 Offline 列钉行为） | toast 内 [重试]（重开抽屉再拉一次） |
| unlisted/未上市 404 | 见 §5.4 权限态 | [去治理目录查看]（若来自治理行） |

### 5.4 权限态

| 场景 | 表现 |
|---|---|

## 8. 占位图设计规则（FR-06，AssetVisual 纯函数）

1. **确定性**：`index = hash(asset_type + ':' + name) % 8`（字符串 hash 任意稳定实现，禁止 Math.random/Date）；同一资产任意次渲染恒同图（GWT-06.1）。
2. **形制**：135° 线性渐变（下表 8 组）+ 居中展示名首字符（`cardTitle` 短名首字符，中文/英文均可）+ 右下角类型角标 chip。
3. **首字母字色** = #fff，字号 = 容器边长 × 0.4，字重 600。渐变**最浅端**对白字对比全部 ≥ 3:1（大字/UI 图形线，已验，见 §9 验证表）。
4. **类型角标 chip**（四类资产可区分的图标形，第二通道非颜色）：底 `rgba(0,0,0,0.28)` + 白色图标 14px——skill=闪电、command=代码括号、agent=机器人、plugin=应用四方格（与 ImportWizard `TYPE_ICONS` 现状映射一致）、team=群组（货架五类含 team）。
5. **回落链**：`logo` 有值 → `<img>` + `onError` → 占位；`logo` 无值 → 直接占位（GWT-06.2 真图不占位 / 06.3 损坏回落，页面不报错）。
6. **尺寸**：卡片头像 40×40（radius 8px）；抽屉头像 72×72（radius 12px）；抽屉横幅无背景图时 = 同渐变横向拉伸（高 120px，不加首字符）。
