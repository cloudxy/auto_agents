## 0. 文案护栏（全访客 / 全租户可见面）

出现任一句 = 本设计合同失败（FR-U24 / P-06 / P-DES-01 / P-DES-03）：

| 禁止 | 用什么 |
|---|---|
| **「当前可买」**（四字及其变体：当前可买中转 / 当前可买套餐） | 不陈述可买；付费出口用「去结账」 |
| `QUOTA_EXCEEDED` / 裸 `429` / 业务 `code` 字面 | 工人句或配额句（见锁句） |
| 「暂无数据」「暂无渠道」 | 下表锁句 |
| 市场关闭渲染成「暂无已上架能力」 | 「能力市场未开放」 |
| 开关已开、可见行=0 渲染成「能力市场未开放」 | 「暂无已上架能力」 |
| 仅预告行渲染成「暂无已上架能力」 | 出预告卡，无订阅按钮 |
| 租户打开「能力市场」整页 404 | 货架（三空或订一行）；404 只给上架治理写面 / RBAC |
| 失败装 0 条 / 失败装没货 / 失败画成 0% | 错误态 +「重试」 |
| 「抱歉您没有权限」当平台页 Then | 后台 404 同形 |
| 专业/企业主按钮进免费注册 | 买方→结账；经办/只读→联系管理员 |
| 通道 SDK 名（Alipay SDK / 微信支付 API）当按钮或模块名 | 「支付宝」「微信支付」 |
| 超管读回商户密钥全文、`type=text` 回填已存密钥 | 掩码；保存后无全文 |

**锁句（按钮 / Toast / 页内同一动词）：**

| 场景 | 锁句 | 主操作 |
|---|---|---|
| 空企业真 0 结果 | 「还没有结果，去提交采集」 | **去提交采集** → `/spiders/tasks` |
| 工人不在线 | 「采集未运行，不会出数」 | **查看节点** → `/spiders/nodes` |
| 配额已尽 | 「已达配额上限」 | 存储：**去结果库** → `/data`；token/并发：**申请提升** |
| 配额将满（≥90% 未满） | 「接近上限。超额操作会被拒绝。」 | 无「申请提升」当满额出口 |
| 入队成功（3 秒内） | 「已入队」 | — |
| 市场总开关关 | 「能力市场未开放」 | 无订阅 |
| 开关开且可见行=0（listed ∪ coming_soon 皆无） | 「暂无已上架能力」 | 无订阅 |
| 定价专业/企业主按钮 | 「去结账」 | 买方→结账（`plan_pro` / `plan_enterprise`）；访客先登录再回结账；经办/只读→屏 10 |
| 两通道均未配（打开结账、不建单） | 「收款通道未开通」 | 无「去支付」 |
| 仅微信未配（打开结账） | 微信旁注「该通道未开通」 | 支付宝可「去支付」 |
| 仅支付宝未配（打开结账） | 支付宝旁注「该通道未开通」 | 微信可「去支付」 |
| 选了未配通道并去支付 | 「该通道未开通」 | 改选已开通通道；不进该通道侧界面 |
| 待支付（`checkout_pending` / 旧 `pending`） | 「待支付」 | **继续支付**（同一单） |
| 同一商品已有待支付 | 「已有未完成的支付」 | **继续支付**（已有单） |
| 非买方建单 / 经办点升级 | 「请联系本企业管理员开通」 | 关闭；不到注册、不建单 |
| SKU none | 「未开通中转」 | 买方 **去升级**；经办/只读同上联系句 |
| SKU active 且 0 令牌 | 「还没有令牌」 | 买方 **签发令牌** |
| SKU expired 签发 | 「中转已到期」 | 买方 **去升级** |
| 验真通过开通未完成 | 「支付已到账，开通处理中」 | 刷新；数字仍是开通前 |
| 取消/超时/通道失败 | 「支付未完成，套餐未开通」；商品=`relay` 用「支付未完成，中转未开通」 | **重新去结账** |
| 值班无模型 | 「还没有平台模型，去网关登记」 | **刷新** |
| 值班网关挂 | 「LLM 网关管理面不可达，仅本地事件/探针」 | **刷新** |
| 值班行活 | 「活」 | — |
| 权限缓存未就绪 | 「权限加载中」 | 保留读叶 |
| 会话失效 | 「登录已过期。重新登录后回到刚才的页面。」 | **重新登录** |

工人句与配额句 **不得混用**。关闭句与空货架句 **不得混用**。值班三句 **互斥**（有「活」就不能是另两句）。

## 通用规则

### Toast vs 内联 vs 全屏

| 严重度 | 用什么 |
|---|---|
| 成功 | Toast 3s，动词与按钮同名（「已入队」「已签发」「已开通专业档」） |
| 可恢复操作失败 | 内联，不关弹窗、不清表单 |
| 页级加载失败 | 内容区替换 + **重试** |
| 会话失效 | 跳登录，保留 `from` |
| 部分成功（验真过、开通未完） | 警告色 Alert，不是错误色，不是成功绿「已买」 |

### 不只靠颜色

错误 ✕、警告 ⚠、成功 ✓、将满 ⚠、「活」● 文字、「预告」文字角标。通道未开通：禁用控件 + 旁注，不只灰掉。

### 加载节奏

首次：骨架（形状跟真内容）。刷新：旧内容 opacity 0.6 + 顶细进度，不整页骨架。&lt;200ms 不闪。&gt;10s：「加载较慢」+ 仍可重试。

### 未知错误兜底

「加载失败，请稍后重试。」小字「错误编号 {trace_id}」（无堆栈、无 code）。主按钮「重试」。

### 离线默认句

标题「网络不可用」。说明「已打开的内容仍可阅读；提交、订阅、去支付、签发、刷新列表会失败。」主按钮「重试」。**禁止**离线渲染成空列表。

### 404 同形（租户直打平台专属）

与未登录打不存在页同一模板：标题「页面不存在或已被移除」；主按钮「返回工作台」。无渠道列表、无密钥、无源列表、无上架控件、无勾选矩阵、无「抱歉您没有权限」。**上架治理直打与 RBAC 直打用同一套 HTML，不得两套 403。**

闭集（租户含公司管理员；超管打开则进对应产品屏）：

| 地址 | 超管落地 | 租户直打 |
|---|---|---|
| `/rbac`、`/rbac/*` | 屏 20 | **屏 21** |
| `/enterprise`、`/enterprise/*` | 现网企业管理 | **屏 21** |
| `/newapi`（平台渠道窗口） | 屏 19 | **屏 21** |
| `/payment-credentials` | 屏 18 | **屏 21** |
| `/platform-ops` | 屏 22 | **屏 21** |
| `/users` | 用户管理 | **屏 21** |
| 上架治理写面子路由（若拆出：`/capabilities/sources` 及同族 catalog/scan 页） | 屏 24 七叶 | **屏 21** |
| 他企结果/订单/令牌/安装深链 | — | **屏 21**（0 行、无对方字段） |

**禁止：** 租户打开「能力市场」`/capabilities` 整页走屏 21（那是货架，屏 15；否则 GWT-U10 订一行不可达）。

### 同一动作不得两套 Then

| When | Then |
|---|---|
| 打开「我的渠道组」`/relay` | 本企业 SKU 产品面（未开通/已开通/到期） |
| 直打平台值班页 `/newapi` | 404 同形（屏 21） |
| 直打平台 RBAC `/rbac` | 404 同形（屏 21）；超管 → 屏 20 |
| 直打商户凭据 `/payment-credentials` | 404 同形（屏 21） |
| 租户打开「能力市场」`/capabilities` | **货架**（屏 15：未开放 / 暂无已上架 / 订一行）。不是 404，不是七叶 |
| 超管打开「能力市场」`/capabilities` | **七叶治理 + 总开关**（屏 24）。不是租户货架 |
| 租户打开「上架治理」/ 寻找源、扫描、上架写 | 导航无该入口；直打治理写面子路由 → 屏 21（无上架控件、无源列表） |

### 隐藏 vs 禁用（本波默认）

| 能力 | 无权限时 | 理由 |
|---|---|---|
| 平台专属叶（值班/凭据/RBAC/运营台/上架治理写面） | **隐藏**；直打 404 | 不该知道有平台写面 |
| 发现性动作：订阅、提交采集、签发 | **禁用 + 旁注**「请联系本企业管理员开通」或角色句 | 应该知道有这功能 |
| 定价「去结账」、渠道组「去升级」 | 非买方 **可点进屏 10**（文案仍是「去结账」/「去升级」） | GWT-U35.3 / U35.7 的 When 是点按钮；灰掉会让人找不到下一步 |
| 预告行订阅 | **隐藏按钮**（无订阅入口） | 预告不可订，不是权限不够 |
| 未配通道单选项 | **禁用 + 旁注**「该通道未开通」 | 另一通道仍可选 |
| 签发明文「显示全文」眼标（已保存后） | **不出现** | 没有全文可显 |
| 租户货架上的源叶 / 上架开关 / 扫描 / 总开关 | **不渲染**（不是禁用） | 货架不是治理台；禁用仍会泄漏写面 |

## 屏 1：官网首页 Hero `/`

ToB 访客第一句。N3 已施工也不得改口（FR-U04）。

### 加载

静态 Hero 立即可画。精选能力：6 张卡片骨架，不对整页 Spin。

### 空

➖ Hero 无数据依赖。精选 200 且 0 卡：沿用 v2「还没有上架的能力…」；**不得**用支付/订阅顶替空缺。

### 错误

精选失败：「暂时无法加载能力」+「重试」。Hero 采集句仍在。禁止空白当没货。

### 权限

匿名可看。租户公司管理员寻找「编辑官网第一句 / 改 Hero」：**无入口**（GWT-U04.3）。

### 边界

首屏第一句锁采集：**粘贴链接 / 出数**。禁止讲订阅成功、支付成功、中转可买。全文禁「当前可买」。行长不把付费档写成已开通购买。

### 离线

静态 Hero 可阅读。主 CTA：「网络不可用。连接恢复后再注册。」精选走错误句。

**交互：** Hero 主 CTA「免费注册」hover=品牌主色加深；focus=可见 focus ring（不得只靠 hover）；disabled 仅离线拦截时。

## 屏 2：定价 `/pricing`

三档始终在。付费主按钮 **不是**免费注册。专业/企业 CTA 锁字 **「去结账」**（P-DES-03）。通道未配 **不是**本屏空态。

### 加载

价格与档名静态可先出，无整页骨架。登录态未返回：**付费档已写「去结账」**，禁止先闪「预告不可购买 / 联系升级 / 当前可买」再改口。识别为只读/经办后 **不改按钮字**，按下才进屏 10。

### 空

➖ 三档始终渲染。通道未配到屏 11 说「收款通道未开通」。本页无货架空句。无「尚未开通购买」副标题（与「去结账」互否）。

### 错误

未登录点专业/企业：先登录（GWT-U35.2）；登录失败走登录屏，保留 `from=/billing/checkout?product=plan_pro`（企业档则 `plan_enterprise`）。结账打开失败：屏 11 错误句，本页不改口。mailto **不**用于付费主按钮。

### 权限

| 谁 | 免费档主按钮 | 专业档主按钮 | 企业档主按钮 |
|---|---|---|---|
| 匿名访客 | **免费注册** → `/register` | **去结账** → 先登录，登录后回到 `/billing/checkout?product=plan_pro`；不到「再注册一家」 | 同左，`product=plan_enterprise` |
| 只读 / 经办 | 不出现（已有企业） | **去结账** → 屏 10「请联系本企业管理员开通」；不建单；不到结账 | 同左 |
| 买方 | 不出现 | **去结账** → 屏 11 `product=plan_pro`（已有该商品待支付则落「待支付」，不建第二笔） | **去结账** → 屏 11 `product=plan_enterprise`（同上） |
| 公司管理员找「编辑定价」 | 无入口（GWT-U24.3） | | |

禁止三档都进 `/register`。禁止按钮或弹窗写「联系升级 / 联系销售 / 预告不可购买 / 该档尚未开通购买」却送到注册或 mailto。禁止「当前可买」及其变体。

**现网作废（T-21 消费）：** 专业/企业 `cta.label=预告不可购买`、Tag「预告」、副标题「专业档与企业档尚未开通购买」、Modal「预告不可购买」+ mailto。改口后主按钮一律「去结账」。

### 边界

免费数字与用量一致。付费价格可展示；**不得**写成「现在可买 / 当前可买」。Q-AGPL 未答期间，即使已有非夹具支付成功，本页全文仍无「当前可买」（GWT-U24.2）。企业档无 `plan_ent` 文案。企业档功能列表 **不得**写成开通即送中转 SKU（中转出口只在屏 13「去升级」`product=relay`）。`paid_pending_fulfillment` 期间本页 CTA 仍是「去结账」，不得改成「已开通」。

焦点序：免费注册 → 专业去结账 → 企业去结账。

### 离线

页可阅读。点免费注册：「网络不可用。连接恢复后再创建企业。」点去结账：「网络不可用。连接恢复后再去结账。」

**交互：** 「去结账」hover/focus ring 可见；loading=按钮内 spinner「打开结账…」，5 秒内进结账、结账空态或屏 10（NFR-U01）。disabled 仅离线点击后的瞬时，不把付费档做成「预告」灰按钮。
