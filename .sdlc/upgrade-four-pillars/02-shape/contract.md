## 1. 现状测绘（改造类必填，新建写 N/A）

**现有边界**（2026-09-12 读码）：单进程 FastAPI `:9111` + 平行 Scrapy Worker + 双前端。四柱 v2 有条件放行。采集入队已走 `require_online_worker` + 配额闸；结果查询有空态句「还没有采集结果」。市场包 `power_market/` 可订一行，但 `POWER_MARKET.ENABLED` **只**作启动/源扫描开关，**订阅路径不读它**。计费：线下挂账；`alipay`/`wechat` 在创建前拒绝。`/relay` 已有组+令牌，**无** SKU 权益。值班 `/newapi` 已有「还没有平台模型」与「网关管理面不可达」，无独立「活」句。产品事件有 `task_completed` / `market_subscribe_succeeded`，**无** `is_internal_fixture`。官网 Hero 已是采集句。

## 5. 关键决策

| 决策 | 结论 | ADR |
|---|---|---|
| 在线履约何时发生 | 仅验真通过的通道通知之后；创建待支付≠开通 | [ADR-0024](adr-0024-notify-driven-checkout.md) |
| 商户凭据怎么存 | 加密落库，与 LLM 密钥同级；超管读回掩码 | ADR-0024 |
| 是否把通道 SDK 当产品 | **否**。产品是通道码 + 验真端口 | ADR-0024 |
| 中转已买的真相 | SKU 权益，不是组行存在，不是专业档 | [ADR-0025](adr-0025-relay-sku-entitlement.md) |
| 「我的渠道组」vs 值班页 | 两 When；后者对租户 404 同形 | ADR-0025 |
| 市场总开关 | 超管可改的运行配置（NFR-U10）；yaml 默认 false 仍是进程默认/值班联系人启动闸 | 无需新 ADR（可逆；关闭句与空货架句分家） |
| 夹具排除 | 超管维护企业名单；事件写入当时快照布尔 | 无需 ADR（交给 /dba 语义） |
| 存储 | 沿用 MySQL+Redis；不引入第二种主存储 | 无需 ADR |
| 拓扑 | 沿用 ADR-0010 单体四柱 + 独立网关 | 不重开 |
| Q-AGPL | **不关**。可见面禁「当前可买」四字（FR-U24） | 禁止方案帽代选 |

不可逆决策必须有 ADR。判据：三个月后想改，成本是「改几行」还是「改一片」。

## 6. 契约

| 契约 | 路径 | 消费方 |
|---|---|---|
| HTTP/事件（本波新面，见本节） | 本节 6.1–6.4 | `/backend` `/frontend` `/qa` |
| 数据语义（给 /dba） | §7 | `/dba` |

通用：Base `/api/v1`；时间 ISO 8601 UTC；集合不返回 null；业务判断用 `code` 不用 `message`；5xx 带 `trace_id`。破坏性变更字段并存。

### 6.1 错误码（本波新增/收紧）

| HTTP | code | 语义 | 用户可见（禁止把 code 渲染给租户） |
|---|---|---|---|
| 409 | `ORDER_PENDING_EXISTS` | 同一企业同一商品已有待支付 | 「已有未完成的支付」 |
| 422 | `ORDER_ROLE_NOT_ALLOWED` | 非买方建单 | 「请联系本企业管理员开通」 |
| 422 | `ORDER_CHANNEL_UNCONFIGURED` | 选了未配通道并去支付（单据已转 unpaid） | 「该通道未开通」 |
| 422 | `BILLING_CHANNELS_UNCONFIGURED` | 打开结账时两通道均未配（**不建单**） | 「收款通道未开通」 |
| 422 | `RELAY_SKU_INACTIVE` | 未开通/到期签发或当已买用 | 未开通句 / 「中转已到期」 |
| 422 | `RELAY_TOKEN_ROLE_NOT_ALLOWED` | 经办签发 | 现网找管理员句 |
| 409 | `MARKET_CLOSED` | 总开关关闭时订阅 | 「能力市场未开放」 |
| 404 | （无业务信封） | 租户打平台专属页 | 与未登录打不存在页同形 |
| 禁止 | 用户可见 `QUOTA_EXCEEDED` / 裸 `429` / `PAYMENT_NOT_CONFIGURED` 当唯一句 | P-06 / 现网在线拒绝句作废为结账空态 | 工人句与配额句不得混用 |

既有 `SPIDER_WORKER_OFFLINE` → 用户句「采集未运行，不会出数」（已冻）。配额已尽 → 「已达配额上限」+ 存储满「去结果库」/ token 满「申请提升」。

### 6.2 采集加深

沿用 `POST /api/v1/spiders/run`（经办）、结果列表/导出 100 条上限。入队 3 秒内：已入队 **或** 拦住（工人/配额），不得停在「正在采集」。

空结果：`message` 须含「还没有结果」且可行动「去提交采集」；禁止空白；禁止「加载失败」装 0 条。跨企业：0 行、无对方字段、同形不存在。

申请提升：**只读/经办**不创建待支付，着陆联系管理员。**买方**进入结账，`product=plan_pro`（token 满默认专业档；本波不另开并发/存储独立 SKU）。N1 可只落到结账路由的「收款通道未开通」空态；N3 填通道。禁止进企业注册。

### 6.3 市场总开关与订一行

`POWER_MARKET` yaml 默认 false 保持进程默认。超管运行时总开关（NFR-U10）打开后：`POST .../subscribe` 对已上架∩已发布或推荐∩许可过闸的一行产生安装行；订插件不带子卡；预告无按钮。关闭：公开列表「能力市场未开放」，**禁止**「暂无已上架能力」。打开且 0 行才用空货架句。只读拒绝。公司管理员改开关 → 拒绝且开关不变。

事件：`market_subscribe_succeeded` 仅成功安装；关闭时尝试不得出现该事件（可有 rejected，不进 D2 分子）。

详情：`skill_md`/`body_md` 纯文本；`<script>` 不执行。PIT-1：公开静态段仍先于 `/{type}/{name}`。

### 6.4 结账 / 通知 / 中转 SKU

**商品码闭集**（请求与事件字段 `product`）：`plan_pro` | `plan_enterprise` | `relay`。无 `plan_ent`。

**通道闭集**：`alipay` | `wechat`。

租户写：

| 方法 | 路径 | 谁 | 幂等 |
|---|---|---|---|
| GET | `/billing/checkout?product=` | 买方可见选择；经办/只读同 U35.3/U36.2 | 打开两通道均未配 → **不建单** |
| POST | `/billing/checkout` body `{product, channel}` | 仅买方 | 同一企业同一商品仅 1 笔非终态待支付；重复 → 409 不建第二笔 |
| GET | `/billing/orders` | 本企业 | 租户看不到他企 |
| POST | `/billing/notify/{channel}` | **无 JWT**；通道 | 至少一次；幂等键=本笔订单号 |

通知路由必须是静态段，注册在任何 `/billing/orders/{id}` 之前（PIT-1）。验真失败：HTTP 可 200（避免通道狂重试）但**不开通**、无 `payment_succeeded`；内部记失败原因。验真算法/签名格式/回调 query 形态 **不在本合同选定**（FR-U38）；实现必须满足「视为通道侧真通知」四要素。

超管：

| 方法 | 路径 | 谁 |
|---|---|---|
| GET/PUT | `/admin/payment-credentials` | 仅 `require_platform_admin_or_404`；PUT 后读回密钥掩码；响应无全文 |
| GET | `/product-events` | 既有超管查询；本波事件名追加见下 |

`confirm_paid` 本波不勾 GWT-U33/U38。

中转：既有 `/relay/groups|tokens`。SKU ≠ active：列表空且 message 未开通；签发 422。到期签发：「中转已到期」。已开通无令牌：「还没有令牌」。跨租户 404 同形。

**支付单据状态（对 /dba 与实现同一张）**：`checkout_pending` →（验真+开通完成）`fulfilled`；→（取消/超时/通道失败/未配置）`unpaid`；→（验真通过开通未完成）`paid_pending_fulfillment` → `fulfilled`。伪造/四要素不符：保持 `checkout_pending` 或已转的 `unpaid`，不得 `fulfilled`。`unpaid` 不得被迟到成功通知拉成 `fulfilled`。

Expand-contract：读模型把旧 `pending` 视为 `checkout_pending`，旧 `paid` 视为 `fulfilled`，旧 `cancelled` 视为 `unpaid`。写路径新单只用新枚举。

**事件**（至少一次，失败不挡，查询仅超管）：

| event_name | 何时 | props 必有 | 禁止 |
|---|---|---|---|
| `task_completed` | 终态 completed | `result_count`,`spider`,`source`,`is_marketplace_candidate`,`is_internal_fixture` | 夹具完成进北极星分子 |
| `task_run_submitted` | 入队成功 | `spider`；拦住**不**发 submitted 当完成 | 与完成混口 |
| `task_blocked`（本波新增名，供 D3） | 工人或配额拦住、未入队或 3 秒内失败 | `reason`∈`worker_offline`/`quota_storage`/`quota_tokens`/`quota_concurrency`；`is_internal_fixture` | 有对应 completed 且 count>0 |
| `market_subscribe_succeeded` | 安装行新产生或幂等已订成功 | `host`,`tenant_id` | 开关关闭时的尝试 |
| `payment_succeeded` | **验真通过即可**，不等开通完成 | `channel`,`product`,`tenant_id` | 密钥、口令、未验真 |
| `payment_failed` | 取消/超时/通道失败/未配置 | `reason`∈`cancel`/`timeout`/`channel_error`/`unconfigured` | 仅打开结账（U32.2）不得有本事件 |

投递：至少一次；分区键语义=tenant_id（同租户查询）；幂等键建议订单号/任务 id（v1 产品事件表仍无精确一次键，沿用 ADR-0016；支付开通本身必须精确一次）。

### 6.5 权限三态与 404 同形

未知（权限缓存未就绪）：「权限加载中」或保留读叶；不得整站空白；不得露出平台 RBAC/上架/值班写/商户凭据。拒绝：平台专属页对租户隐藏；直打与页面不存在同形，不是道歉 403。允许：超管。

同一动作不得两套 Then：「打开我的渠道组」≠「直打平台值班页」≠「直打平台 RBAC」≠「直打商户凭据页」。

  orders.status 旧值并存映射见 §6.4
