## 4. 给 T-10 的消费清单

1. 屏 **3 / 15** 现网「还没有上架的能力」作废为货架空句「暂无已上架能力」（Hero 精选空仍走 v2，不扩散到列表）。
2. 总开关关：两屏都用「能力市场未开放」；关+筛选仍关闭句，不是筛选空。
3. 仅 coming_soon：出预告卡，**不要**货架空句。
4. 租户 `/capabilities` 只渲染货架（屏 15）：无源叶、无上架控件、无扫描、无总开关。超管同一 path 走屏 24。

6. 上架治理 / `/rbac` 直打：屏 **21**「页面不存在或已被移除」+「返回工作台」。不要道歉 403。
