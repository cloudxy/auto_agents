## 4. 给 T-19 / T-20 / T-21 的消费清单

**T-21 定价**

1. 专业/企业主按钮字 **「去结账」**。作废「预告不可购买」「联系升级」「联系销售」、Tag「预告」、副标题「尚未开通购买」、mailto 弹窗。
2. 免费档仍「免费注册」→ `/register`。
3. 买方：`/billing/checkout?product=plan_pro` 或 `plan_enterprise`。已有该商品待支付 → 屏 11「待支付」，不建第二笔。
4. 访客：先登录，`from` 带回上列结账 URL。
5. 经办/只读：按下进屏 10，不改按钮字、不建单。
6. 全文不得出现「当前可买」。企业档列表不得写成开通即送中转。

**T-19 结账**

1. 两通道未配：锁句「收款通道未开通」；**无「去支付」**；不建单（N1 空态句继续有效）。
2. 仅微信未配 / 仅支付宝未配：未配项禁用 + 旁注「该通道未开通」；已配项可「去支付」。
3. 选未配通道并去支付：可先「待支付」，随即 unpaid +「该通道未开通」；不进该通道侧界面。
4. `checkout_pending` / 旧 `pending`：租户「待支付」+ **继续支付**。再点去支付：「已有未完成的支付」。
5. `paid_pending_fulfillment`：「支付已到账，开通处理中」⚠；档位/SKU 仍开通前；无去支付。
6. 通道名只用「支付宝」「微信支付」。回跳不改档位。禁「当前可买」。

**T-20 我的渠道组**

1. 页标题与导航：「我的渠道组」。SKU none 导航无「已开通 / 使用中」。
2. none（含已停用）：「未开通中转」+「去升级」。expired：「中转已到期」+「去升级」。active 且 0 令牌：「还没有令牌」。
3. 买方「去升级」→ `product=relay`。经办/只读同一 CTA → 屏 10。
4. 040 骨架行在 SKU≠active 时隐藏不删。专业档开通仍走 none。
5. 商品=relay 的处理中：顶栏处理中句，内容按开通前。
