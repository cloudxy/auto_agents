## 1. 谁第一次碰到

| 角色 | 本轮？ | 第一次成功是什么 |

## 3. 开通 / 激活

### 第一次成功（gate）— 空租户经办

本轮 **判定北极星** 仍是这一条：一家任务数为 0、**不在夹具名单**的企业里，经办当天能交差。步骤给人看，不是密钥注入。

1. **进空企业。** 未登录从官网首页读到采集第一句后点「免费注册」，登录后台。企业必须是新开通、不在内部测试名单。打开「我的结果」：标题「还没有结果」，说明「去提交采集」（合成锁句「还没有结果，去提交采集」）。**禁止**把加载失败当成 0 条。
2. **去提交采集。** 点 CTA 进入采集任务。空表 **可以**提交，不是禁用。新增任务：爬虫用示例站点，地址贴示例链接（沿用既有示例，不新开站点、不承诺登录墙）。
3. **提交后立刻看句，不要盯着转圈。** 3 秒内必须变成「已入队」，或下面拦住句之一。不得停在「正在采集」。
4. **入队成功才算等待。** 最多等 120 秒。回到「我的结果」，本企业出现条数>0。别的企业打开同一条，看起来像「页面不存在」（0 行、没有对方字段）。这就是 **第一次成功（gate）**。
5. **拦住也算诚实交差，不算「没货」。**  
   - 「采集未运行，不会出数」→ **查看节点**（屏 8）。租户 **没有**「启动工人」按钮；工人是平台进程。客服不指导重启。  
   - 存储满：「已达配额上限」→ **去结果库**。  
   - 用量/并发满：「已达配额上限」→ **申请提升**（经办到屏 10 为止）。  
   工人句与配额句 **不得混用**。将满只警告「接近上限。超额操作会被拒绝。」，**不是**已达上限，页上无「申请提升」当满额出口。

ToB：邀请 / SSO **说明文案**本波 N/A（证书怎么配是 sre，本文不写）。  
ToC：未付费/未登录的第一次成功 = 读懂首页采集句并免费注册。**付费不是北极星，也不是经办的第一次成功。**

本波合入闸里的出数等待走的是预发夹具，**不得**对外宣称：非夹具租户北极星已经在生产出现。客服仍按上面五步教；教完不等于成绩已达成。

### 买方：结账（支付宝 / 微信支付）

买方从定价点「去结账」，或从用量/规划点「申请提升」，或从「我的渠道组」点「去升级」。5 秒内应进入结账、结账空态或「请联系本企业管理员开通」。

| 看见什么 | 含义 | 下一步 |
|---|---|---|
| 支付宝、微信支付 可选，「去支付」 | 至少一条通道已配 | 选 **支付宝** 只进支付宝；选 **微信支付** 只进微信。不到企业注册。 |
| 「收款通道未开通」 | 两通道都还没配。无「去支付」、不建单 | **预期空态**，不是账号坏了。不要改走免费注册。 |
| 某一通道旁注「该通道未开通」 | 只有另一条能收 | 改选已开通的那条。选了未配的去支付：会先见「待支付」，随即「该通道未开通」，**不进入**该通道侧界面，不标已买。 |
| 「待支付」 | 同一商品已有未完成单 | **继续支付**（同一单）。再点去支付会提示「已有未完成的支付」，不建第二笔。 |
| 「支付已到账，开通处理中」 | 钱的通知已过，档位/中转数字仍是开通前 | **刷新**。不是成功绿「已买完成」。 |
| 「支付未完成，套餐未开通」或「支付未完成，中转未开通」 | 取消 / 超时 / 通道失败 | **重新去结账**。档位与中转都不变。 |
| Toast「已开通专业档 / 企业档 / 中转」 | 对应商品开通完成 | 专业档、企业档 **不会**把「我的渠道组」画成已开通中转。中转开通后去「我的渠道组」。 |

**客服与对外说明禁止接着说：** 现在就能买、已经能买、四柱可卖。通道名只用「支付宝」「微信支付」，不用通道开发包名。打开结账 ≠ 已买。回站只看单据态，不把通道侧「支付成功」回跳当成开通完成。

非买方点「去结账 / 去升级 / 去支付」：只到「请联系本企业管理员开通」，不建单。只读不能提交采集、不能订阅、不能签发。

**预发 / 生产接通收款前：** 超管先在商户凭据页保存通道。未保存时买方应看到上表空态。本波合入闸 **不含** 沙箱收银台；客服 **不得**对外说生产已经能付完。通道配好之后，再按上表教「去支付」。

开通之后（不是 gate）：中转已开通且还没有令牌 → 「还没有令牌」，买方 **签发令牌**（明文只出现一次，关闭后再看只有掩码）。经办不能签发。未开通中转 → 「未开通中转」；到期 → 「中转已到期」。导航不得角标「已开通 / 使用中」。专业档付成 **不是** 中转开通。

### 租户管理员：改不了上架，打不开平台写面

第一次成功 = 本人知道边界，不再把登录者当成平台超管。

| 想做的事 | 实际看到 |
|---|---|
| 打开能力市场 | **货架**（屏 15）。总开关关：「能力市场未开放」。开关开且没货：「暂无已上架能力」。两句不得对调。本页 **无**总开关、无上架、无扫描。 |
| 上架 / 下架一行 | 导航无入口。直打上架写面 → 「页面不存在或已被移除」。提交上架不会成功，一行不变。 |
| 打开平台权限管理 | 直打与「页面不存在」同形：无勾选矩阵、无「抱歉您没有权限」。 |
| 打开平台值班 | 同上 404 同形。这 **不是**「我的渠道组」。我的渠道组在本企业菜单，地址不是值班页。 |
| 同事申请提升 | 接到「请联系本企业管理员开通」。本人以买方再点「申请提升」→ 结账（上节），不是线下挂账。 |

权限还在加载时：旁注「权限加载中」，读叶还在。**不得**整站空白，也 **不得**露出平台写面。会话失效：「登录已过期。重新登录后回到刚才的页面。」

### 平台超管：上架、凭据、值班三态

**能力市场（上架，不是货架）：**

1. 打开能力市场：七叶 + 总开关「能力市场」开/关。租户看不见这个开关。
2. 上架一行后，公开面按既有规则可见。关闭总开关只挡住 **新**订阅，不把已有安装抹掉。打开成功 Toast「已打开能力市场」；关闭 Toast「已关闭能力市场」。
3. 开关关时租户/访客只见「能力市场未开放」，**不要**做成「暂无已上架能力」。开关开且可见行为 0 才用货架空句。仅预告行要出预告卡，无订阅按钮，不是货架空。
4. 公司管理员提交打开总开关：拒绝；开关仍关。

**商户凭据：**

1. 打开商户凭据。两通道都从未配：空表单可填，不是服务器错误页。
2. 保存后密钥只显示掩码，不能再查看全文。没有「显示全文」、没有复制密钥。轮换后旧密钥不能再履约新支付。
3. 租户打开本页 = 404 同形；响应里不能有商户密钥。
4. 本页也不陈述可买。

**值班（三句互斥）：**

| 状态 | 锁句 | 不是 |
|---|---|---|
| 没配 | 「还没有平台模型，去网关登记」 | 加载失败；「活」 |
| 挂了 | 「LLM 网关管理面不可达，仅本地事件/探针」 | 没配过；把行标「活」 |
| 活 | 该行状态「活」 | 没配；挂了；**租户已买中转** |

禁止三句都渲染成「暂无渠道」。有任一「活」行时，页级标题不得改回空/降级句。伪装探针 **不**自动关渠道。值班「活」只说明平台模型探针为活，**不是**套餐已开通，**不是**中转已买。本波 **不承诺**值班服务时效数字；客服不得口播时效。

**产品事实（仅超管）：** 非夹具企业合格出数按非夹具筛选能查到。名单内企业交差不算北极星。拦住与完成不是同一口径。支付成功事件是驱动，查到它 **不得**对外改口成北极星已达成。租户寻找「分析 / 产品事实」：导航无入口；直打 404 同形。

夹具名单加入/移出：见 §2 open_question，不在本文发明路径。

## 4. 客服 / CS 话术

客服先对锁句，再决定升不升级。三问不够就停，不要发明第四套出口。升级对象是 **人**（本企业管理员 / 平台超管 / 产品运营），不是进程命令。

| 用户会问 | 标准答 | 升级给谁 |
|---|---|---|
| 「新公司后台是空的，是不是坏了？第一次怎么交差？」 | 空是真的 0 条，不是故障。打开「我的结果」应看到「还没有结果，去提交采集」。按示例地址提交后，3 秒内应出现「已入队」，随后在本企业结果里看到条数。看不到这句、一直「正在采集」，或页上空白当 0 条，才算异常。拦住时只会出现「采集未运行，不会出数」或「已达配额上限」，两句不能混。 | 句对但一直无条数 → 平台超管（先看是不是工人句）。客服不指导启动工人。不要把拦住解释成「没人要采集」。 |
| 「怎么用支付宝或微信开通？现在是不是已经能买？」 | **不陈述可买。** 收费怎么对外讲尚未选定，客服不得代答「能买」。经办/只读点「去结账」只会看到「请联系本企业管理员开通」。买方打开结账：两通道都没配 → 「收款通道未开通」，没有「去支付」；配好了 → 只在支付宝与微信支付里选，点「去支付」离开本站。付成前档位不变；「支付已到账，开通处理中」时数字仍是开通前。专业档开通 **不会**自动开通中转。官网第一句仍是采集，不是付钱。生产能不能付完，以通道是否已配、单据态为准，不得口播「已经能付完」。 | 把空态当成事故、或要求改口成能买 → **产品运营**（这是预期护栏，不是故障抢修）。凭据没配/配错 → 平台超管去商户凭据页。单据已付但一直「开通处理中」→ 平台超管。 |
| 「我是公司管理员，为什么权限和值班是『页面不存在』？市场我能不能自己上架？值班显示活是不是买过中转？」 | **不能上架，也不是买过。** 公司管理员打开的是货架，不是上架台；上架、扫描、总开关只有平台超管能做。直接打开平台权限或值班地址，本来就应看到「页面不存在或已被移除」，主按钮「返回工作台」，没有「抱歉您没有权限」。本企业「我的渠道组」才是中转产品面；没开通时写「未开通中转」。值班页一行「活」只表示平台模型探针为活，**不是**贵司已买中转，也不是套餐已开通。 | 把 404 当故障、或要求开通平台写面 → 产品运营确认这是壳差。真要上架/改总开关/看值班三态 → **平台超管**。租户不要被带到值班页或权限矩阵。 |

补充（同一套锁句，不另开 FR）：

- 「同事把链接发给我，我打开是空白/不存在」→ 跨企业结果本来就像「页面不存在」。不要答「你没有权限」。
- 「能力市场是空的 / 订不了」→ 先对两句：「能力市场未开放」= 总开关关着，不是没货；「暂无已上架能力」= 开关开了但没货。仅预告卡没有订阅按钮。只读订阅会提示联系企业管理员。公司管理员改不了总开关。
- 「结账打不开 / 网络不行」→ 「结账打开失败，请稍后重试。」或离线句「网络不可用。连接恢复后再打开结账。」离线 **不是**「收款通道未开通」（后者是已加载的配置空态）。
- 「签发令牌看不见全文了」→ 明文只显示这一次。关闭后再看只有掩码。经办不能签发。到期后旧令牌不能再用。
- 页上若出现内部英文码或裸数字状态，按未知错误兜底：「加载失败，请稍后重试。」记下页上的错误编号，升级平台超管。客服不读堆栈。

## 5. 对外说明

用户语言，无内部代号。本轮 **有条件放行**采集第一次成功、能力市场订一行与上架壳差、中转结账路径、值班三态——**不是**整站四柱已完成。

**新企业可以当天交差。** 注册并登录后，若还没有结果，页面会请你去提交采集。贴一条示例链接，成功时会提示已入队，随后在「我的结果」看到本企业的条数。别人的企业看不到你的条。卡住会立刻说明：采集没有运行时写「采集未运行，不会出数」；用量或存储到顶时写「已达配额上限」，并给你「去结果库」或「申请提升」。

**官网第一句仍是采集**（粘贴链接即可出数）。不是订阅成功，不是支付成功，也不是中转推销。支付成功只说明有人走完收款，不替代交差。

**开通套餐或中转由本企业管理员在结账完成。** 定价付费档按钮是「去结账」。结账只提供支付宝与微信支付。通道还没配时会看到「收款通道未开通」——这是说明，不是你的账号坏了。请不要把「去结账」理解成已经付完，也不要把可见面理解成已经陈述可买。专业档开通不会附赠中转；中转要从「我的渠道组」的「去升级」走。

**公司管理员不是平台超管。** 上架、平台权限、值班、商户凭据不属于本企业菜单。误打这些地址会看到「页面不存在或已被移除」。能力市场对租户是逛货架、订一行；开不开放由平台决定。
