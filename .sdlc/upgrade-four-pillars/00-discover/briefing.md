# Briefing · 四柱深度调整（中转站 / Power Market / RBAC / 智能采集）

- 表面：ToB 先（采集经办 / 租户管理员 / 平台管理员）；官网商店面随 Power Market，不单开 ToC 增长环
- Appetite：采集履约深度仍按 **2 人周**；**中转对外可买 + 支付宝/微信支付** 超出该预算 → 定义帽必须拆波，禁止塞进同一 2 人周。超过所在波 50% 停下重判
- Claim：**已经有四柱 v2（有条件放行、非 GA）的平台**，在「示意完整、履约仍裂、市场 flag 关闭」的现状里，把采集做成可判定的第一次成功，并把中转站做成 **租户可买 SKU**（支付宝 / 微信结账，商户凭据仅超管后台可配）；不是再开一张「实现四支柱」巨票
- 泳道：建议 L3（租户边界 + 外部网关 + 权限 → Q-security=yes）
- 分类：**product-change**
