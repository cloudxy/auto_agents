## 渠道偏差

当前证据来自：**操作者**（intent + 未关八问）/ **设计与评审**（D1–D29 Accepted，0 open 产品 issue）/ **内部诊断**（ops S-01…S-19、miner 本机 OLTP、各帽现网裂缝）/ **销售材料**（官网、定价、README）。

**不是**来自：工单（0；定价写「工单支持」，仓库无租户工单模块）/ 应用商店评论（0）/ 访谈 / NPS / 问卷 / 生产行为数据。

| 渠道 | 本期量 | 系统性偏差（本变更） |
|---|---|---|
| 操作者对话 | 1 名程序主人 | 把「必须能演示四柱」听成「租户都要四柱」。一人不是市场 |
| 设计文档 / 评审 | D1–D29 + 修订通过 | 内容与治理拍板，易被写成需求投票 |
| 官网 / 定价 / README | 已读 | 销售口径可靠性低～中；Hero 示意大数会冒充增长 |
| 工单 / 客服 | **0** | 「零投诉」不能推出「没问题」；也听不到不满 |
| 使用数据 | **未获取**生产 n | 无行为则无法发现沉默需求（重复操作、搜无点、漏斗掉） |
| 本机插件树 | 6 / ~16 / 51 | 供给盘点冒充需求规模 |

听不到谁：**真实买方租户**、**轻度经办**、**已流失**（无付费样本则无流失原因）、**企业沉默**（公司管理员不来聊天窗）、**满意者**、**匿名访客 UV**、非操作者的平台值班接班人。

主动反馈通常不到 1%。本期连这 1% 的通道都没有。影响面一律 **未量化**。

本轮补不补：**明确不补** 生产 UV/工单查询（没有可引用的生产窗；本机库外推会把工作区写成市场）。**不补** 把 6/16/51 写成 Reach。发现带不开问卷。补数属于事件查询面可用之后的 ops/analyst，不在本帽。

## 现状替代与切换成本

与 compete 的「现状」对齐（本帽只写 **他们现在用什么代替「做完的四柱产品」**，不写 borrow/avoid/differentiate）。

操作者 / 本机工作区（唯一被观察到的使用者）**现在**把四柱拆开用：

| 柱 | 现状替代 | 切换到「深度四柱」时要放下什么 |
|---|---|---|
| 智能采集 | 后台数据工厂碎片（任务/向导/CSV）；QC 曾跑通一次夹具出数后删除；官网仍按采集叙事获客 | 自建规则与人工导出；第一次出数仍可能卡在工人/配额/LLM 前置 |
| SaaS + RBAC | 免费注册 + 手改配额 + README 三角色；公司管理员与超管写面曾被当成同一类（v2 施工集收过权，无生产碰撞样本） | 习惯「谁登录谁是超管」；到期/套餐叙事无付费样本可练 |
| 中转站 | 租户 **BYOK 直连**供应商；平台路径目标 LiteLLM，默认 `LLM.ENABLED` 关；new-api 退役不作为可卖网关；官网零入口；企业档仍可能印渠道组（Q-PRICE 开） | 自建网关 / 厂商控制台 / 不走平台路径。租户令牌未发（CONTEXT）。卖 SKU 还挡 Q-RELAY / Q-AGPL |
| 能力市场 | 各宿主自己的目录：`~/.zcode/local-plugins`、Kimi desktop managed、Claude/Grok 启用子集；P6 目录能扫能验；商店 flag 关、无「我的安装」生产行为 | 按宿主重复安装；跨宿主 51 个重名靠人记。切换成本 = 改用平台订阅语义（订插件不带礼包，与宿主商店习惯相反） |

**没有**「已在用竞品四柱一体、等着迁来」的计数样本。未完成的四柱产品面前，默认替代是 **拆开的宿主工具 + 示意官网 + 操作者本人当唯一租户**。

## 频次 / 付费位置

- **每租户多久遇到一次：** **未量化**。推断（不得当 E3）：采集经办按任务；RBAC 按每次写面；中转值班按排班、规划/评分按次；市场订阅远低于采集（若主用户是治理则更稀）。无工单可证「多久疼一次」。
- **ToB 预算 / 套餐：** 定价印专业 ¥299、企业档渠道组/私有技能库/工单支持；三档 CTA 曾同进注册（ops S-07）。**0 笔支付**（miner：幽灵 `orders`/`tenant_subscriptions` 不得当金标）。谁出钱、出在哪一档 = **Q-PRICE / Q-BILL 未关**。中转是否可买 SKU = **Q-RELAY**；对外收费还挡 **Q-AGPL**。本帽不代选。
- **ToC：** 本变更单位不是去重访客。briefing：官网商店面随市场波次，**本轮不做 ToC 增长环、不改付费墙假设为已决**。访客诚实履约是裂缝（ops S-01…S-05），UV **未量化**。
