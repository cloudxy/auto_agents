## 边界

**本票做什么**：拉数验钥：先 `outbound_keys`（hash + `revoked_at IS NULL` + 本企业）再 `KEY_BINDINGS`。未绑定/revoked/他企业/渠道组 `sk-` → 拒绝、0 行。出站钥匙打页上 Base URL → 拒绝、非套餐句、渠道组用量相对基线不变。签发事件 `outbound_key_issued` 含 `tenant_id`、**不含明文**。

**本票不做什么**：签发 CRUD → T-04；出站页 → T-06；令牌打网关 → T-09；fail-open → T-22。
