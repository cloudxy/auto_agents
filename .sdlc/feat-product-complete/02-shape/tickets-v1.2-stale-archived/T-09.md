## 边界

**本票做什么**：夹具网关可达时，租户令牌对 Base URL 合法请求：不是无效平台钥匙、不是套餐超限、用量 0→≥1。`RelayService` 读路径对账 spend HTTP → 写 `used_tokens` + `spend_synced_at`。吊销后再打拒绝。60.5 与套餐句分离。A 调用不动 B。熔断/跨企业 404 同形。不得打开 `LLM.ENABLED` 勾 60.3。

**本票不做什么**：签发 HTTP 登记 → T-08；GET 建组 → T-07；渠道组页 UI → T-10；焊根编排。

## expand-contract

`used_tokens` 040 已有，本票定义 **写点**：渠道组读路径，金标=网关 HTTP。吊销门闩=`revoked_at` **加上** 网关作废，不是把 `used_tokens` 置 -1。

## GWT / Then（从 spec 抄）

- **GWT-60.3**：Then 用户可观察同时成立：不是无效平台钥匙、不是套餐超限、该令牌用量从 0 变为 ≥1。本 Then 不把打开产品闸 / 填上游 key 写成需求；闸关或上游空不得把本 GWT 勾成通过（走 GWT-60.5）。
- **GWT-60.2**：Then 用量数字 ≥1，不是 0；只读成员也能看到该数字。
- **GWT-60.5**：Then 与「网关不可达」**同一 Then**：失败可见；**不是** 套餐超限句；不含 `QUOTA_EXCEEDED`；用量不因此显示成「已用完」。
- **GWT-60.6**：Then 无入口；直打与后台「页面不存在」同形；熔断与窗口不变。
- **GWT-60.8**：Then 与页面不存在同形；A 的组与令牌不变。
- **GWT-60.10**：Then 企业 B 用量数字与配额上限相对该基线不变。
- **GWT-92.4**：Then 上报 `relay_token_call_succeeded`，含 `tenant_id`。
