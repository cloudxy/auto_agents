## 边界

**本票做什么**：新建出站域：签发/吊销/列本企业行。明文只在签发响应一次；再 GET 只见 prefix/状态。经办/负责人可签可吊；只读无控件且 API 拒。TenantMixin；**禁止**进 `TENANT_EXEMPT_TABLES`。

**本票不做什么**：

- 拉数执法 / 与渠道组互否 / 事件 → T-05
- 出站页 UI → T-06
- 不调 `llm_gateway`；不写 `relay_tokens`
- 平台共享 `/spider/status|results|stats` 不收进本表

## expand-contract

**新表** `outbound_keys`（db-spec §1）：`tenant_id` NOT NULL；`key_hash` VARCHAR(64) UNIQUE；`key_prefix` 应用保证 **不以 `sk-` 开头**；明文不落库；无 `kind` / `gateway_key_id` / `used_tokens`。索引 `idx_outbound_keys_tenant_created`。生产禁止 downgrade past 037。

## GWT / Then（从 spec 抄）

- **GWT-51.1（本票半格）**：Then 明文只出现一次且可复制；页上名称是「出站拉数钥匙」不是「渠道组令牌」。（「用该钥匙拉本企业结果能拿到行」→ T-05。）
- **GWT-51.2**：Then 「还没有出站拉数钥匙。签发后才能从外部系统拉本企业结果。」；有权角色看见签发；不是渠道组页冒充本入口。（本票 API：200 + 0 把；文案 UI T-06。）
- **GWT-51.5**：Then 无签发按钮，或点了说明找管理员；不产生钥匙。
- **GWT-51.8**：Then 只见前缀与状态（已签发 / 已吊销），不见明文。
- **GWT-51.9**：Then 无吊销控件，或点了说明找管理员；钥匙仍可拉本企业结果。（本票：只读吊销不写 `revoked_at`。）
