## 边界

**本票做什么**：侧栏唯一输入 = `menuConfig` + 权限过滤。脏 DB 树（有 rbac/enterprise、无 relay/installs）**不得**改变侧栏。直打 `/rbac` `/enterprise` 与 NotFound 同形，不是「抱歉您没有权限」。权限未就绪：「权限加载中」；渠道组/我的安装不永久消失。

**本票不做什么**：FR-91 租户能力市场落点；把幽灵修成超管功能；重排五组；`/orders` `/outbound-keys` 叶由 T-03/T-06 在对应组 children 末尾加。

**会改哪些文件**：

| 文件 | 改动性质 |
|---|---|
| `frontend/admin/src/components/AdminLayout.tsx` | 修改：**停读** `fetchDynamicMenus` 驱动侧栏 |
| `frontend/admin/src/hooks/usePermission.ts` | 修改：仅 `menuConfig` 过滤 |
| `frontend/admin/src/hooks/usePermission.test.tsx` | 修改 |
| `frontend/admin/src/App.tsx` | 修改：`/rbac` `/enterprise` 走 NotFound 同形 |
| `frontend/admin/src/pages/RbacManagement.tsx` | 对照：租户不可达 |
| `frontend/admin/src/pages/EnterpriseManagement.tsx` | 对照 |
| `frontend/admin/src/App.test.tsx` | 修改：脏树仍见渠道组/我的安装；直打 404 |
| `frontend/admin/src/services/menus.ts` | 可停用调用；禁止再当侧栏源 |

**不许改的文件**：五组 key/顺序；`/capabilities` 租户落点（FR-91）；backend `/auth/menus` 可留接口但前端侧栏不消费。

## GWT / Then（从 spec 抄）

- **GWT-82.1**：Then 能找到「渠道组」与「我的安装」；找不到「角色权限」「企业管理」。
- **GWT-82.2**：Then 「权限加载中」；渠道组/我的安装不永久消失；不闪出「角色权限」「企业管理」。
- **GWT-82.3**：Then 与后台「页面不存在」同形，不是「抱歉，您没有权限访问该页面。」；看不到其他公司列表。
- **GWT-82.4**：Then 「用量/安装属于企业空间」同类说明，不是空表假装没订阅。
