## GWT / Then（从 spec 抄）

- **GWT-60.1**：Then 明文只出现一次；同一屏给出 Base URL 与「复制 Base URL → 粘贴令牌 → 发一条请求」三步内用法；不得把出站拉数地址写成 Base URL；不得出现平台网关钥匙。
- **GWT-60.2**：Then 用量数字 ≥1，不是 0；只读成员也能看到该数字。
- **GWT-60.4**：Then 「还没有令牌。签发后才能按下方用法调用平台网关。」；有权者看见签发；无权者看见找管理员句，不是默认「暂无数据」。
- **GWT-60.9**：Then 官网不得出现「当前可买中转」。本 Then **不**验收官网渠道组句是否与后台能否管理渠道组互否。
- **GWT-60.11**：Then 只见前缀与状态，不见明文。
