## 边界

**本票做什么**：用量满额不到注册；无「没有下一步」否定骨架。购买形「提交升级订单」改为骨架「提交升级申请」（**不**改官网成该动词、**不**撤 ¥299、**不**写当前可买）。只读找管理员。概览组加叶 `/orders`（h1「我的订单」）。`listMyOrders` 必须渲染。定价页专业档三数字与用量执法同一套。

**本票不做什么**：

- 不代选 Q-PRICE 三项（官网动词、确认履约三数字、撤价）
- 不把确认后配额变专业档写成成功句
- 超管待确认 Tab 失败≠空 → T-23
- 不重排五组

## GWT / Then（从 spec 抄）

- **GWT-50.1**：Then 去结果库；不到注册；页上不出现「没有下一步 / 尚未开通」来否定线下申请骨架。
- **GWT-50.6**：Then 「已达任务并发上限」+ 与 token 满同一线下申请入口（只读则找管理员）；不到注册。
- **GWT-50.12**：Then 两处都不是「当前可买」；不得一处「预告不可购买」一处购买形「提交升级订单」。用量页骨架（GWT-50.1/50.2）仍成立，本 Then 没有「两处都没有购买形按钮」这一支。官网是否改成「提交升级申请」= Q-PRICE，不在本 Then。
- **GWT-50.13**：Then 两处为同一套三个数；不得两套对外数字。本 GWT 不把确认收款写成已履约该三数字（Q-PRICE）。

空态（edge-states `/orders`）：接口 200 且 0 行 →「还没有升级申请。」禁止「暂无数据」。paid 文案「已确认」，**不**写「配额已变为专业档」。
