## 边界

**本票做什么**：扩 `POST /api/v1/billing/orders` 写规则：仅负责人/公司管理员 + `channel=offline` 才可能产生 pending；在线通道零新行；已有 pending 不产生第二张；经办/只读不产生单且可见「请联系企业管理员」；免费档 / 企业档无 SKU 不下单。入口必写 `idempotency_key`。

**本票不做什么**：

- 我的订单读模型 / 超管确认 / 事件 → T-02
- 用量/定价 UI / `listMyOrders` 渲染 → T-03
- 不代选 Q-PRICE（不撤 ¥299、不履约三数字、不改官网动词）
- 不实现在线扣款、发票、取消
- 不把 `_apply_plan` 写成完成条件，也不单票删除它

## GWT / Then（从 spec 抄，不另写 oracle）

- **GWT-50.2**：Then 本企业多一条状态=待确认收款的线下申请（档位=专业 / pro，不是企业档）；提示等待管理员确认收款；不到注册；不产生已支付在线单。
- **GWT-50.5**：Then **不产生任何单**（含不产生 pending / 已支付）；若此前已有 pending 则保持原 pending、不新开一张；用户可见「在线支付尚未开通，请改用线下对公。」；可见文案不含 `PAYMENT_NOT_CONFIGURED`。
- **GWT-50.7**：Then 页上说明「请联系企业管理员」；套餐不变；不产生订单；用户可见不含 `FORBIDDEN`、`QUOTA_EXCEEDED`、裸 `429`、`QUOTA_PLAN_LOCKED`。（本票 API 侧：不产生单 + 可见句无内码；UI 旁注 T-03。）
- **GWT-50.8**：Then 「请联系企业管理员」；不产生订单。
- **GWT-50.14**：Then 企业档不得与专业档写成同一「提交升级申请」动作；不得出现第三档可申请 SKU。
- **GWT-50.15**：Then 不产生第二张单；原单保持 pending；配额不变；用户可见「已有待确认的升级申请」；不是取消。

用户可见禁内码：`PAYMENT_NOT_CONFIGURED` / `FORBIDDEN` / `QUOTA_EXCEEDED` / 裸 `429`。分支用 `code`。
