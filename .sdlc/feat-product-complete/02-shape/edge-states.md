## 0. 纪律（先于各屏）

### 0.1 不得互否的空态（X-TRUTH）· 本轮不冻的互否

三处必须可同时成立，**空闲/空态文案也不得互相否定**：

| 处 | 空闲时允许说 | 空闲时禁止说 |
|---|---|---|
| 官网定价 | 付费档「预告不可购买」；免费可开通 | 「当前可买」；把企业档写成与专业档同一申请动作 |
| 用量满额 / 未满 | 负责人看见「提交升级申请」骨架；可保留「本波不提供自助改套餐」 | 「没有下一步 / 尚未开通」来否定骨架；「当前可买」；购买形「提交升级订单」 |
| 我的订单空 | 「还没有升级申请。」+ 去用量或定价 | 「暂无数据」；「购买未开通所以没有订单」（否定骨架） |

**不是本轮冻结 Then（不要用空态去「修」）：** 官网渠道组仍可画成企业档预告，后台免费租户已能打开渠道组。禁止为了自洽去写「现在就能买中转站」，禁止给渠道组叶加档位前提。官网动词是否改成「提交升级申请」、确认后是否履约三数字、是否撤 ¥299 = Q-PRICE，本文件不选。

### 0.2 失败 ≠ 空（FR-84，全后台点名屏同一 Then）

接口失败时内容区必须是 **失败句 + 可点「重试」**。表格/数字 **禁止** 变成：

- 「暂无数据」
- 「暂无在线节点」
- 「还没有采集结果」（当失败时）
- 「暂无 LLM 供应商，点击新建」
- 仪表盘卡片用 **0** 冒充没跑过

真 0 才走「还没有…」。渠道组无令牌走 §渠道组空态，不是失败句。

### 0.3 用户可见禁内码（X-QUOTA）

可见处 **禁止** 渲染：`QUOTA_EXCEEDED`、裸 `429`、`FORBIDDEN`、`PAYMENT_NOT_CONFIGURED`、`QUOTA_PLAN_LOCKED`。内部码可留在异常类型。分支用 `code`，不用 `message`。

| code | 用户可见 |
|---|---|
| `QUOTA_EXCEEDED` | 「已达配额上限」。经办入队再加「请联系企业管理员」（**没有**提交升级申请） |
| `PAYMENT_NOT_CONFIGURED` | 「在线支付尚未开通，请改用线下对公。」；**不产生任何单** |
| `FORBIDDEN` / 裸 `429`（只读改套餐） | 「请联系企业管理员」 |
| `ORDER_PENDING_EXISTS` | 「已有待确认的升级申请」 |
| `ORDER_FREE_PLAN` | 「免费档无需下单」 |
| `AUTH_BAD_CREDENTIALS` / `AUTH_FAILED` | 「用户名或密码不正确。核对后再登录。」 |
| `AUTH_TENANT_EXPIRED` / `TENANT_EXPIRED` | 「企业已到期或停用，请联系平台。」（与上一行 **不同句**） |
| `LLM_GATEWAY_UNREACHABLE` | 「平台 LLM 网关不可达」；不是套餐句；用量不显示「已用完」 |

未知码兜底：「加载失败，请稍后重试。」小字「错误编号 {trace_id}」。主按钮「重试」。

### 0.4 隐藏 vs 禁用 vs 404

| 类 | 做法 | 理由 |
|---|---|---|
| 发现性写（下单、签发渠道组令牌、入队）无权限 | **隐藏控件** + 旁注找管理员句 | 点了再失败不算藏（FR-89） |
| 危险/平台专属/组织幽灵 | **导航隐藏**；直打 404 同形 | 不泄漏「这里有一个你进不去的功能」 |
| 系统设置经办/只读 | **进页** +「当前账号不能改系统设置」；无保存 | GWT-90.2 **单 Then**；设置不是幽灵 |
| 权限未知 | 「权限加载中」；保留读叶 | 未知 ≠ 无权限滤光 |

前端藏控件是体验；后端必须独立拒。强提交仍拒、名单/钥匙不变。

### 0.5 明文只一次

出站拉数钥匙与渠道组令牌同一交互：签发成功后 **本屏一次性** 展示明文 +「复制」+ 警告「关闭后无法再查看明文」。再次打开同一入口只见 **前缀 + 状态**（已签发 / 已吊销）。复制 toast 动词与产品名一致：「已复制出站拉数钥匙」/「已复制渠道组令牌」。事件与日志不含明文。平台网关钥匙不得出现在租户复制框。

### 0.6 Toast vs 内联 vs 全屏

| 严重度 | 用什么 |
|---|---|
| 成功 | Toast 3s，动词与按钮同名 |
| 可恢复操作失败 | 内联，不关弹窗 |
| 页级加载失败 | 内容区替换 +「重试」 |
| 会话失效 | 跳登录，保留 `from`：「登录已过期。重新登录后回到刚才的页面。」 |

不只靠颜色：错误 ✕、警告 ⚠、成功 ✓、预告「预告」文字角标、伪装「伪装」字样。

### 0.7 加载节奏 / 离线默认

首次：骨架（形状跟真内容）。刷新：旧内容 opacity 0.6 + 顶细进度。&lt;200ms 不闪。&gt;10s：「加载较慢」+ 仍可重试。

离线默认：标题「网络不可用」。说明「现在连不上服务器。已打开的内容仍可阅读；提交、签发、刷新列表会失败。」主按钮「重试」。**禁止**把离线渲染成空列表。

### 0.8 交互四态（写控件通用）

| 态 | 表现 |
|---|---|
| hover | antd 默认；可点控件指针变化 |
| focus | **可见焦点环**（不能只有 hover） |
| active | 按下反馈 |
| disabled | 降对比 + 旁注或 tooltip 说明 **为什么**（签发中… / 已有待确认…） |
| loading | 按钮内部 spinner + 文案「{动词}中…」；弹窗其余部分不禁用 |

无权限的写控件：**不渲染**（见 0.4），不要做成 disabled 再 403。

### 0.9 mailto

若仍出现 `contact@localhost`，必须标明「本机占位，不是值班电话」。不得验收成已接通客服。不发明电话。

### 0.10 页头规范（FR-99）与布局 token

**结构（后台点名页统一）：**

- 顶栏行 = 页名 +（如有）页级 tab，与欢迎语同一行。页名是本页**唯一**标题。
- 内容区直接开始业务内容（筛选 / 表格 / 表单）。**禁止**复述页名的标题卡（h1 / Card title）与页级装饰横幅。
- 区块标题（Card title 用于**区块**，不复述页名）允许保留；弹窗、行展开不受本条约束。

**布局 token（antd 基座，不新增视觉体系）：**

| token | 值 | 用途 |
|---|---|---|
| `page-header.height` | 56px | 顶栏行高（含页名与页级 tab） |
| `page-header.title` | 16px / 字重 600 | 页名；内容区不再出现同级标题 |
| `page-header.tab` | 14px，选中 600 | 页级 tab，位于页名右侧同一行 |
| `page-header.gap` | 16px | 页名 ↔ 页级 tab 间距 |
| `content.padding-top` | 16px | 顶栏行下沿 → 内容区第一行 |
| `content.block-gap` | 16px | 内容区块之间 |
| `section.title` | 14px / 600 | 内容区区块标题（不得复述页名） |
| `tab-switch.motion` | ≤150ms 透明度过渡，无位移 | tab 切换只动内容区 |

**六点名页改造前后（GWT-99.1；中转站管控详见该屏）：**

| 页 | 改造前（冗余三层） | 改造后 |
|---|---|---|
| LLM 配置 `/llm` | 顶栏页名 + 页内标题卡 + 绿色「当前激活供应商」横幅 | 顶栏行=页名；横幅移除，其信息由「默认」标记列与无默认提示承担（FR-97）；内容区直接供应商表 |
| 中转站管控 `/newapi` | 页内标题卡 + tab 在页内第二行 | 顶栏行=页名 +「总览 / 探针 / 事件」tab（GWT-98.1）；内容区直接当前 tab |
| 采集任务 `/spiders` | 顶栏页名 + 页内标题卡复述 | 顶栏行=页名 + 页级 tab（任务列表 / 定时任务 / 采集方案 / 告警规则）；内容区直接列表 |
| AI 采集规划 | 顶栏页名 + 页内标题卡复述 | 顶栏行=页名；内容区直接方案列表；六态沿用 v2 |
| 系统设置 `/settings` | 顶栏页名 + 页内标题卡复述 | 顶栏行=页名；内容区直接表单分区 |
| 用户管理 `/users` | 顶栏页名 + 页内标题卡复述 | 顶栏行=页名；内容区直接筛选 + 用户表 |

**不变式（GWT-99.2/99.3/99.4，精简不阉割）：**

- 列表加载失败句 +「重试」不因页头精简被吞、不回落空表（FR-84）。
- 该页原有动作（新建 / 保存 / 筛选）结果与精简前等价。
- 只读成员写控件仍隐藏（FR-89 不因布局回退）。
- 横幅中非冗余信息在内容区安置：**不借机删信息，也不借机加新横幅**。条件态提示不是装饰横幅，允许保留（如采集任务页无工人横幅 FR-85、LLM 无默认提示 FR-97）。

### 0.11 内容区切换过渡态（FR-96 验收口径）

路由结构（单布局树）归 ADR-0022，本条只钉可见口径：**首访与懒加载的 fallback（骨架 / loading）只渲染在内容区**；侧栏与顶栏不卸载、不重挂、不闪「权限加载中」。「权限加载中」仅首次权限未就绪时出现（GWT-96.3 = 82.2 同句），此后任意菜单切换：内容区切换、侧栏展开与滚动状态保持（GWT-96.1/96.2）；菜单真相仍是 ADR-0021（GWT-96.4，布局重构不改变）。

## 屏：官网定价 `/pricing`

### 加载

➖ 静态三档，无请求则无骨架。

### 空

➖ 三档始终渲染。不是空货架。

### 错误

mailto 客户端失败：「邮件客户端没有打开。复制 {CONTACT_MAIL} 联系平台。」（占位须标 0.9）

### 权限

匿名 = 已登录可看集合相同。专业/企业主钮 **不到** `/register`。无「提交升级申请」写在官网（不代选 Q-PRICE 官网动词）。

### 边界

- 专业/企业 CTA 文案 **「预告不可购买」**，角标「预告」。不得「当前可买」。不得「当前可买中转」。
- 企业档 **不得**与专业档写成同一「提交升级申请」动作，不得假装第三档 SKU。
- 专业档印的并发 / 存储 / tokens 必须与用量页该档 **正在执法** 的三数字同一套（抽检夹具 = 企业已在专业档，不是本波确认履约）。
- ¥299 是否撤 = Q-PRICE，本屏不改价、不藏价、不写成已选「不撤」。
- 渠道组出现在企业档预告列表 **允许**（本轮不冻与后台的互否）。

### 离线

页可阅读。点免费注册：「网络不可用。连接恢复后再创建企业。」

## 屏：用量看板 `/usage`

### 加载

三卡骨架。刷新保留数字半透明。禁止整页 Spin 把进度条闪没。

### 空

| 类型 | 判据 | 文案 | 操作 |
|---|---|---|---|
| 本来没有用量 | 接口 200，三指标均为 0 | 「还没有用量。完成第一次采集后这里会显示配额进度。」 | 「去采集」→ `/spiders/tasks` |
| 超管无企业 | `scope=platform` 或企业空间句 | 「用量属于企业空间。」 | 无「去采集」装成租户 |

禁止「暂无用量数据」。本空态 **不得**写「尚未开通」来否定线下申请骨架。

### 错误

「用量加载失败。检查网络后重试。」主按钮「重试」。禁止把失败画成 0%。`LLM_GATEWAY_UNREACHABLE` → 「平台 LLM 网关不可达」，**不是**套餐超限，进度条不画满。

### 权限

| 角色 | 表现 |
|---|---|
| 负责人 / 公司管理员 | 满额可见「提交升级申请」（骨架）。可保留「本波不提供自助改套餐或支付」与申请按钮 **同屏** |
| 经办 / 只读 | **无**申请按钮。旁注「请联系企业管理员」。只读可另有「只读可见进度，不能改套餐」 |
| 超管无企业 | 上表空态 |

### 边界

| 边界 | 文案 / 行为 |
|---|---|
| 存储满 | 「去结果库」→ `/data`。不到注册。不出现「没有下一步 / 尚未开通」 |
| token 满 | 「已达配额上限」+「提交升级申请」。档位=专业/pro。提示等待管理员确认收款。不到注册。不产生在线已支付单 |
| 并发满 | 「已达任务并发上限」+ 与 token 满 **同一**线下申请入口（只读则找管理员） |
| ≥90% 未满 | 「接近上限。超额操作会被拒绝。」 |
| 在线渠道 | **不产生任何单**。「在线支付尚未开通，请改用线下对公。」无 `PAYMENT_NOT_CONFIGURED` |

「用户列表加载失败。检查网络后重试。」+「重试」；不是空表（FR-84 同句式）。恢复提交失败（非占用）：「恢复失败。{原因或检查网络后重试}。该用户仍保持已删除。」弹窗不关。

### 权限

仅平台超管。租户任一角色：导航隐藏；直打页面或恢复动作 = 404 同形；已删用户保持已删除。

### 边界

- **已删标记（GWT-93.1）**：「已删除」筛选中的行带状态 Tag「已删除」；活跃用户不出现在该筛选结果中。
- **恢复确认**：行动作「恢复」→ 弹窗「恢复用户 “{用户名}”？」说明「恢复后该用户回到用户列表并恢复为启用状态，可重新登录。」按钮「恢复」/「取消」；恢复中「恢复中…」。
- **占用冲突（GWT-93.4/93.8）**：内联红字「用户名或邮箱已被现有用户占用。」+ 第二行「该用户仍保留在已删除列表中。」弹窗不关（0.6）。username 按同租户在册判、email 按全局在册判，任一冲突即本句；现有用户的标识与数据不变。
- **恢复成功（GWT-93.3）**：toast「已恢复 “{用户名}”。该用户已回到用户列表。」该行从「已删除」筛选消失、出现在默认列表且状态=启用；上报 `user_restored`（产品事实，非用户可见面）。
- **重复恢复（GWT-93.9）**：已恢复行不在「已删除」筛选中，无恢复入口；并发残留触发 = no-op，不重复 toast、不重复事件。
- **种子 admin 不可删（GWT-94.1）**：删除确认弹窗内联「平台初始账号不可删除。」admin 行不变（即使存在第二个超管）。
- **建号归属（GWT-95.4）**：新建用户不选归属企业时，归属字段旁注「不选则归属平台租户」；保存后归属列显示「平台租户」。

### 离线

列表错误句。点恢复：「网络不可用，用户没有恢复。」弹窗不关。

## 屏：企业管理 `/enterprise`（FR-94/95，平台页增强）

## 屏：一键导入向导（FR-100，治理台内）

治理台目录区入口「导入资产」（仅超管）→ 三步向导：①选择 → ②解析预览 → ③结果。导入产物**未上架**（上架仍走治理目录既有动作）；不触发资产执行；完成上报 `asset_imported`（产品事实，非用户可见面）。

### 加载

上传「上传中…{percent}」；解析「解析中…」+ 列表骨架；导入「导入中…」逐条状态滚动。向导不锁整页。

### 空

| 判据 | 文案 | 操作 |
|---|---|---|
| 初始未选 | 「选择包含 skill、agent、command 或 plugin 的文件或目录压缩包。类型由导入过程自动判定。」 | 「选择文件 / 目录」 |
| 所选内容无任何可导入资产（GWT-100.3） | **「没有可导入的资产。」** | 「重新选择」 |

空批次不是静默成功，也不是失败句。

### 错误

| 场景 | 文案 |
|---|---|
| 上传 / 网络 | 「导入没有开始：网络不可用。」保留所选 |
| 解析失败 | 「解析失败。{原因或检查文件格式后重试}。」+「重新选择」 |
| 格式不合法（逐条，GWT-100.2） | 「{文件名}：格式不合法，无法识别为 skill / agent / command / plugin。」 |
| 超大文件（逐条，GWT-100.5） | 「{文件名}：超过大小上限 {N}，未导入。」（N 为来自配置的具体数字，必现） |
| 路径逃逸（逐条，GWT-100.7） | 「{条目名}：路径指向资产目录之外（如 `../` 或绝对路径），已拒绝。」资产目录外零新文件 |

超大与路径逃逸均为**逐条拒绝**，同批合法项照常导入（部分成功）。

### 权限（GWT-100.6）

仅平台超管；入口仅在治理台（超管七叶，FR-37 保持）。租户无入口；直打导入动作 = 404 同形；不产生任何目录行。

### 边界 · 部分成功与幂等

- **解析预览**：逐行 = 类型徽标（技能 / 智能体 / 命令 / 插件）+ 名称 + 状态（可导入 / 不可导入 + 原因）。确认按钮「开始导入」。
- **结果清单（GWT-100.2）**：两组「导入成功 {n}」/「未导入 {m}」，逐行名称 + 中文原因；不可导入行原因必现。
- **未上架提示**：成功行旁「已导入，未上架。上架请在治理目录操作。」禁止出现「已上架」。
- **幂等重导（GWT-100.8）**：已存在资产行标「已存在，跳过」，不产生第二行；不计入失败。
- **四类齐（GWT-100.4）**：预览可见四类徽标，类型由导入过程判定，无需手工分型。

### 离线

「导入没有开始：网络不可用。」保留已选内容。
