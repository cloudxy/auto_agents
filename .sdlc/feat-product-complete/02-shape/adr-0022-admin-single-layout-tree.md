# ADR-0022：Admin 单布局树——撤平台页双挂载，切换不重挂不闪

> 状态：**accepted**
> 日期：2026-09-11｜决策者：architect 帽｜相关：spec v1.5 FR-96 / FR-99；**ADR-0021（菜单真相，本 ADR 不改其语义）**；X-IA（五组不重排）；GWT-96.4 钉 FR-82 不变

## 背景

`frontend/admin/src/App.tsx` L59–68 `PlatformAdminLayout` 为 `/newapi` `/platform-ops` `/users` 三个平台页**单独再挂一份 `AdminLayout`**（L78–83），主树另挂一份（L85 起）。超管在「平台组页 ⇄ 业务组页」之间切换时，两棵路由子树交替卸载/重挂 → 整个 `AdminLayout`（含侧栏、权限加载）重建，闪「权限加载中」，侧栏展开态丢失（操作者 F6；FR-96）。

**触发这个决策的约束**：

| 约束 | 来源 |
|---|---|
| 跨组/组内切换：侧栏不闪「权限加载中」，展开态保持 | GWT-96.1/96.2 |
| 首次加载允许「权限加载中」（与 82.2 同句），此后不再出现 | GWT-96.3 |
| 布局重构不改菜单真相（menuConfig + filteredMenus 仍是唯一输入） | GWT-96.4；ADR-0021 |
| 平台页对租户（含公司管理员）= NotFound 同形，不进 Unauthorized | X-IA；现网 `PlatformAdminLayout` 语义保持 |
| 五组不重排 | X-IA；spec §5 |

## 决策

1. **单一 `AdminLayout` 挂载点。** 撤 `PlatformAdminLayout` 布局分支，`/newapi` `/platform-ops` `/users` 并入主路由树（与 `/dashboard` `/users` 等同层）。平台属性改由**页级守卫**表达：页面/路由 element 内判定 `is_platform_admin`，非超管渲染与后台 NotFound **同形**（保持现网 `PlatformAdminLayout` 的 404 语义，不进 Unauthorized、不闪权限 UI）。
2. **权限快照只加载一次。** 权限/菜单数据在 `AdminLayout` 生命周期内加载一次并缓存于 store；子路由切换不重新触发加载，因此不重挂、不闪「权限加载中」。首次加载句保留（= GWT-82.2/96.3 同句）。
3. **expand-contract：** 第一步（expand）：平台页并入主树 + 页级守卫上线，旧分支仍留作回滚保险；第二步（contract）：验证 96.1–96.4 与 404 同形后删除 `PlatformAdminLayout` 分支。两步同特征内完成，不跨特征留双路径。
4. **与 ADR-0021 的边界（QA-02/QA-07 一并钉死）：** 本 ADR 只动**挂载结构**，不动**菜单真相**——侧栏仍由 `menuConfig + filteredMenus` 驱动（ADR-0021）；`/enterprise` `/rbac` 对租户的 404 同形语义不变（T-15）；FR-95 对 `/enterprise` 的增强是既有超管页能力增强，不新开第二入口、不改租户语义。
5. **FR-99 同规范承接：** 页名/页级 tab 上提到顶栏行、内容区直接开始的规范在单树落地后推广到点名六页（T-34）；本 ADR 不规定视觉细节（designer）。

## 备选与否决理由

### 备选 A：维持双分支，缓存权限数据消除闪烁

**否决理由：** 治标。整树卸载重挂仍发生：侧栏滚动位置、展开态、动画状态全部丢失；GWT-96.2 的「滚动位置与展开状态相同」无法稳定。

### 备选 B：平台页拆独立应用/独立路由根

**否决理由：** 变相重排导航结构；超管跨组操作更碎；与「总台一体化」的操作者诉求相反。五组 IA 不许重排（X-IA）。

### 备选 C：微前端/iframe 嵌平台页

**否决理由：** 为一个布局问题引入新运行时与鉴权穿透复杂度。「第二次出现再抽象」。

### 备选 D：把守卫做成全局路由拦截器（loader 级重定向 /unauthorized）

**否决理由：** 现网平台页语义是 **NotFound 同形**（不暴露页面存在），重定向到 Unauthorized 会泄漏「这里有页」。页级守卫渲染 NotFound 保持同形。

## 证据

```
spike：平台页为何闪
问题：跨组切换为何整树重挂、闪「权限加载中」
环境：读码 App.tsx L59–83（PlatformAdminLayout + 双 AdminLayout 挂载）、
      L85 起主树；AdminLayout 依赖权限加载状态渲染侧栏
结果：两组路由各自包一份 AdminLayout；组间切换 = 卸载 A 树挂 B 树；
      权限加载随布局重建重跑 → 闪「权限加载中」
结论：单树 + 页级守卫 + 权限快照单次加载
```

## 代价与风险

| 代价 | 缓解 |
|---|---|
| 平台守卫从布局层下沉到页级，多页重复判定 | 抽一个页级守卫组件复用；lint 禁止再新建布局分支 |
| 主树体积增大（平台页并入） | 路由级懒加载保持（Page/Suspense 已有） |
| 回归面：租户可达性 | qa 直打 /newapi /platform-ops /users /enterprise /rbac 全套 404 同形重跑（§14 风险行） |

## 影响范围

| 谁 | 需要做什么 |
|---|---|
| `/frontend` | 撤双挂载；页级守卫组件；权限快照单次加载；Jest 96.1–96.4 |
| `/backend` | 无（纯前端结构） |
| `/qa` | 96.1–96.4 + 平台页 404 同形回归 + 脏 /auth/menus 下 82.1 重跑 |
| `/designer` | FR-99 页头规范在单树上落（点名六页） |

## 后续复审条件

若未来平台页数量增长到需要独立信息架构（独立导航分组），再评估分组级布局；本 ADR 不预授权第二布局分支。
