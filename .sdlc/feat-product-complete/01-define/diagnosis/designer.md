## 1. 租户壳 vs 平台壳：仍会走错页

### P-IA-01 两套菜单真相，找不着的叶与不该出现的叶同时存在

- **用户目标：** 登录后侧栏就是「我能做的事」。
- **现网阻碍：** `AdminLayout` 在 `/auth/menus` 非空时用 DB 树，空/失败才回退 `menuConfig`。DB 无「渠道组」「我的安装」，却有「角色权限菜单」「企业管理」。角色权限已回填 `menu:relay`，但没有对应菜单行——权限开了、入口没有。
- **空/错同形：** 不是空态，是**入口消失**。用户以为产品没有该能力（与「页内空表」同形于「没有这回事」）。

### P-IA-02 租户公司管理员走进平台组织页

- **用户目标：** 管本企业成员，不要碰到别的公司。
- **现网阻碍：** `requireAdmin` 认的是租户 `role==='admin'` / `is_admin`，不是 `is_platform_admin`。`/enterprise` 文案写「中转站渠道/虚拟 Key 的公司→部门→个人链路」，并 `listTenants()`。`/rbac` 改全站角色权限矩阵。侧栏若下发这两叶，租户负责人会当成「系统管理」正门。
- **空/错同形：** 进得去则像有权；API 失败则 toast + 空表，像「还没有公司」。不是后台 404 同形。v2：「直打平台专属 = 404，禁止『抱歉您没有权限』」。

### P-IA-03 平台专属直打：一半 404，一半 403 道歉

- **用户目标：** 打错地址时不要看到别人的渠道/密钥，也不要被骂「没权限」。
- **现网阻碍：** `/newapi` `/platform-ops` `/users`（含未登录）→ 后台 `NotFound`「页面不存在或已被移除」+「返回工作台」（对）。`/settings` `/enterprise` `/rbac` → `/unauthorized`「抱歉，您没有权限访问该页面。」词表禁用句。经办打设置：403；打中转：404。同一「不该进」两套语言。
- **空/错同形：** 403 与 404 不像同一产品；403 还泄漏「这里有一个你进不去的功能」。

### P-IA-04 后台「能力市场」对租户是治理台，不是货架

- **用户目标：** 在后台订一份能力，或找到已订的。
- **现网阻碍：** 官网才是逛店。后台 `/capabilities` 七叶（源|目录|插件|技能|命令|智能体|专家团）对租户**整页渲染**。源叶非超管：不请求、`rows=[]`，画出「还没有源。登记源后才能同步。」——权限画成空货。目录叶上架 Radio 禁用 +「需要平台市场权限」，租户仍看见全套上架控件。订阅弹窗从治理表触发；空 CTA「去能力市场」跳出到官网。
- **空/错同形：** **权限空 = 产品空。** 源叶是最干净的反例。

### P-IA-05 超管无企业 / 权限未就绪

- **用户目标：** 超管不当成租户；权限加载时不要闪出写叶。
- **现网阻碍：** 用量无企业走「用量属于企业空间」（对）。`/relay` `/installs` 路由无租户守卫，超管无 `tenant_id` 可直打；安装失败句可能是「需要企业空间才能订阅」，渠道组则 toast「渠道组加载失败」+ 空表。权限未就绪：读叶保留、平台写叶剥离（对）；动态菜单 `allowPlatform` 还要求 `permissionsReady`，超管在加载窗口可能暂时看不到值班叶（安全，但无「权限加载中」以外的解释）。
- **空/错同形：** 渠道组失败 ≈ 空组；用量权限态有专句，渠道组没有。

## 2. 注册 → 登录 → 第一次出数：会断，也吓人

### P-ONB-01 用邮箱注册，用「用户名」登录，用户名从未让用户选

- **用户目标：** 开通企业后马上登录开工。
- **现网阻碍：** 注册只收 `admin_email` + 密码。后端 `username = email.split("@")[0][:48]`。成功句：「企业「…」已开通，负责人 {username}。登录后开始采集。」「负责人」不是「登录名」。登录页 label「用户名」，placeholder「用户名」，邮箱框还 `autoComplete="username"`。用户若填完整邮箱 → `AUTH_FAILED`「用户名或密码不正确。核对后再登录。」与真错密码**同一句**。跨租户同名靠密码消歧；同名同密直接 401，仍是这句。
- **空/错同形：** 凭证错 / 消歧失败 / 邮箱当用户名 = 同一错误。成功屏不复述「请用『{username}』登录」。链在这里断一次。

### P-ONB-02 注册成功有路，登录后三步与真实出数条件打架

- **用户目标：** 第一次提交采集并在数据中心看见条。
- **现网阻碍：** 成功主按钮 `{ADMIN}/login?from=/dashboard`（不断链，对）。仪表盘零任务：「还没有采集任务。按下面三步开始。」LLM → 采集任务 → AI 规划（不到 `/newapi`，对）。然后：
  1. LLM 空表：「暂无 LLM 供应商…」不是「还没有本企业供应商。添加并激活后…」。失败 catch 静默 → 空表。
  2. 采集任务：无工人横幅「采集未运行，不会出数」——**无「查看节点」**。任务表无空态句，zhCN 默认「暂无数据」。筛选空与本来没有同形。
  3. 节点：「暂无在线节点（Worker 进程心跳 10s 上报一次）」——心跳实现细节，新用户读成「系统坏了」。`isError` 未分支，失败也是这张空表。
  4. 数据中心：无「还没有采集结果。完成一次采集后会显示在这里。」失败 toast，表仍空。统计卡失败后 `?? 0`，零任务像「没跑过」而不是「没加载到」。
  5. AI 列表：「暂无 AI 采集计划，去「采集向导」创建一个」——有邀请，但「暂无」词表不推荐；向导失败句与网关/套餐/本行未在本诊断展开（v2 已锁，现网部分落地）。
- **空/错同形：** 无工人 / 接口失败 / 真的 0 条，在任务、节点、数据中心三条路上同形。横幅「不会出数」是吓人口径：对，但下一步只剩猜。

### P-ONB-03 仪表盘其余空块是死胡同

- **用户目标：** 看清「还没跑」和「跑过但没分」。
- **现网阻碍：** 趋势「近 7 日还没有运行记录。」（对）。Top5「暂无采集结果」、质量「暂无质量评分数据 / 暂无质量分布数据」无 CTA。加载失败 toast「获取运行统计失败」，卡片继续显示 0。
- **空/错同形：** 失败画成零。

## 3. 用量 / 升级 / 渠道组 / 我的安装：找不找得到，空态说什么

### P-FIND-01 用量找得到（静态或 DB 都有），空/错基本分得开，升级出口和官网打架

- **用户目标：** 看配额；满了知道下一步；不要被骗去再注册一家。
- **现网阻碍：** 叶在概览，租户找得到（DB 有此行）。零用量：「还没有用量。完成第一次采集后这里会显示配额进度。」+「去采集」（对）。将满/满额句对，满额不到 `/register`（对）。缺块：`!data || !usage || !quota` →「**暂无用量数据**」（v2 禁）。加载失败有 Alert，但无「重试」按钮。只读有「只读可见进度，不能改套餐」。满额另有「提交升级订单」→ 线下 `createOrder(pro)`；无单则 toast「暂无付费档」。**没有「我的订单」叶**，提交后无法在后台核对 pending。申请提升 = mailto。
- **空/错同形：** 零用量 ≠ 失败（对）；「暂无用量数据」把契约缺口画成空。网关不可达有专句，不装套餐满（对）。

### P-FIND-02 渠道组：Q-RELAY 已关，入口却经常不存在；页内无空态

- **用户目标：** 给本企业建组、签发令牌、看到限额；不要碰到平台熔断。
- **现网阻碍：** 静态菜单在概览（和用量并列）。动态菜单无此叶 → 现网默认**找不到**。找到后：Info「平台渠道窗口与熔断由值班超管在「中转站管控」维护」——租户点不进该页（404 同形），等于指向一扇不存在的门。写权仅 `isAdmin || role==='admin'`；经办能开页、无按钮、无「当前账号不能管理渠道组」。空表 = antd 默认「暂无数据」。签发后明文只一次（对）但无「令牌用来干什么」的下一步（接 LLM？接外部？）。吊销无确认。
- **空/错同形：** 加载失败 toast「渠道组加载失败」，表变空；与「还没有组」同形。经办无组 vs 无写权同形。

### P-FIND-03 我的安装：页内空态合格，导航经常没有；空 CTA 把人送出后台

- **用户目标：** 看到已订、卸一行、分辨已下架 vs 还能订。
- **现网阻碍：** 静态在能力资产组；DB 无行 → 找不到。页内空：「还没有订阅的能力。去能力市场看看已上架的能力。」+「去能力市场」→ **官网** `/capabilities`，不是后台订入口。加载失败有重试（对）。卸载失败留在确认框（对）。只读 tooltip「当前账号不能卸载」。unlist「已下架，不能新订」。加载中是「加载中…」不是骨架。
- **空/错同形：** 列表失败 ≠ 空（对）。找不到入口时，用户以为「没有安装这回事」。

### P-FIND-04 订阅回跳落在治理台，不落在「我的安装」

- **用户目标：** 官网点「登录后订阅」→ 登录后完成这一行，并在「我的安装」看见它。
- **现网阻碍：** `from=/capabilities?subscribeType&subscribeName`，进后台七叶治理 + 弹窗。取消弹窗 = 停在源/目录。v2：未登录订阅回跳后**尚未订**（对），但回跳地址不是 `/capabilities/installs`。
- **空/错同形：** 订成功无「已订到 {host}，去我的安装」落点（toast 在弹窗内，导航仍无该叶）。

## 4. 官网定价空头 vs 后台实际能力（只记差，不代选 Q-PRICE）

差是认知差，不是定价决策。Q-PRICE 保持开放。

| 官网 `/pricing` 说 | 后台实际 | 用户会以为 |
|---|---|---|
| 免费档：5 并发 / 10,000 条 / 20 万 tokens；成员管理；用量看板 | 用量三指标数字对齐（`FREE_TIER_FEATURE_COPY`） | 数字这条是诚实的 |
| 专业档 ¥299/月，「预告不可购买」+ mailto | DB `plans.pro` = 29900 分；用量「提交升级订单」可建 pending 线下单；在线通道 `PAYMENT_NOT_CONFIGURED` | 一边不能买，一边已经能下单 |
| 专业档预告：50 并发 / 200,000 条 / 500 万 tokens | 种子 pro 配额 20 / 500,000 / 5,000,000 | 预告数字与账本不是同一套 |
| 企业档预告含「中转站渠道组分配」 | Q-RELAY 已关：租户渠道组是**本企业 SKU**，不是企业档专属；且免费租户菜单（静态）已有「渠道组」 | 免费用户要么找不到组，要么发现「企业档才有的东西」已经在概览里 |
| 免费可买；付费「尚未开通购买」 | 无「我的订单」；无自助支付 | 升级发生在用量满额之后，定价页不知情 |
| 首页功能区仍写失败自动重试、Webhook 多通道、节点扩缩容；导出已诚实「CSV/JSON、单次最多 100 条」 | 第一次出数还依赖本机 Worker 心跳 | Hero/功能卡比定价更空头；定价页本身比首页克制 |

**Q-VOICE 未关：** 首页仍是 ALL-CAPS 眉标、Hero glow、漂浮芯片、整卡抬起——与 brief 两遍法未对齐。此处只记「品牌前线仍像另一套模板」，不代选对外第一句。

**Q-MARKET-USER 未关：** 租户在后台看见治理七叶，在官网看见货架。差已构成「两套店」体验，但不在本诊断选定市场用户是谁。

## 5. 其它会让人觉得「不好用」的同形与可见差（短列）

| ID | 用户目标 | 现网阻碍 | 空/错同形 |
|---|---|---|---|

| P-OFF-01 | 断网时知道哪些还能看 | 登录/注册/定价/详情/卸载有离线句；用量/任务/渠道组/仪表盘多数把离线当普通失败或空表 | **离线 = 错误 = 空** 大面积成立 |

## 6. 第一次出数路径（屏序列，只标断点）

```
官网 / 或 /pricing
  → /register（邮箱当登录线索，未标明登录名）          P-ONB-01
  → 成功「登录管理后台」
  → {ADMIN}/login?from=/dashboard（填邮箱则失败同句）   P-ONB-01
  → /dashboard 三步（LLM / 任务 / AI）
  → /llm 空表「暂无供应商」或失败变空                     P-ONB-02
  → /spiders/tasks 「不会出数」+「暂无数据」               P-ONB-02
  → /spiders/nodes 「心跳 10s」                          P-ONB-02
  → /data 零卡片 + 空表                                  P-ONB-02
  → （可选）官网订能力 → 登录到治理台而非我的安装          P-FIND-04
  → 用量满了：mailto 或「提交升级订单」；定价页仍说买不了  §4
```

吓人点不在注册按钮，而在**登录字段**和**无 Worker 的产品句**。后者是真约束，缺的是「去节点看 / 现在提交也会排队」而不是只宣布失败。

## 7. 给 shape 的待补清单（本文件不是合同）

DEFINE 之后 designer 再写六态时，优先这些屏（permission + offline 不得再跳）：

1. 后台壳：动态菜单 vs 静态；租户 vs 平台叶；直打 404 vs 403 道歉
2. 登录：邮箱/用户名/消歧失败三句要分
3. 仪表盘 / 采集任务 / 节点 / 数据中心：失败 ≠ 0 ≠ 无工人
4. 渠道组（Q-RELAY 已关，v2 sitemap 过期）：空组、经办只读、无企业超管、失败
5. 我的安装：导航可见；空 CTA 留在哪一店
6. 租户「能力市场」：货架 vs 七叶（Q-MARKET-USER 未关前只列态，不发明用户是谁）
7. 用量：去掉「暂无用量数据」；升级订单去哪看（出口受 Q-PRICE 约束，设计只预留位置）
