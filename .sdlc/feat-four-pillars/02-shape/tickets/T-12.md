## 边界

**本票做什么**：从 git 跟踪中移除 `deploy/litellm/config.gen.yaml` 一类生成配置中的上游明文 Key（改 ignore + 占位模板）。启动缺密钥拒绝或功能保持关闭，不用仓库真 Key 默默连上。租户**仍能打开**的系统设置若有上游密钥字段则掩码（GWT-14.3）。渠道/中转页对租户不渲染密钥——那条走 T-04 / GWT-14.4，本票不把「打开渠道页看到掩码」当验收。

**本票不做什么**：改 new-api 本体；把 Key 写进本方案正文；历史 git filter-repo 是否执行由操作者/sre 在机外完成并在 evidence 记录命令。

**会改哪些文件**：

| 文件 | 改动性质 |
|---|---|
| `.gitignore` | 修改：登记生成配置 |
| `deploy/litellm/` | 修改：占位符模板，去掉明文 |
| 启动校验 `_validate_runtime_secrets` | 核对/加强 |
| 渠道响应 schema | 核对掩码 |

**不许改的文件**：`config/default/*.yml` 不得新写明文 password
