## 1. 一句话结论

现界面仍是「采集控制台 + 能力目录雏形 + SaaS 骨架 + 中转值班页」，**不是四柱产品**。官网只卖爬虫、商店双入口、上架/订阅/预告六态空白。spec 已把用户可见规则写死（能力市场、listed ≠ trusted ≠ enabled ≠ 已订阅、失败不得装空），**UI 尚未翻译成任务**。Wave 0 的设计工作是**停止说谎 + 接上注册登录 + 权限态文案**；Wave 1 才是商店面与治理台。Q-VOICE 未关前，禁止新写并列四柱 Hero。

## 2. 诊断口径

### 2.1 用户（spec 角色，界面是否认得）

| 角色 | 心智任务 | 熟练度 | 现界面 |
|---|---|---|---|
| 匿名访客 | 判断现在能做什么、逛已上架能力、比价、注册 | 陌生 | 首页只讲爬虫；市场是两个广场；定价卖未履约项 |
| 租户 owner | 注册后登录、邀成员、看配额、升级出口 | 新手 | 注册有；成功页无登录；升级=再注册 |
| 租户经办 | 建任务、AI 规划、导出、订阅到宿主 | 混合 | 采集最完整；订阅无屏 |
| 租户只读 | 看本企业任务/用量 | 新手 | 按钮常直接隐藏，无「请联系管理员」 |
| 平台超管 | 源同步、上架、许可、渠道窗口、平台 LLM | 熟练 | 菜单有，词是工程师的；守卫把租户 `admin` 当平台超管（`ProtectedRoute.requireAdmin`） |

策略不变：后台 antd 基座，契约质量 > 花样；官网是品牌前线，必须两遍法。混合熟练度 → 空态邀请，破坏性确认永不跳过。

### 3.3 IA 碰撞（按严重度）

**P0 — 与冻结 FR 直接冲突（Wave 0/1 必须改）**

1. **商店双入口**（FR-17）  
   `NAV_LINKS`：「技能广场」`/skills` + 「能力广场」`/capabilities`。技能广场能搜能开；能力广场技能 Tab 不能。首页 `SkillsSection` 链 `/skills`，「查看全部技能 →」。

2. **后台叶名不是市场**（FR-17 词表）  
   组「能力资产」+ 叶「资产目录」+ 页注释「能力中心」。可见标签必须改成「能力市场」（治理台页眉可加「治理」）。

3. **官网价值主张只卖采集，定价卖四柱**（FR-01）  
   `SITE_SLOGAN = 'AI 驱动的智能数据采集系统'`。Features 五张卡全是爬虫生命周期，且写「CSV / Excel」。定价突然出现工单支持、BYOK、中转站渠道组、私有技能库。

4. **虚构规模仍渲染**（FR-02）  
   `HERO_STATS`：`128,000+` / `12 节点` / `3.2 亿条`。角标「示意数据」**不够**：GWT-02.1 要求不出现这类绝对规模；GWT-02.2 禁止用「0」冒充运营。该区应不渲染。

5. **注册成功无登录出口**（FR-04）  
   Toast「即可登录开始第一次采集」；主按钮「再注册一家」，次「返回官网」。登录页无「企业注册」。

**P1 — 任务归属错误（本波以改词/改空态为主，不拆信息架构）**

6. 人帐双页：Members Alert「请用用户管理页」——应在菜单层按角色消失，不要进页上课。  
7. 日志三处：任务抽屉 / 运行日志 / 日志中心。本波不改组；空态写清「这是任务日志 / Worker 流 / 审计」。  
8. 「采集方案」三义：`TaskList` 列、`Spiders` 文件 Tab、AI「采集计划」。改列名为「爬虫」。  
9. 能力资产组单叶：Wave 1 出现「源 + 目录」两个叶子后组才成立；此前叶可升顶层，但无 IA FR → **Wave 1 治理台用页内 Tab 实现源/目录，不先改组名以外的菜单树**。

**P2**

10. 幽灵 `/enterprise` `/rbac`。  
11. `tenantOnly` 对超管隐藏用量/成员，Header 无「你在平台视角」。  
12. 官网「管理后台」直链 `REACT_APP_ADMIN_URL`（默认 localhost:9112）。  
13. 登录页紫渐变与品牌蓝青脱节。

## 4. 四柱流程（正常路径 + 断点）

图例：✅ 可走完　⚠️ 能进但断或词错　❌ 无屏

### 4.1 柱 A · 采集（Wave 0 补洞，Wave 4 才「第一次出数」完整）

```
官网 Hero「体验 AI 采集流程」→ 页内锚点（不是产品）
「进入管理后台」→ 外链 /login → /dashboard
    零任务 ✅ 三步 Alert（LLM → 任务 → AI）
    非 admin 点 LLM ⚠️ /unauthorized「抱歉」
任务列表：新增 → 日志抽屉 → 结果抽屉 CSV/JSON
    ❌ 无定制空态（TaskList 无 emptyText，筛选空=真没有）
    ❌ Worker 未在线不拦（FR-71 在 Wave 4 stub）
    ⚠️ 数据中心导出写了 100 条；官网仍承诺 Excel
```

Wave 0 必须补的交互（FR-03/08/12，不重写任务状态机）：

- 导出选项只留 CSV（及已实现的 JSON）；旁注「单次最多 100 条」；0 条「没有可导出的结果」，不下载空文件。  
- 空任务：「还没有采集任务」+「新增任务」+「用 AI 生成方案」。筛选空：「没有符合筛选的任务」+「清除筛选」。  
- 配额拒绝：内联 FR-12 文案，不把 `QUOTA_EXCEEDED` 抛到 Usage 顶栏当说明书。

Tab 焦点（新建任务弹窗）：关闭 → 类型 → 爬虫 → 参数 → 取消 → 提交；Esc；关闭后焦点回「新增任务」。返回抽屉：**保留筛选、页码、滚动**。

## 7. Admin vs Official

| 维度 | Official | Admin | 伤害 |
|---|---|---|---|
| 产品是什么 | 智能数据采集系统 | AutoAgents 控制台 | 访客买 A 进 B |
| 能力入口 | 两个广场 | 一个资产目录 | 无法建立「市场」心智 |
| 技能浏览 | 可搜可开 Modal | 表 + 英文状态 | 两边不是同一对象 |
| 卡片可点 | 技能广场可；能力广场不可 | 行点开详情 | 能力广场像死展览 |
| 登录 | 无会话 | 仅后台 | 订阅无法发生（FR-20.3 需要回跳） |

## 8. Tokens 与无障碍

### 8.1 现 token 不构成合同

`frontend/shared/src/theme/tokens.ts` 仅 6 色：`primary #1677ff` · `accent #13c2c2` · `success` · `warning` · `danger` · `deepSpace #001529`。  
`tokens.css` 另加 `--site-text-secondary: rgba(0,0,0,0.45)`。

缺：spacing 节奏、字号/字重/行高成套、radius、shadow **按用途**、motion、**breakpoints**、语义色成套（subtle/onSubtle/hover）、focusRing、touchTarget。

后果：Features `borderRadius: 20`；登录 `#667eea–#764ba2`；Hero `#0b1830` 与 `deepSpace` 分叉；`text-secondary` **大概率 < 4.5:1**。Admin ConfigProvider 不映射 radius / fontSize / controlHeight / motion。

### 8.2 必验对比度对（实现前写入 token `_contrastAudit`）

- textPrimary on surface  
- **textSecondary on surface**（优先修）  
- textInverse on primary / on deepSpace  
- 预告标上的字  
- 正品/伪装 Tag：不能只靠绿/红（加文字或图标）

### 8.3 a11y 缺口

| 项 | 现状 | 合同 |
|---|---|---|
| 焦点可见 | 未定义 | `focusRing` 2px；禁止无替代 `outline:none` |
| 焦点顺序 | 技能卡有 Enter/Space（好） | 弹窗：关 → 字段 → 取消 → 主按钮；Esc；关闭归还 |
| 触摸 | 表 `size=small` | 官网 CTA ≥ 44px；后台桌面可 32px 高但可点区域够 |
| 图标 aria-label | 部分装饰 `aria-hidden` | 「删除任务 {id}」「验证插件 {name}」 |
| 标题层级 | 官网 h1+h2；后台标题在 Header 不是 h1 | 每页一个 h1 = `pageTitleFor` |
| 动效可关 | FadeIn 已 `useReducedMotion`（好） | Hero `.hero-glow` infinite **也要停** |
| 键盘逛市场 | 能力广场卡无 role/tabIndex | 详情必须是 **真链接**（URL），不要再做不可点 Card |

### 8.4 下一轮 token 层（结构，不选定假品牌 hex）

前端只消费 semantic。primitive 暂留现品牌蓝/青，补齐套件：

- color：primary/hover/subtle/onSubtle；danger/warning/success 同套；textPrimary/Secondary/Disabled/Inverse；surface/sunken/raised；border；focusRing；listingComingSoon / listingListed（语义名）  
- space：4 的倍数 4–64  
- text：heading1/2/3、body、bodyStrong、caption（size+weight+lineHeight）  
- radius：sm/md/lg/full（后台 md=antd 6px；官网 lg **只用在一处大胆**）  
- shadow：card / dropdown / modal  
- motion：150ms hover / 250ms modal / standard easing；respect reduced-motion  
- breakpoint：sm 640 / md 768 / lg 1024 / xl 1280  
- size.touchTarget 44px  

完整 JSON 等视觉计划 critique 通过后再交。本诊断不交付一套默认蓝表冒充选择。

**色彩（命名）**  
`ink` = 统一 `deepSpace`，删 `#0b1830` 分叉；`signal` = 主操作蓝；`telemetry` 青 **只用于一处**（数据在流动 **或** 预告，二选一）；`paper` 内容底；`alert` 熔断/配额。

**字体**

**布局概念**
